## Design (shared with KW-RESUME-1, agreed 20:15)
- tools/die_plan/eco_loop.py: <=3 iterations on the routed DB, each = the shared post_route_drv recipe (prd_mk.sh OT_PRD_FROM=route; grt when DRC>0) + prd_run.sh 1 pass (repair_design -> repair_timing -setup (two-mode kits) -> -hold margin 10 ps on the routed RCX SPEF -> detailed_placement -> global_route -start/-end_incremental -> DRT of the dirty nets -> clk_freeze_check -> do-finish), then the kit's OWN sign-off with the kit's original config.mk (runner GOAL=post for KV/HBM, else do-generate_abstract + signoff.py run as run_kit.sh). Stop: SIGNED -> PASS; neg-WNS gain <1 ps and DRV/DRC not falling -> EXHAUSTED; error -> stop with best. Record eco_loop.json (kind eco, base routed DB, commands, flow sha). CLI for hard cores: eco_loop.py run --kit K [--runner R] [--lec] (one ot-run job).
- signoff_chain.py: default-on hook before RUNNER_FAIL/NOT_SIGNED when fails are only setup_tt/hold_ff/drv/drc/fanout and DRC<=50. PASS -> KIT/signoff_eco_* link (autopilot probe reads it) + the usual routed LEC on the ECO netlist + PROVENANCE kind eco. Else the old FAIL path, reason prefixed "late-ECO exhausted (...)" (kit_wave class table).
- Opt-out: kit_wave.json "late_eco": false (autopilot passes --no-late-eco), OT_LATE_ECO=0, KIT/late_eco.off.
- KW-RESUME-1 edits run_item/launch/collect/kit_resume.py; I edit only signoff_chain.py, autopilot finish/provenance/submit argv, kit_wave queue_class. eco_* dirs stay inside the attempt's kit dir.
- Known limit: kits without the two-mode session (OT_HOLD_MM=0, e.g. HEAD l48x) ECO only at the FF corner (prd_mk b-variant; kit_modes_eco.tcl forbids a TT scene there), so TT setup/TT-only slew is not repaired on them.
