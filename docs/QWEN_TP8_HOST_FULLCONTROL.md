# TP8 host control composition

`qkd_host_fullcontrol` binds the original `ot_host_if_pb2` with FMT1, token18, one user, prompt8192, context8192 to the actual ND8 `qkd_host_ctl`, original ND8 boot/reset sequencer and extended CSR. Prompt storage remains an external physical `ot_qfd_prompt_sram` leaf. Its 14-bit host addresses include a zero slot bit; the physical SRAM uses bits12:0. No behavioral memory exists in the production wrapper.

The four synchronous clock ports identify physical partitions (`ck_host`, `ck_csr`, `ck_rst`, `ck_ctl`); they require the die's insertion-compensated clock delivery, actual pin files and hop audit. `die_id==0` enables the host engine. Other die roles receive physical control/status via the package transport. Genuine boot vectors must come from the separate boot2 field `{boot_ok,boot_done}`; `kst10` means `{fault,cause9}` and is never interpreted as boot.

The original host BAR and global CSR offsets are preserved. Legacy global FAULT_STATUS retains its original 16 lower per-die summaries plus global bits16..22. The additional bank preserves all eight dies: 0x1080 sticky32, 0x1084 mask32, 0x1088 raw32, 0x108c capability8dies/4bits. Each nibble is `{physical,transport,KVfault,stepfault}`; these are explicit summaries, not an invented equivalent of the historical category map. 0x1090/1094/1098 expose all80 raw KV fault/cause bits. The summary bank supports W1C, re-latching active sources, and masked IRQ. Its reset follows the original host reset, so software soft reset preserves diagnostic history.

The controller's input/result pin stations delay the deassertion of its level `done`. The original host interface guards `done` only while `eng_start` is asserted for one edge. The host hardened leaf therefore disarms completion at each start and re-arms only after observing controller done-low. Without this glue, the next step retires stale data and eventually fails the ring bench.

`tools/qwen_host/fullcontrol_gate.sh OUT` proves the actual 32-byte descriptor, 32-bit packed prompt fields containing18-bit tokens, external synchronous prompt reads, two16-byte CQ entries with high token bits, token feedback, genuine die7 boot wait/failure, global/host ID offsets, all32 summaries, raw80 bank, W1C and IRQ. Mutants independently remove upper-die diagnostics, remove completion re-arming, and select FMT0; all must fail. This is a functional composition gate, not a physical release.

Measured hierarchical Yosys clock census after pin hardening: host4157 sinks; CSR1175; reset103; controller1292. Parent composition has zero flops and owns no mux. Every root is below15000. Census establishes the count gate only; insertion/spread, actual routed setup/hold/DRC, child_lint, die-assigned pins/slot fit, pin stations and immutable-price production throughput remain required. `physical/qkd_host_fullcontrol/partition.json` explicitly records these residual gates; no accepted physical qualification is implied.

`tools/qwen_host/fullcontrol_packet_gate.sh OUT [TRANSPORT_TREE]` runs the same exact ring/diagnostic/boot workload through actual qkd_host_packet_bundle RX/TX class routing and AXI packet transport. The board model returns physical credits and logical class7 HOST/CTRL credits independently, replies to DMA read/write packets, and sends BAR transactions as class0 HOST. Package tk/boot inputs remain directly modeled in this bench: transported TP8 control/status and PHY/CDC are independent remaining composition gates. The test takes an optional transport tree while those files live on the parent integration branch; after integration no argument is needed.

Physical pin seams now use `qkd_host_if_pins`, `qkd_host_csr_pins`, `qkd_host_rst_pins` and `qkd_host_ctl_pins`. All external channel inputs are sampled before decode, outputs are pin flops, and the actual one-outstanding endpoint's duplicate-inhibition and VALID-low re-arm preserve each delayed acknowledgement. This is an explicit matched host protocol, not an arbitrary AXI fabric. Original host engine request outputs already come from flops and are wired directly. Completion re-arm and user-clear acknowledgement belong to the host leaf; qualified-ready mux belongs to the controller leaf after pin capture. Reset leaf samples true boot/link status before the original reductions.

Prompt write/read request pins are registered and prompt read data is sampled before use. `PROMPT_READ_LATENCY=1` names the external synchronous SRAM response latency; the host inserts two extra wait edges for its request/response pin stations. A physical SRAM with a different registered latency must bind its measured latency in this parameter and repeat the exact composition bench. Original `ot_host_if_pb2` PB_READ_PIPE0/1 behavior is preserved while the parameter now counts extra wait edges.
