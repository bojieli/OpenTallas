# Actual host control and packet composition

`qkd_host_control_packet` connects `qkd_host_control_prompt`, role-aware `qkd_host_hc_station` and `qkd_host_packet_bundle`. Original controller requests and metadata travel through the bounded station into actual addressed CTRL broadcasts. Actual local93-bit sequencer status and remote93-bit status packets produce the ND8 tk vector; all80 KV status bits and all16 genuine boot bits come from the same transport. The reset checker consumes `{boot_ok,boot_done}` independently of `{fault,cause9}`. No direct tk8/boot8 test shortcut exists on the production wrapper.

The composition has zero parent flops. Ten clock entries belong to the five control/prompt leaves, four packet leaves and raw command station. `physical/qkd_host_control_compose/machine.json` lists exact machine ports, child instances and measured root sinks. The packet parent total16510 FF is distributed across four independent roots; no root exceeds15000. Physical pins, clock insertion/spread, routed timing/DRC, child lint, die hop reach and immutable-price throughput remain unverified. In particular the baseline prompt q3 source has an observed macro-to-ECC CTS failure; this functional composition does not accept that view.

The source has four initial command credits. `source_cr` returns one credit only after all seven remote copies have been emitted. `available` is registered advisory information and cannot authorize a same-cycle launch. Producers reserve capacity beforehand and count engine events as well as metadata. Original start38, PW113 and DW181 pulses on one edge form one indivisible182-bit event and consume one credit. Metadata should preload before ring enable or explicitly coordinate with an engine event; arbitrary unlimited metadata streaming alongside autonomous engine starts is outside this bounded contract. Violations raise `source_fault` instead of silently dropping events.

The exact bench uses seven real original CTRL endpoint instances. The board model routes actual addressed command packets and peer-generated status packets through the master HOST/CTRL class plane, returning physical and logical credits independently. It proves original FMT1 descriptor/DMA prompt/CQ semantics across12 steps and three2-bit generation wraps, with die7 deliberately undrained for600 cycles on every step. Genuine transported die7 boot-done blocks readiness. Every peer checks the complete raw command against the source event, including three standalone PW+DW events and a fourth PW+DW event coincident with the first start. Exactly15 commands and15 credits return; ten CQ entries and IRQ are checked bit-exactly. A separate full wrapper at role7 remains silent and cannot run an independent package controller.

The undrained mutant reports die7 drained early and must fail the premature-next-start assertion. The payload mutant corrupts one hc bit and must fail exact local/remote command comparison. Gate scripts require explicit expected exit statuses; their regression selftest demonstrates that unexpectedly passing mutants are refused. Source snapshots and authoritative remote logs bind the evidence. PHY/CDC, native metadata producers, all-die physical composition and production throughput remain separate gates.

The separate qkd_host_control_packet_capture/qkd_host_control_prompt_capture variants bind the exact capture256 prompt candidate from ea338634f with PROMPT_READ_LATENCY=4, PB_READ_PIPE=5, and fault latency5. Baseline modules remain unchanged. These variants are functional candidates and do not adopt a physical view. The native priced production composition and die phase/pin/routed gates remain required, even after independently measured balanced-spine clock results.

The candidate gate repeats the entire real ND8 transport/FMT1 ring with a single physical macro cell error corrected. It adds double-ECC UE through the same actual HOST/CTRL composition: sticky fault at cycle1010 precedes host request1012 and sampled controller request1013, both seeing qualified-ready0; controller launch count stays0, masked IRQ asserts and CQ reports fault00000000cafe0075. All metadata still reaches all peers and all reserved command credits return. Mutants separately break die7 drain, raw command payload, ECC correction, the response pipeline, the host latency binding and fault qualification; each fails. Exact snapshot hashes and authoritative remote logs bind both positive workloads and all six failures. The parent remains zero-flop with the same ten explicit clock entries.
