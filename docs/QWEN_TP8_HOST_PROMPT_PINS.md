# Actual physical prompt storage at registered pins

`qkd_host_prompt_pins` captures all request inputs at the leaf pins before the original `ot_qfd_prompt_sram` encode, lane/mask selection and SRAM address/control. It registers the decoded18-bit response and sticky fault at the output pins. Production RTL instantiates the original SECDED wrapper and actual physical `ot_sram_1r1w_1024x256_m2_r2c2`; it contains no substitute prompt array. Eight24-bit ECC codewords occupy the low24 bits of each32-bit lane, preserving the real256-bit masked-write macro and all8192 tokens.

After a request is sampled at a rising edge, input capture adds one edge before the macro's synchronous read, then the output register adds one edge: decoded q appears at the third edge, counting the request edge as the first. The original sticky UE fault stage followed by the output register appears at the fourth edge. Disabled reads hold the last q. Reset clears request controls and the response/fault pins; stored tokens retain original macro semantics.

The host binding must set `PROMPT_READ_LATENCY=3`. The hardened host adds its own request/response station edges and uses `PB_READ_PIPE=1+PROMPT_READ_LATENCY`. The actual macro ring fixture proves this binding through the actual class0 HOST packet plane, original FMT1 descriptor/CQ fields, three18-bit prompt IDs and token feedback. A real physical array cell error is injected into the first stored codeword and corrected during that ring. Package boot/tk status remain independently modeled in this fixture; CTRL/PHY full-package composition remains separate.

The unit fixture writes/reads all8192 addresses, checks simultaneous read-before-write collisions and masked lane preservation, and exercises every single-bit correction and every double-bit error in all eight lanes at the actual macro output. Both unit and packet fixtures have payload corruption, shortened response latency and disabled ECC-correction mutants.

The physical macro is174.744×70.470µm. The requested220.08×110.04µm outline,5.4µm halo and M5 cap are unverified requests for the die tools, not a slot-fit or timing claim. There are67 external pin bits, one logic clock entry and one macro clock pin. Measured black-box-macro synthesis finds71 logic flops, so the root has72 sinks including the macro clock pin. `physical/qkd_host_prompt_pins/partition.json` records inventory and residual gates. Existing original prompt views are untouched. The new master remains physically unqualified until die-assigned pins, actual timing/DRC, clock evidence, child lint and immutable-price throughput are proven.
