# Actual static HBM quadrant composition

`ot_hfd_coll_q_static` and unique wrappers `ot_hfd_coll_q3_static`/`ot_hfd_coll_q2_static` instantiate the actual native program issuer, two-root quadrant switch, 17-root arithmetic ring, fixed VM writer, and three/two native545-bit SRAM/CRC link codecs. The q3 wrapper also instantiates the actual KMAX2048 static TOPK engine (32 tile roots plus buffer and control); q2 has no TOPK operation and faults if its program attempts one. No legacy on-chip credit path is instantiated. The reserved source/sink positions in the reusable qslots encoding are invalid ISA entries and fault if used; actual RC/return data use separate SU pins.

The interface is a **new compiled-program entry**, `hgi_start/hgi_start_pc/program_cfg`, with separate busy/done/fault outputs. It is not a decoder for historical968-bit collective records. Binding the normative command producer/compiler and full production programs remains required, and the die must remain unqualified until that entry is joined. `static_uop_layout.json` defines all bitfields. Every undefined word is masked only by issuer `uop_v`; sticky faults never postpone normal issue. Reserved bits fault. Loop iteration offsets are actual RTL arithmetic. Link slot offsets are checked at extended width before truncation, so crossing slot63 faults instead of silently wrapping an epoch.

The parent has one explicit `clk_control` root for pin requests, fixed metadata pipelines, VM response assembly and fault checks, in addition to the73 q3 or34 q2 child roots: **74/35 total**. Every root is a synchronous logical edge with independent physical clock delivery. The pre-build analytic model is `tools/uarch_model_hcoll_q_static.py`; root sizes, physical slots, clock insertion, area and die timing still require measurement. No qualification is inferred from this source composition.

SU request pins are registered. A request launched at P has its source payload captured by qslots at P+12; the external SU must supply the actual512-bit answer before that edge. The two33-bit metadata words follow the same fixed request pipeline. Each metadata low16 and injection index adds iteration*index_step; each of four40-bit injection address segments adds iteration*address_step.

VM requests expose the actual136-bit read-group ABI (eight `{v,sector16}` tuples). Responses are the actual2056-bit ABI (eight `{v,data256}` tuples). Request launched P is sampled by the external bank at P+1; its real response register changes P+7; parent pin capture P+8, explicit low/high bank selection and512-bit assembly register P+9, qslots capture P+10. Metadata and pair selectors follow that exact pipeline. Pair selectors with equal bank indices encode an unused assembly lane; they produce no source valid, and attempting to capture that lane faults in qslots. Distinct selected banks must have matching valids. The complete eight-bank actual arrival bitmap must match the delayed request bitmap. The die must bind a real allocated COLL read group (SW/SE group3, NW/NE group5 under the current H-VM decision), including its static ownership; the parent creates no new SRAM port.

Qslots captures source at C and launches selected destination after C+2. The compiler's sink selection command at C+1 refers to source C. Native digital links retain TX3/RX1; PHY/package latency is external. Writer low/high launches retain C+1/C+2 from writer capture; SRAM commit remains H-VM's contract. VM mirror kq writes update only the local copy; a real fixed-cycle collective distribution must update all required mirror copies. The component writer alone does not replicate them.

Issuer halt produces `hgi_done` on its fixed program edge. The compiler must place it after all required bank commits, link drains and deliveries; it is not a dynamic drain condition. The TOPK done pulse is checked against the explicit `tkm_done_slot` calendar. Protocol, arithmetic, writer, source availability and link faults are aggregated as observations. No fault check repairs the timeline.


Delivery base addresses and RGX writer addresses are computed and registered in the parent protocol root. An address word executed at edge C changes the address register after C; a synchronous consumer samples it at C+1. The compiler must put RGX address words one edge before the corresponding writer ingress reservation; delivery address words similarly precede SU consumption by one edge. These registers remove arithmetic from the producer's physical face. This adds320 declared protocol-root register bits; the complete analytic root bound is7,231 bits for q3 (7,223 for q2), below15,000 but still requiring synthesis/CTS evidence.
