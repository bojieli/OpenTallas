# V3 native pin-registered quadrant candidate

V3 preserves the frozen V1/V2 files and their source-pinned evidence. New modules are `ot_hfd_coll_q_static_v3`, `ot_hfd_coll_q3_static_v3`, `ot_hfd_coll_q2_static_v3` and `ot_hgi_coll_q_static_ctl_v3`. Native computation, program ISA bit positions and source/sink ownership match V2. The actual endpoint child changes to `ot_hgi_coll_static_link_pinreg`, with actual registered controller and SRAM-store faces fromcc12ab88a. No wrapper substitutes a PHY or a store. Every endpoint still has five clock roots and the same612-bit digital pin ABI.

The endpoint read reservation at C now produces the physical TX frame after **C+5**; RX capture at R produces registered payload after **R+1**. The compiler must move the read reservation two edges earlier relative to V2 when preserving a physical TX launch. Sequence metadata must still be emitted one edge before the read/write/receive reservation that consumes it. Native program generation must preserve the real64-slot SRAM ownership lifetime and the new write/read pipeline, not only subtract two from the read number. The endpoint transport proof prices actual613-bit framed transport over its487-bit beats; full parent programs must adopt that measured schedule before production qualification.

Each endpoint's mapped controller has3,201 FF bits; its four mapped store roots have597,597,597,567. There remain108 clock entries on q3 and68 on q2. The expanded qslots output roots retain their measured14,824/13,727 FF counts. These counts do not prove CTS insertion/spread, die timing or slot fit. The pre-build model is `tools/uarch_model_hcoll_q_static_v3.py`.

V3 additionally exposes nine actual issuer feedback bits for the host program assembler: `issuer_busy`, `issuer_fault`, `issuer_uop_v` and `issuer_uop_pc[5:0]`. They are direct wires from the actual native issuer, with no hierarchical test access or invented status. Program halt remains an explicit static instruction; compiler drain rows must cover all required outputs and responses. Host-binding wrappers and host assembler proof are separate deliverables.

This is a new candidate logical composition. Existing native V2 ARGMAX/reduction/VM mechanism proofs retain their original scope and do not by themselves qualify V3 link timing. V3 native q2 elaboration and the endpoint's separately source-pinned TX5/RX1 proofs are required together; q3 full current-source operation, production compiler timing, physical closure and end-to-end throughput remain open.
