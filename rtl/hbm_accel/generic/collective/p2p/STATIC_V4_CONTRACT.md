# Native static quadrant V4 candidate

V4 instantiates the actual ALL-input-capture `ot_hgi_coll_static_link_capture` endpoint. It keeps the V3 issuer, program assembler, registered protocol leaf, qslots, ring, reduction, ARG, writer and TKM connections. V1/V2/V3 source and receipts remain independent.

The generic and q3/q2 interfaces match V3, including the nine direct native issuer feedback bits. The host wrappers retain physical QID, raw HOST target 52+QID, and the proven native assembler. The assembler root captures aggregate fault one additional edge; fault reporting never changes normal reservations. The ISA remains 1536 bits with identical field positions; the versioned layout carries the changed timing contract.

For a link reservation sampled at E, TX publication is E+6. An incoming digital RX pin sampled at E publishes RX at E+2, and a directly connected qslots source captures it at E+3. The raw write reservation at E reaches the actual native SRAM write at E+4; compiler slot lifetime checks must include that visibility. Full sequence arithmetic is prepared in the protocol leaf one edge before the corresponding reservation. Every external endpoint command, sequence, data, epoch and PHY-up input is captured before guard forks. V3 TX5/RX1 calendars require explicit recompilation; no V3 throughput receipt applies to V4 automatically. Wire flight, physical relays, FEC and CDC costs are additional compiler obligations.

Each actual endpoint has the same five clock entries: controller plus four real SRAM stores. The measured controller inventory reported by its owner is 4421 FFs; store roots retain 597/597/597/567. The quadrant has 108 SW or 68 other-quadrant logical clock entries; adding the native HOST assembler makes 109/69. These are explicit source entries, not physical clock-tree qualification. The qslots output inventories remain 14824/13727 FFs; adding input capture leaves that root unchanged. Area, pin placement, clock skew, TT setup and FF hold remain unqualified.

`check_v4_binding.py` compares the complete normalized V3/V4 generic and host RTL: permitted changes are versioned names and the actual endpoint module. It also checks unchanged field maps and every first input capture. The source-bound native q2 HOST/reduction gate instantiates the real program target, issuer's three program SRAMs, full q2 parent and endpoint SRAM stores. Declared SU input vectors are supplied at the documented INJLAT12 boundary. It proves HOST assembly/start/feedback, source routing, native FP32 reduction and exact output/finish cycles. Wrong-source and shifted-add-issue mutants must reject. The endpoint is idle in that workload; its TX6/RX2 traffic evidence belongs to the separate actual endpoint gate, not to this host/reduction test. q3/TKM flattening is deliberately excluded from this selected qualification; production parameters are unchanged.

The actual digital endpoint/FEC finite-window end-to-end component receipts `1b3f1c2bb` (parent `7213927bc`) and capture endpoint `f7280c70d` (parent `581ee44e1`) describe typed boundary evidence. V4 exposes the native 612-bit registered frame and validity pins for that composition. This change does not instantiate a PHY, hide a rate adapter or claim an integrated FEC/physical parent. Board flight, exact FEC/CDC epoch/phase/calendar and full native programs remain open.

Reproduce the selected gate with `HCOLL_ROOT=<checkout> bash rtl/hbm_accel/generic/collective/p2p/run_q_static_host_v4_reduce_bench.sh <output>` through `ot-run`. Run `python3 tools/uarch_model_hcoll_q_static_v4.py` before building, and `python3 tools/hbm_coll_static/check_v4_binding.py` for the reviewed source/ISA binding.
