# V2 native HBM quadrant

The new `ot_hfd_coll_q_static_v2`, `ot_hfd_coll_q3_static_v2`, `ot_hfd_coll_q2_static_v2` and `ot_hgi_coll_q_static_ctl_v2` leave V1 source and its frozen proof unchanged. V2 instantiates the actual native 16-lane FP32 reduction/BF16 publication engine on33 independent clock roots and the actual native ARGMAX fold on one additional SW root. Physical frames are612 bits per rail, including CRC-protected full16-bit sequence. The registered sequence controller is the real HBM specialization; TX3/RX1 is unchanged, with no PHY substitute or normal credits/backpressure.

The q3 wrapper has108 physical clock entries; q2 has68. New ports are `clk_reduce[32:0]` on both wrappers and `clk_arg` on q3. Actual reducer control is root0, state lanes1..16, add lanes17..32. The expanded qslots source list is SU0/1, rails, VM0..3, reducer, ARGMAX. The q2 ARGMAX position is an explicitly unsupported ISA position and faults if captured. The final sink is the actual reducer input. Reduction and ARGMAX have separate registered producer faces; there is no data mux between them.

`static_uop_layout_v2.json` defines the packed fields. Native ARGMAX and TKM share four sink positions under an explicit static mode. In ARG mode the TKM valid/slot bitmap is zero. Unsupported operations, simultaneous starts and an issuer halt while either operator remains active fault without changing the production calendar. Arithmetic inputs, outputs and publication slots are checked by their actual child controllers.

Full sequence words are `{high10,low6}+iteration*iter_link_slot_step`, calculated at40-bit width. **The compiler emits each sequence word one edge before its endpoint wr/rd/rx reservation.** The protocol leaf registers all16-bit sequence fields and their overflow flags. An endpoint reservation sees the prior word's registered sequence; an extended value >=65536 faults at that reservation edge. The endpoint independently checks monotonic full identity and native64-slot ownership. Publication, read and receive reservation bits themselves keep their existing edge; only sequence metadata is prepared one edge ahead. There is no implicit epoch drain at sequence64. Epoch recovery remains exceptional and unimplemented at this parent boundary.

Existing SU/VM metadata, address, request and native assembly timing remains unchanged. Reducer load/add-read consumes the final qslots sink at its reserved edge. Add issue follows add-read by exactly one edge; publication issue follows publication-read by exactly one edge. The actual reducer's registered result becomes a distinct qslots source. ARGMAX flush-to-registered-publication remains six edges, after which its result is independently captured by qslots.

Before building this source, `tools/uarch_model_hcoll_q_static_v2.py` records its analytic budget. Actual Yosys process conversion and optimization measured qslots output-root register bits at14,824 for NS11/ND16 and13,727 for NS10/ND15. Both satisfy the15,000-sink count rule; routed clock insertion/spread, area, physical slot, pin reach, die timing and production token rate remain unqualified. This measurement is a register-bit count, not a CTS result.

The native q2 reduction gate programs actual1536-bit issuer SRAM through its real37-bit configuration bus. Declared SU-boundary stimuli supply two512-bit FP32 operand flits at INJLAT12. The real qslots/reducer/qslots path produces16 exact FP32 sums at start+34 and the issuer halts at start+38. A wrong source selection and a late arithmetic reservation each fail. Both612-bit native endpoints, all17 ring roots and the actual issuer remain instantiated; idle inputs are declared component-boundary stimuli. This gate does not qualify a full G96 collective, the normative host record assembler, SW TKM/ARG integration, PHYs or die closure.
