# HBM545 static digital link boundary

`ot_hgi_coll_static_link` specializes the existing native `ot_qwen_static_slot_link` for the 545-bit HBM rail, with CRC32 and 596-bit framed digital wire pins. It does not instantiate or model a PHY. Historical PHY and credit-based link components are preserved. This component bench does not qualify a licensed PHY, physical bandwidth, full collective, or die timing.

The shared source is unchanged and pinned to revision `4c66b6a95`; `static_link_sources.json` records exact Git blobs. The bench extracts these blobs into its temporary build, including the real 64x512 SRAM macro functional model. Four independently clocked native SRAM leaves each hold one 137-bit slice of 64 flit slots. Unused high payload bits are padded; no C++ array, latency-only store or computed reference payload supplies DUT data.

The compiler reserves `wr_v/wr_slot/wr_flit` publication, verifies the producer with `wr_observed_v`, and reserves `rd_v/rd_slot` transmission and `rx_expect_v/rx_expect_slot` reception. A publication cannot overwrite a live slot or collide with an in-flight read. Read ownership cannot consume absent or already consumed publication. Frame identity is epoch8 plus slot6, protected by the same CRC32 as the complete 545-bit payload. The HBM wrapper additionally requires transmit-read and receive-expected slots to progress monotonically from zero through63, once per epoch, with no wrap. A repeated, skipped or exhausted slot sequence faults. This bounded sequence identifies each frame uniquely within its epoch.

The shared native path has exact **TX3** latency: a slot read reserved at rising edge C changes registered TX pin frame after C+3. **RX1**: digital RX pin capture at R changes checked payload after R+1. CRC32 uses the actual masked-parity RTL, IEEE polynomial0x04c11db7, all-ones initialization, MSB-first, no final complement. The independent bench serial CRC checks every valid transmitted frame. The digital wire delay is supplied explicitly by external bench stimuli; the production compiler must use the actual PHY/package latency and clock phase. Neither PHY readiness nor acknowledgments move a normal issue edge. Shared core observes PHY down as an epoch fault.

RX expected/present mismatch, CRC corruption, epoch/slot identity mismatch, publication ownership faults or sequence violations assert sticky `epoch_abort` and `retry_requested`. The latter is only an **exceptional recovery request**, not an implemented retry, replay or automatic restart mechanism. The shared codec aborts normal traffic after its own faults; wrapper sequence faults suppress checked delivery. No normal credit, ready, demand arbitration or runtime stall exists. Recovery requires an explicit compiler/link-control drain and a new `epoch_begin` with a new identity; drain duration, stale-epoch exclusion, physical retry and system restart remain unimplemented/unqualified here. Reset or epoch begin clears sticky faults. Epoch identities must not be reused while old frames can remain externally in flight.

`tools/uarch_model_hcoll_static_link.py` was written before this wrapper and before its build. The analytic budget is four64x512 macros (131,072 physical storage bits,34,880 usable payload bits), five clock roots, 2,335 input/output pin bits, an estimated control-root upper bound of2,533 sinks, and four431-flop replay leaf wrappers. The CRC estimate is at most36,032 XOR equivalents for TX+RX, before synthesis simplification. One reserved frame per cycle carries545 payload bits on596 digital wire bits (51 bits overhead,9.36% relative to payload). SRAM macro area plus actual mapped logic area, assigned slot, route cut/reach, clock insertion/spread, PHY capacity and production throughput cost remain unknown. No physical qualification or area fit is claimed.

`run_static_link_bench.sh` checks two epochs of64 frames in both directions,256 exact full-width receives, fixed TX3/RX1 timing, and serial CRC. It uses a declared external five-cycle wire stimulus. Negative controls include wire bit corruption, expected slot/sequence mismatch, real SRAM leaf corruption, late wire arrival, missing publication, overwrite/read collision, missing producer observation and a missing wire frame. Protocol faults must abort and request exceptional recovery. The SRAM corruption mutant occurs before CRC generation, so only the independent payload scoreboard can reject it; CRC cannot detect an internally corrupted payload that is subsequently framed correctly.
