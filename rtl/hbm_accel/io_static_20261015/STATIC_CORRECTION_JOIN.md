# Opt-in static-correction PHY512 join

This profile substitutes the symbol-owned static correction decoder from source `59d0a3335` into the actual current core/FEC/PHY512 composition. It preserves the frozen production candidate `ot_hbm_core_fec_frame_link` and its `ea849baca` proof. The opt-in API is `ot_hbm_core_fec_frame_static_correction_link`; its ports and clock indices match `CORE_FEC_FRAME_API.md`.

`hfd_serdes487_static_correction_window` instantiates `ot_hbm_kp4_dec_static_correction`, the actual static correction leaf and unchanged linear Chien map. The separate `hfd_serdes487_phy512_static_correction_window` retains real serializer/deserializer banks and 512 physical pins. The two external finite487-bit CDCs, compiler-stepped613/487 transport, native SRAM/CRC TX6/RX2 endpoints and all numerical clock controls remain actual RTL. No internal golden compute or memory substitution is added.

The exact finite calendar is unchanged: core period833.333333ps, FEC period885.416667ps, ratio16/17, 2048 words, measured151 FEC-edge input-to-decoded capture. Endpoint acceptance, SRAM write/read offsets, decoder capture, internal window, external CDC and endpoint publication use the same expressions as the baseline. This does not adopt the separate116-edge streaming candidate. `profile_difference.json` verifies identifiers/decoder class are the only changes in the three wrappers and complete joined bench.

Run `tools/hbm_io/run_core_fec_static_correction_gate.sh OUT 0` for the positive and four boundary negatives; use argument2 for the actual Forney mutant. The numerical positive must match234 payloads,66 idle reservations,2048 decoded and2048 internal-window words on their exact cycles. The positive already injects physical-pin bit errors periodically and requires exact correction. Source SHA256 bindings are in `static_correction_join_provenance.json` and the result receipt.

This is a numerical opt-in proof, not physical adoption. Same-family clock ties in the bench do not establish routed root phases, MTBF, clock insertion, pin timing or a full-system rate. Do not inherit the standalone decoder or FEC root/sink counts into this joined hierarchy. Physical partitioning and mapped inventory are owned separately by the FEC physical prebuild stream.
