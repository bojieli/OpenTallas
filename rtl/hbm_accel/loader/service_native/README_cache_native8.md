# Packed136 eight-slot assembler candidate

`ot_hbm_svc_static_sm_packed136_native8` is an opt-in component successor.
The historical source is unchanged. `PACKED136=0` remains disabled by default;
`MUT=0` is the production candidate, 1 and 2 are bench negative controls.
The five existing 128x256 SRAM payload row-cache macros and their ports are unchanged.

The pre-RTL model was committed at 848e5cb84 before the candidate RTL.
Every legal open_count (1..64) starts slot_phase=0 and record_phase=0 in the
unchanged protocol. Exhausting those 64 deterministic schedules proves the
payload live bound of eight sectors (2048 bits), including the padded final
128-byte group. Other absolute clock phases only translate this schedule.
No padding sector is discarded early. The assembler consumes 4,4,4,5 sectors
per four 1088-bit rows while the source supplies 4,4,4,4,1 per five edges.
The first row uses old data after the two-edge initial fill.

The old ring held 16x256=4096 runtime payload bits. The candidate holds
8x256=2048, exactly the authorized eight-sector bound. A row gathers five OLD
slots before NBA writes. A push can reuse a slot consumed on this edge;
duplicate detection therefore checks `present && !popmask`. The ownership
update is `(present & ~popmask) | pushmask`, so the incoming sector wins.
Blindly changing modulo16 to modulo8 or letting pop win loses live sectors.
All equality, row-valid, ownership, identity, read, retirement and fault
logic remains the original logic. Tag/epoch values do not influence addressing
or this live bound, so the schedule proof applies to every legal identity.

There are zero added row-write, ready, SRAM-read or packet cycles. Sustained
four rows/five edges and ingress 17 sectors/five edges remain unchanged.
Input bandwidth is up to 1024 bits/edge; gather is 1280 bits into a 1088-bit row,
then five existing 256-bit SRAM write ports. The ring selector drops from
16:1 to 8:1 for each of the five gathered sectors. One assembler per SM and
16 per die saves 2048 payload flop bits/SM (32768/die); the 1280 tag bits,
valid bits and control registers remain unchanged. No area or rate credit is
claimed before mapped results. The existing model reports physical status OPEN.

The component bench compares candidate against the unchanged original on
EVERY edge: control outputs, valid packets, actual row SRAM write enable and
1088-bit write payload. It additionally compares the historical general
assembler and checks independent generated byte-pattern packet goldens.
All 64 counts run in both banks, with varying epoch/tag bit patterns including
tag wrap, cross-bank reads during loading, retirement immediately followed by
reopen, reset with a just-open transaction and reset with eight sectors live.
Seven invalid-input classes check sticky faults. The exact count and cycle
measurements and both mutant failure witnesses live in the evidence directory.
Wrong-slot gather (MUT1) and pop-wins recycle (MUT2) must fail equivalence.

Physical qualification remains OPEN. This patch fixes the runtime payload
storage violation only; it does not claim safe registered pins, reset landing,
kept control fanout, <=405um reach, mapped mux depth, floorplan utilization,
clock spread or route timing. No gate/REVIEW/submission has been attempted.
A parent must retain its native registered regional boundary and audit this
assembler in the actual hardened row-cache context before adoption.
