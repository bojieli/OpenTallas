# Real96 SUM integration contract (candidate, not adopted)

The existing eight-rank tree supplies raw FP32 words from `lvl[LV][0]` together with its issue index. A real96 command routes all twelve contiguous groups' raw512bit partials, with a subgroup ID0..11 and a tile ID0..15, to the final reducer owner. It MUST NOT consume existing BF16-packed delivery results. Generic ALL_REDUCE_SUM packs to its output format once, after the new final tree. GROUP_REDUCE_MCAST retains its separate released behavior.

Each subgroup owns one `ot_hgi_sum96_partial_bank`; its512bit payload is eight64bit SECDED chunks stored in576bits, three real128x256 SRAMs. Write command accepted at edge t is acknowledged at t+1, the actual macro write edge. Read command accepted at t yields a qualified decoded response at t+3 after the macro address pin register, macro read, raw output capture, and decode/output register. A UE suppresses response_valid and raises uncorrectable. CE is valid-qualified. Presence/tile masks are ordinary control flops, no protection duplication.

The command adapter must count each subgroup/tile exactly once, set presence only on actual write acknowledgement, reject duplicates/out-of-range subgroup IDs, launch only when all twelve tile entries exist, and reserve an output credit before issuing simultaneous bank reads. The final tree accepts one fully qualified twelve-bank snapshot per cycle and emits the corresponding512bit result28cycles later. The caller must carry tile index and command identity across that28cycle latency, prevent completion until all16 tiles are consumed, and drain all requests/results before rearming. No endpoint producer or finite-credit adapter is claimed by this child module alone.

The literal rank tree is96→48→24→12→6→3→2→1. The third surviving subtree at the3→2 level is delayed without arithmetic. U2 converts any final signed-zero result to+0. These are candidate numerical semantics pending hbm-sim's normative vector confirmation. Independent repositorygolden tests establish the arithmetic mechanism, not full generic-record conformance.

The initial serial96 controller is retained only as MODEL_REJECTED history; it is not a route target. Two final-tree+protected-bank current-flow variants are intended after the fullshape synthesis inventory, grownslot pin spread, real macro hierarchy, floorplan lint, and producer binding pass. Neither an inferred-memory stand-in nor UNIT area estimates establish physical closure.
