# Conditional common-reset copy theorem proposal; no helper adoption

The actual HOST request/ack source copies are separate kept state registers. Their Q values may differ at arbitrary initial state. This packet does not alias those initial Qs and does not change the shared CDC helper. The original source protocol requires reset assertion before functional traffic/first valid; an adopter must establish that contract and may use equality only after the shared actual asynchronous reset has asserted.

Actual generated-source signature inventory in witnesses/actual_signature.json establishes eight copies (four req_copy, four ack_copy). Each canonical/copy has the same actual D bit, clock bit, asynchronous reset bit, and $_DFF_PN0_ type (edge/polarity/reset value). Four source mutations in independent copied source roots change D, clock, remove reset or change reset value; all are refused by the same actual elaborated signature validator. Literal signature tests also refuse tied reset. This is proof input closure, not a claim that the current unmodified CDC checker accepts the duplicates.

Source-RTL formal theorem uses independent arbitrary initial Q0/Q1. With shared real asynchronous reset asserted, both output states become the same reset value. On every subsequent common clock edge the identical D gives equal outputs. The induction property is qualified_equal = !reset_seen || (q0==q1), with reset_seen a verification-only monitor initially0; DUT Q states have no initialization assumption. SAT temporal induction proves this conditional property for all time. The first-valid five-step coupon asserts reset atstep2/releases3 and proves equal fromstep2 onward. Removing reset assertion causes an equality counterexample; wrong D, wrong reset value and missing reset each cause real SAT counterexamples. Source clocks/type differences refuse before applying the theorem.

Independent RTL offphase simulation deposits Q0=0,Q1=1 before any clock and verifies they differ. It then performs100 offphase asynchronous assert/release episodes and600 first-valid/induction checks. This uses source RTL, not an imported sequential-cell behavioral model. Old ASR/HQN model issues are not assumed resolved.

Proposed bounded integration: an explicit reviewed HOST contract lists canonical and copy names plus the guaranteed reset-before-valid requirement. The helper verifies actual signature closure, refuses missing/tied/different reset, clocks, edge/type/value or D, and reports that the BDD proof is conditional on reset occurrence. No blanket Q canonicalization, no arbitrary-initial-state equivalence, no false/multicycle paths, no clock budget change. ROOT must review this conditional contract before any shared helper change/adoption. The independent PC SRAM batch does not use this theorem.
