## Checks (fleet, Verilator 5.050 / yosys 0.68)

- `test/lint_hd.sh`: Verilator lint of all three masters: 0 errors. The only warnings are in the reused lane source.
- `test/run_hd_ctl_bench.sh`: smoke bench `tb_s81hd_ctl`. The sequence is: CSR writes, 80 shuffled tagged XB beats, then the
  bus B stream (go + null best). Every slice m = 0..8247 is checked at G+5+m on both spines, together with the exact xv window.
  Fake N/S returns follow, then BEST frames on the 6 mesh lanes and fake peers, then the merged token through
  `dsfd_mtp_seq` to ro (K_TOK) and the host RESULT frame. There are 2 positions: a strict win, and an all-equal tie (+0/-0)
  that the lowest id wins. Results: base PASS. Mutants SLICE and TIE both FAIL as required (fail witnesses in `test/witness/`).
- `test/hd_census.sh`: yosys parse + `hierarchy -check` per master, then the pre-gate native census
  (`tools/ref_tile/native_census.py` from origin/main, ASAP7 RVT TT) on the ABC-mapped netlist. Hard children
  (macros, lane tile, lep_mu_ab, mu_land, dsfd_mtp_seq) are black boxes with port-derived abstract Liberty cells.
  The numbers are in the census section below.

The first census run failed. These fixes made it pass:
- 16-bit hold groups (`ot_s81hd_hreg32` has 2 enable copies);
- 16-bit lane slices with kept tx_v / lo_r pin copies;
- `ot_s81hd_pick` (one compare, 4 kept decision copies) in place of duplicated compares;
- a sign-safe compare, so the sign net does not fan out across the word;
- kept CSR, tag-FIFO and HFWD enable copies, plus a grant-receiver pin stage.

Mapping used `physical/common_flow/ot_keep_regs.tcl`, as the gate synth does.

## SAFE review (8 points)

1. Pins: every ctl input lands in a pin flop and every output leaves a flop. Lane: tx_v / lo_r pin flops sit in every
   slice, and rx leaves pin flops. Reset uses `ot_rst_relay_tree3` (root + group = 2-stage landing, leaves <= 32 pins).
2. Reach: these are block masters. ctl <-> lep and ctl <-> lane crossings are die-level land-plan rows (HD-CHAIN).
3. Fanout: wide holds use `ot_s81hd_hreg32` (a landed enable copy per 16 bits). Wide selects use `ot_s81hd_kf` kept copies
   (17 per ro select, 8 per stream slice select). Compares use `ot_s81hd_pick` (one compare plus kept decision copies). The census gives the numbers.
4. Depth: one compare or one 4:1 mux level group per stage. The merge is a 2-level registered tree with 2 edges a level.
5. Storage: the x store is in SRAM macros (80 kb). Flop holds are each < 2 kb: the lane buffer is 1,659 b and the host
   HFWD hold is 512 b.
6. Floorplan: owned by HD-FP. The ctl has about 15k signal pins (13 lanes x 1,108 + 2 x 1,130 bus B + 2,280 ring).
7. Clock: one region per master. The 80 ps rule applies inside the region.
8. Schedule: static. Flow control exists only in the lane adapters (off-die credits) and at the `dsfd_mtp_seq` grant
   pairs, which are fed by the static schedule. Overflow conditions are sticky faults, never stalls. The added cycles are:
   - lane: TX tx_v -> lo_v 5, RX +1;
   - ctl: ri -> x write 2, start -> go 3, forward ri -> ro 7, N/S fire -> BEST frame 5, merge fire -> RESULT 6.
