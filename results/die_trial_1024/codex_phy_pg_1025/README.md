# Regional CORE/PHY PDN and explicit PG pin prototype

`gen.py assembly PLAN --views VIEWS --pg-map MAP.json` opts into disjoint supply meshes. The map is `{ "instances": { "part": { "VDD": "VDD", "VSS": "VSS", "VDDPHY": "VDDPHY" } } }`; existing same-named exposed PG pins are inferred, with the map used for explicit overrides. Every mapped pin must actually exist and expose M7 geometry. Every declared PHY domain needs intersecting VDDPHY pin metal, and CORE VDD pin metal is forbidden inside it. Missing pins stop before assembly output, as the committed negative record shows.

`gen.py mockview PLAN --out NEW_PROXY_DIR --planned-phy-pg` emits a **planned prototype** PG interface only where die_io maps the PHY region to the containing partition. It never modifies a released view. Replicated types must have identical transformed PHY regions; a PHY reservation erasing all CORE supply is rejected. Only the external M7 PG interface is exported, and M7 OBS is cleared at actual PG landing windows.

The regional generator takes the union of same-net overlapping PHY halos and emits its exact CORE complement. It uses one die-phase stripe pattern for all pieces. A mixed-containing macro needs contacts to more than one supply region: the native per-instance macro-grid connector fails with an empty grid on this case, while same-net sroute asserts in this OpenROAD build. The opt-in connector places the technology's actual VIA78 in2x2 arrays at real same-net M7/M8 intersections, checking full enclosures. An80nm cut-center pitch exceeds V7's32nm cut plus46nm spacing; four cuts satisfy the wide-strap multi-cut requirement. The assembly checks every exposed supply, and stops on a PG connectivity failure in this mode.

The committed physical smoke has12,480 actual vias, no cross-supply M8/M9 contact, and PASS connectivity on VDD/VDDPHY/VSS. The separate16-load PDNSim proof passes both power nets (CORE2.96mV, PHY0.873mV at explicit0.15W/mm²). Grid/pin pictures were viewed before the runs. All historical failed attempts are retained in the source host run directories; representative native-grid and sroute crash logs are included here.

The updated head PG metadata7cbf009cc generates16 planned views and326-part regional assembly with664 pin bindings (12 VDDPHY). This is a planned assembly check, not whole-die physical timing or G4 credit. Released views must implement the same real separate power interface before adoption.

To reproduce the physical single-macro pin smoke, copy `pin_edge_vias/` to a new scratch directory, review `pin_review.png`, then use `ot-run --mem 16 --threads 4 --dir DIR -- bash DIR/run_psm.sh`. Require `OT_DONE` plus all three `OT_PG_CHECK_OK` records and zero `OT_PG_SHORT_COUNT`; this OpenROAD version can return exit0 after an assertion, so the exit code alone is insufficient.
