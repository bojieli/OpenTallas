Persistent candidate mask and index-selection capacity is query rows, while

This selected address/reuse gate supplies external block-ID stimuli and does

Prompt driver: one bounded position-zero PREFILL, then single-token DECODE
continuations required by the released Compressor's start_pos>0 branch. It
reuses the same real device/session/persistent state; stages each current token
slice at HOST input element0; publishes no intermediate generated token; stops
on actual transaction failure. No host activation arithmetic, oracle callbacks,
state clearing or cursor fabrication. The false automatic_prefill_chunk_driver
field belongs to frontend specialization alone: execution is explicitly through
ingest_prompt. Multirow continuation is intentionally refused by source semantics,
not disguised as legal arbitrary chunking. This path does not claim bit equality
to a single large prefill's floating-point association.
