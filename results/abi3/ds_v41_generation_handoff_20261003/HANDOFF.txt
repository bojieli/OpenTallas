Choose this successor before prompt ingestion. It compiles ONE full released
40-layer/3250-kernel AR KernelIR program, retaining the SAMPLE SCALE/ARGMAX/
TOKEN_APPEND tail and exactly one set of objects, views and state descriptors.
This is not the distinct 2213-PC native program and makes no MTP claim.
It retains the archived graph's declared greedy boundary; stochastic Gumbel
sampling is not expressible by that graph and is not added by this successor.

The only operator control change is one explicit predicate on TOKEN_APPEND:
MAX_NEW_TOKENS>0. Intermediate prompt requests bind0 and do not publish tokens.
SCALE and ARGMAX still execute, so their work/rounding remains paid/unchanged.
Final prompt binds the positive source-clipped budget and appends directly from
the final prompt forward's actual logits. A13 SPAN_LAST_INDEX binds the emitted
LAST_TOKEN_SELECT index. Subsequent one-token decode forwards consume the token
already published by Device. No logits transfer, state copying, directory
rewrite, cursor fabrication, oracle callback or prompt-prefix replay.

Prompt uses one bounded position-zero prefill, then source-legal one-token
continuations. Device supplies all state commits, cursor/generation changes,
argmax, token append and EOS decisions. Driver stops immediately on failed
receipts and preserves prior successful commits/publications. Isolated session
memories remain isolated. The final published token has not been processed
into KV. Output context clipping follows the released generate loop's total
length min(context_capacity, prompt_length+requested_new_tokens); a full-context
prompt publishes zero tokens. This is not an extra out-of-context AR bonus.

MAX_NEW_TOKENS=0 is used only by this direct Device request API. Existing host
GENERATE queue admission requiring a positive generation budget is unchanged.
Generic compiler/runtime behavior is unchanged unless this additive API is used.
An already-completed old prompt-only deployment is refused, not silently
reinterpreted/migrated. No already-running checkpoint inference was rerun.
