# Future exported-clock prevention: native gap and bounded restoration API

The actual SPN_END producer uses OpenROAD 26Q3-1510-g6cb3f2b704. The pinned native sources at that revision were inspected; their git blob identities match the source tree. The original HOST first-bad4_1 and SPN_END B_p2 four gate-X output failures remain unchanged. The SPN saved-final-ODB audit is the sole native diagnostic; it subsequently confirmed four NULL A pins and three good controls. All seven drivers are DNT/LOCKED at final, but the audit does not establish their pre-CTS flag state, so that final-only observation is not an empirical test of pre-CTS protection.

Instance DNT is not a demonstrated prevention. `TritonCTS::writeClockNetsToDb` calls `disconnectAllSinksFromNet(topClockNet)` before constructing/reconnecting its clock subnets. That helper disconnects every INPUT ITerm and never queries DNT. TIMING-buffer inputs can also be excluded from sink enumeration; actual export source types have not yet been audited, so this is a source-level candidate mechanism rather than a proved per-pin cause. Reconnection operates on the builder's selected sinks. A DNT-only wrapper cannot promise that an explicit export input survives this sequence.

`repairClockNets` is later: CTS calls Resizer::repairClkNets, then RepairDesign traverses declared clock drivers. RepairDesign's collected input sinks omit DNT instances, and Resizer reads that flag from dbInst. Net DNT is not a safe substitute: the shared source tap also drives real register trees and may disable required buffering, while the earlier unconditional CTS disconnect remains. `removeBuffer` can clear instance/net DNT when its caller explicitly declines to honor protection. Those separate mechanisms prohibit a generic claim that either DNT flag protects an export through all CTS phases.

## Smallest concrete API for a future scoped experiment

Keep the future587 detector. Add an uninstalled, default-disabled private stage wrapper around precisely one native `clock_tree_synthesis` call, with the following state machine. This is an API proposal, not an executable hook or authorization to repair the current kits.

1. PRE calls the existing declared-export continuity checker. For each declared output, bind exact source/output BTerm identities, driver dbInst identity, positive-unate A→Y BUFx24 Lib function/profile, A/Y ITerm identities, original A dbNet identity, original Y/output dbNet identity, original driver master/pose/status and DNT bit. Require the original A net to be CLOCK and directly attached to the exact declared input source BTerm. Bind the original source BTerm net identity, source/clock/Lib/SDC hashes and the complete allowed output inventory. The snapshot records actual objects, not aliases inferred from leaf names.
2. Set instance DNT only for those exact export drivers for the narrow call. Leave all net DNT bits unchanged. This is optional secondary protection from Resizer resizing/buffering, not the claimed fix for CTS's disconnect loop. Save every old bit and own its restoration with `try/finally` semantics, including native failure paths.
3. Run the native CTS call once. If it errors or cannot reach a clean post-call boundary, preserve the failure and serialize no repaired result. No guessed recovery from a partially failed CTS is allowed.
4. Validate all snapshot identities before any connection mutation. For a connected A, require a unique real buffered/inverted fanin path rooted at the exact declared source and compute its Liberty polarity; keep a correct path unchanged. Reject a non-null wrong-root, ambiguous, cyclic or inverted path. Never force an existing path back onto the old source net.
5. A NULL A is eligible for restoration only if the exact saved original dbNet still exists, the exact saved source BTerm still belongs to that same CLOCK net, the same declared BUFx24/master/A/Y/output objects and Y/output connection survive, and the source net has the intended sole input root with noninverting source semantics. Restore only that A ITerm onto that identical saved original net. A missing/replaced source net, renamed object without identity, changed output driver or lost polarity proof refuses; there is no alternate root selection, leaf-name alias or nearest-clock fallback. Prevalidate every candidate row before mutating any one of them.
6. Re-run declared-export continuity and snapshot guards. Restore every original instance DNT bit before writing any checkpoint, leave all net DNT unchanged, then require actual legal pose/overlap and PG0. Any restoration or verification error discards the private result and preserves the negative fixture; no partial repaired ODB is eligible for use.

This restores a source-backed logical connection only. It changes the actual upstream load and may expose a long root-to-export branch, skew or CTS infeasibility. It provides no valid sender phase, insertion, source-equivalence or receiver reference contract. Geometry LOOK, source/clock policy review and separately scoped paired TT/FF timing are prerequisites to any later use. The old DRC/DRV/hold/parent failures remain independent holds.

A native alternative would add an explicit, source-bound preserved-input allowlist to CTS and exclude only those exact validated ITerms from its initial disconnect. That needs an owned native API/build and the same source-root/polarity/geometry checks; changing the global meaning of DNT for all clock sinks is outside this proposal. The bounded private wrapper above is the smaller reviewable vehicle and is disabled pending ROOT scope and exact native input/pricing.
