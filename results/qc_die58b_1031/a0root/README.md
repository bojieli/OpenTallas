# DIE-QC-58B: A0 NK/NL single tile-root clock gate (ICG=1), COORD 10-31 22:5x ruling (3) variant (B)

Base origin/main 26360778f5e. RTL unchanged: `rtl/physical/a0_core/qfd_tile_{nk,nl}_a0c.sv` are byte-identical to the
reviewed kit RTL. The design already has the DIE-QC-16 `ICG == 1` (`g_root`) form; this change only selects it.

## Why
DIE-QC-57d (lanes/DIE-QC-57.md 20:55): under ICG=2 (B-hop), TritonCTS balances 37 per-entry ICG hops against hard-child
insertion. The ungated `ck` face registers then land 100-170 ps after the gated body (best CTS knob set V3: NL FF hold
-108.47, NK at the declared frame -179.32, gate -100). With ICG=1 there is one gate at the tile root. Every body register
sits behind that one gate level, and the face registers on `ck` differ from it only by the root ICG.
