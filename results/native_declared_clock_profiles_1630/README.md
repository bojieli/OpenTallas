# Declared native clock profile PREP

This packet exports exact master-local, untransformed M5 rectangles from the actual generated io.tcl of eight separately generated E three-SRAM VMS views and one BFQG view. Each row retains its full original declared pin-contract SHA, canonical SHA, exact plan, source-manifest identity and independent io.tcl SHA. Main clock shapes absent from pins.json are read from the actual emitted pin_size command. The fields match mesh_native_contact.py declared-contract schema (94ebe1e31).

This is GEN-declared source-profile preparation, not actual hardened LEF, typed TT/FF, physical parent net binding or route qualification. Current G may have additional/different pin profiles; the E identities cannot alias a later profile with a shifted main clock rectangle, even when source/master/outline match. No coordinate is recovered from transformed parent targets. No actual mesh contact or source net is created by this packet.
