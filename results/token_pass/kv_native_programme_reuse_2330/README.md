The selected current native binding and the frozen GEN1 vehicle compiler binding have identical complete bus_groups.json bytes, including all member stages and metadata. The explicit comparison also matches all 12,740 landing rows by sink, source, sink port, lane, as-built depth and landed depth. The frozen kst.py run on the current binding returns the same seven KST ages, host round trip and embedding round trip used by the selected recipe.

The native R8 table publication at 7191a31ce therefore introduces zero additional cycles to this existing selected native programme. The table itself is not a direct replacement compiler input. Its sum of per-lane maximum pads is not a token-path incidence sum and must not be added to the programme or converted to a rate. No calendar, image, active job or model default changed for this result.

The surviving compiler uses kv_boot_v36.py prep with the actual binding, followed by compile with die_ages_bound_padded.json and relay_stages_bound.json. Its output remains COMPILED_NOT_QUALIFIED. Physical PC timing, production ROOT/HEAD and global data leases, and the real paired compute/KV host completion remain open. This receipt preserves the existing source gate scope and makes no full token or throughput claim.
