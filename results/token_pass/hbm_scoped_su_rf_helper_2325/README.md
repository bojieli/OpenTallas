# Scoped SU RF compaction helper

This is a source-bound helper for the HBM caller. It constructs unbooked native phase words and refuses scheduled emission without actual source-matched RF/stree/store/VM phase evidence. It is not ordinary HGI descriptor COPY, a DUT replay, a production lease or a performance measurement.

Selected d76 scoped pgslice uses QID0/G0, read return10, write return7, COLLPORT1 and RF_LOCAL1. The concrete fresh-reset candidate reserves delivery row510, output scratch row509, RF index255 and reducer scratch0. The low-half delivery address is0xff00. All16 delivery words must be initialized, and all16 output scratch lane words must be disposable. These reservations have component-only scope and were supplied by the HBM caller. The helper rejects out-of-range rows/indices/source offsets and destination words. It currently supports only the low-half G0 source and one eight-word destination sector.

Pinned storage and liveness prevent a direct cross-lane copy: lane L reads only its own store. Drain masks preserve eight positions. The helper therefore emits all-bypass source VOP with DST_NONE, selects the actual scalar through red_sel, LOADs reducer scratch0 and EXPORTs with tag0x1ff. The selected stree carries that scalar unchanged to RF255. Class0/SRC1 broadcasts RF255 through another all-bypass VOP with DST_VM into disposable scratch509. A native group0/port0 single-word masked drain places it in its desired dense position. The two initial scalar copies use source offsets0/1 and destination masks01/02, whose union is03. No mask rotation or two-word duplicated payload is used. Each scalar has its own real source/target copy and drain slots.

The source and API digests are in unbooked_templates.json. The control words use the actual staged su_arith_compile.pack and physical_word functions. Source construction checks independently compare reducer, RF and drain fields against existing su_top_compile.Prog methods. Those checks and five refusal cases are recorded in source_checks.json. They supply no measured issue/read/commit dates. Old compiler header timing does not transfer to current selected qcore/stree.

The HBM caller owns the sole native runtime/configuration/calendar. It can import templates(source_root, api_root) to obtain diagnostic phase words. The command-line interface requires --source-root, --api-root, --phasebook and --out. Phasebook schema opentallas.hbm.scoped_su_rf_phasebook.v1 requires exact source/API hashes, fresh_reset_component scope, null physical_epoch_mapping, matching component_reservations and a hash-pinned PASS measured_events JSON. Every scalar's command dates and actual hazard observations must appear in that receipt. Missing RF commit, matching class request, source ro_v at LOAD, reducer readiness, output scratch commit or masked VM commit refuses booked emission. The helper never fills missing dates from nominal delays.

The minimum dependencies are explicitly listed in unbooked_templates.json. Retain source data through source reads, reducer scratch through EXPORT, RF through target capture, and output scratch through drain sampling. The caller must measure these events and serialize reuse; this packet does not grant finite production lifetimes or whole-caller qualification.
