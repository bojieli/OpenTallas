These are SOURCE ledgers for the frozen821/f79 emitted ME collector and numerical
neighbor routes. They are separate from the passed nominal two-lane component.
No production provider phase, physical START date or global calendar is adopted.

The L6 ledger traces each region0 physical station input backward through exact
emitted registers, lane pads, literal top wires and CA crossings to its native
cluster root `n_y`. It checks all64payload bits per port for identical age and
preserved order. Native frontend projection bytes match the frozen WT. CA K is a
modulo64 count-frame translation, never an elapsed delay. Each route records its
source forwarded clock/start, receiver clock/start and literal strap. Explicit
register ages and sidecar added_cycles are kept separate and counted once.
