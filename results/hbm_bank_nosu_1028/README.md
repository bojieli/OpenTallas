# Explicit bank master without a local SU client

`hfd_vms_bank_native_q0_faces_nosu` is a distinct, opt-in source master for a memory bank whose calendar proves that local SU read/write client0 is absent. Its interface omits only `rq0` and `wq0`; all other clocks, pins, input-register stages, core and dynamic data paths are preserved. The original master remains unchanged. A sticky diagnostic ORs status[17] if an enabled read or write calendar slot selects absent client0; the check sees the exact existing clock_n face-register outputs. No data-path latency is added.

This is not an adoption or a claim that any production SU/MTP/MU calendar already proves client0 absent. The static compiler/absence-contract owner must accept the actual finite calendar and explicit build mode first. The master supplies no arbitrary producer mapping, time folding or additional SU slices. If the source programme needs local client0, this master is invalid and the missing producer must be resolved.
