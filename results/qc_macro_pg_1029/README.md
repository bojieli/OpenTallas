## Additive actual-source importer

`apply_joins.py` supplies `apply_joins(source_odb, direct_plan, bridge_plan, output_odb, seed_grid=None)` and a matching CLI. It preflights every actual native M7 PG enclosure, matching supply types, any existing binding, exact VIA78/VIA89 technology pads and every required physical upper-grid landing before creating any output. The default requires an already materialized canonical M8/M9 grid. Explicit `--seed-canonical-grid` is only for a scoped standalone source vehicle; it seeds required real canonical stripes and two real same-net anchor stripes, with legal VIA89 connections to make the selected grid connected. It never substitutes logical global connection for real metal.
