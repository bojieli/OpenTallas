## 2. Repeater leg-slide guard + placement root cause (tools/die_plan/die_trial.py, opt-in)
- Root cause (CHECKED, scripts/slide24.py on trial15, plan ev_qc23): all 28 repeaters > 50 um off-leg sit on region-DME
  legs that take their planned L route (`nd["route"]`, attach_region_dme) across an A0 hard core (+halo, 462 x 1162 um).
  The route is accepted because its blocked run (~466 um) is <= route_um 480. The middle repeater of the 504-um leg lands
  inside the core; `site.nearest()` moves it to the CLOSEST core edge in any direction, here sideways (146.8 um to the
  core's top edge; the x edges are 218/244 um away). No legal point exists on the leg within +-125 um (the core spans
  the leg), so a bounded slide would not help; the leg wire gets a 2 x 147-um spur the delay model never sees.
  Branch census: 28/28 'route/detour' legs, 0 straight, 0 snake. Not a blocked-site / cap-merge-point bug as such: the
  cap's re-embedded glue tree just creates more such routes; the stock tree has none (max 7.0 um, below).
- Fix (opt-in `--rep-on-leg`): a blocked repeater on a routed/detour leg slides ALONG its own planned polyline to the
  nearest legal arc point after its upstream neighbour (poly_slide), so the leg keeps its planned wire (no spur);
  site.nearest only if no legal point is left on the leg. Snake legs (explicit plan sites) unchanged.
- Guard (opt-in `--rep-off-leg-max UM`): the kit FAILS (ValueError listing count/regions/worst) if any leg repeater is
  placed more than UM off its planned leg (Manhattan distance to the leg polyline; a straight leg counts its bbox).
- Default off = byte-identical. Tests: test_die_trial_rep_on_leg.py (5: sideways slide reproduced + guard fails;
  on-leg keeps order/legal/no spur; flags byte-identical on clean legs and on the DIE-KV-2 slid-root detour fixture;
  off_leg_um; CLI). Full tools/die_plan suite: see section 6.
- Real geometry: trial24 (stock trial14 form + guard 50) PASSES the guard: 25,142 leg repeaters, max off-leg 7.0 um,
  0 > 50 (CHECKED, identical to trial14). trial15x = trial15 form (cap 1200) + --rep-on-leg + guard 50: see section 3b.
