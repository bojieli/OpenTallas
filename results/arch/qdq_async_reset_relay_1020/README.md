It requires mapped ASAP7 DFFASRHQN cells, one literal input clock, active-low asynchronous clear, inactive set tied high, exactly one constant-one first synchronizer, one second synchronizer, and one final regional edge. It checks the required inversion after every QN publication. Neither synchronizer can expose data, resets, or output ports before the regional edge. Raw reset can reach only relay clear pins; each regional output can reach only same-clock functional reset pins, at most 32 loads, and cannot be exported.
