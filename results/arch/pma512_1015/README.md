This candidate transports every bit using16 coded words ==17 physical words, no truncation and no invented pins.

`ot_hbm_pma_block_gearbox.sv` contains four8704-bit banks/direction, completion/consumption synchronizers, registered outputs and fault-only availability observations. Each read selects from four banks and16/17 slices: these large muxes and bank pin access are physical risks, not a closed tile.
