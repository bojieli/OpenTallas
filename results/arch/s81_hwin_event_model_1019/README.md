Capture retirement time32+comparison time32+pointer6+fresh/valid2:72 FF. The comparison stage costs at least **+1 edge locally**. Captured timestamp must be compared with captured corresponding time and pointer/valid identity. This is not a certified +1 complete ABI: fire advances `pb_r`, updates `fd`, winning-select state and collision detection; retirement advances `rpb`, clears `vld`, changes global/event boot counts and eligibility; `rec_slot` can invalidate a head between capture and use. All must be retimed consistently. A naive register insertion is incorrect. Complete HWIN output delta, parent C, HWIN start, PINPIPE and token-price deltas are **NULL**, not zero. No downstream compiler date has been changed.

The five pre-first-FF predicates (`f_mc24/25`, `f_mw21/22/25`) must move behind registered physical inputs. Existing mc_q/mw_q can supply them only if all related CSR payload/selector/limit/attribute paths align to the additional decode edge. The 52-bit stage above is an explicit alignment reservation, not proof that every boot cone is complete. Event-local decode/capture must preserve same boot word identity under adjacent MC/MW traffic and armed/outstanding refusal. The `cfg_sel_r` next-selector lookahead must be rederived; it cannot read a different CSR generation. These unresolved costs prevent an implementation approval even apart from the band failure.

**B: early-prefetch to retain original fire dates.** The current circuit already compares one edge ahead and captures winning selects/payload at that edge. Early prefetch would need its own pointer/generation-qualified head and valid lifetime, exact forwarding and capture-ready deadline. There is only one real read port per payload bank. A speculative next-head read must not evict the current head before fire/collision/output selection, and a cached next head must be invalidated/refetched after an overlapping record/write. A pair of complete head contexts can remain depth2 FF; a depth3+ delay or indexed runtime table requires ring/SRAM. No such design or zero-date proof exists here. Alternative B remains MODEL OPEN; it is not proved impossible.

## Source-derived failure witnesses / required proofs

These are counterexamples to naive transformations, not claims that a whole new RTL variant was simulated.

1. **Time alignment:** at edge k, fresh valid head due=T and comparison time=T produce old eqn=1 and old fire at k+1. Capturing the head at k but comparing it against current T+1 at k+1 produces eqn=0 and late=1. Capturing time too repairs identity but yields fire one edge later; it cannot certify zero event-date change.
2. **OLD/forwarding:** at k, `we=1,wa=A,wd=N` register wv/waddr/wdata. At k+1 the SRAM reads OLD A while writing N; `hit_r` captures prior wv/address match and fd captures N, so qualified q=N. A speculative cache using only raw SRAM output stores OLD A. `hit_r`, fd and record/fresh invalidation must travel together.
3. **Retirement→boot:** with the final outstanding entry due at k, original due decrements count and clears vld at that edge; idle boot eligibility changes at the following observation edge. Delaying retirement by one moves this eligibility, including boot word rejection/acceptance, and may extend RX outstanding membership. Retiming only the comparator changes behavior.
4. **Advance/invalidate:** `fresh_r <= !adv && !(pe&rec_slot)` deliberately suppresses head use around pointer movement or a new record. A stored old fresh bit without pointer/record-generation revalidation can fire a newly overwritten slot. Copying payload alone cannot certify lifetime.
5. **First/last slots and restart:** reset is inherited synchronous release edge3 (root/group/local), with two synchronizing stages plus its existing local stage. It must not be shortened to a new two-edge release. No added reset stage is free. Original min D=nw+2, first47 slots, wrap at lw, current/previous forwarding, back-to-back start and MC+MW collisions must all remain in the proof.
