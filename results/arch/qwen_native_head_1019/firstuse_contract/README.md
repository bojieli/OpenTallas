# Head first-use source contract

MODEL ONLY; no RTL changes, builds, simulation, gate, fleet jobs, or source activation. Exact source `5cd31ebb8`, terminal packet `cd660e13e`, parent ledger `0dd6c84a7`, and holding proposal `f7659f090` are separate inputs. `extract.py` checks the existing per-bit generic inventory and source hashes; it is not an RTL proof. The proposed two-slot replacement remains optional and unimplemented.

All 97 four-stage unreset paths start at the **same existing ML-tag SRAM output capture**, `u_h.u_lane.e_tag_m`. The first capture stays. Exactly 62 paths end at `s3_tail` (the complete TT tag), 32 at `s3_imm2`, and three at `s3_ad`. Their three downstream stages are respectively `s1_tag -> s2_tail -> s3_tail`, `s1_tag -> s2_imm2 -> s3_imm2`, and `s1_tag -> s2_ad -> s3_ad`. Every stage clocks on the head clock, unconditionally, without reset, enable, class, user, GO, or abort selection. `paths.csv` records all 97 indices, exact stage aliases, native macro consumer ports, and original source attributes. There are 291 data stages under discussion, not 97 SRAM captures to remove.

## Actual producer and connected parent

The slice decodes `c_su = go && kind == 1` from its registered command. This initiates the actual configuration memory read (`p_re(c_su)`, index `cmd_q[12:4]`). Two resettable command-clock stages `u_sug`, reset leaf 318, produce `su_go`; the SU controller uses reset leaf 319. Their equal logical depth does not establish a native release relationship. SU `accept` is **unconditionally GO**. `ready = !active && ((i_sfu == cls) || inflight == 0)` diagnoses legal admission; it does not delay a command. The controller updates `cls` on acceptance, starts `active`, and emits the following cycle. A class switch while old elements remain in flight faults rather than waiting in hardware.

With LTD enabled the actual SU transports controls and memory answers in **two separate HOPS3 `ot_pl_stream_land` instances**, command `clk` to `ck_lane[l]`. It has separate HOPS3 request/result return crossings. The lane fixture adds IREG1, its reset relay, head input data/valid registers, and the head's `rt` reset relay. The exact native-head module is selected by the private production source-list replacement in `run_production.py`; the ordinary source file with the same lane-module name instantiates the older `qfd_dv_lane_h_landed`. Therefore the full W10 result is evidence for that declared private substitution, not proof that every current physical parent already instantiates this head. The fixture opts into `CONTROL_SAFE=1` only with `OT_HEAD_CONTROL_SAFE`; the cached census explicitly sets that parameter.

The particular source slice connects `ck_lane`, `ck_head`, all SFU clocks, and reducer clocks to copies of `ck`. It consequently exercises functional common-clock crossings. Native regional phase, independent clock stop/resume, and actual reset pulse delivery are unqualified. HOPS writer/reader reset and warm state use their own clock edges. A command-domain startup count cannot supply missing destination edges or guarantee the same command/answer epoch. `RESET_WARM=18` only offsets the event file; base events already start at 16. Existing first SU commands at e191, a325, g248 are observed test schedules, not earliest legal producer ages.

## Conditional local edge derivation

Let H1 be the first rising **head** edge at which its input reset `rt` is already high. Assume reset previously reached the existing asynchronous valid/age state, the head clock subsequently runs, the same external pin stream feeds both designs, and macros obey their exact OLD-read RTL. This is a local source calculation, not measured timing or an actual producer first-use contract. It introduces no command waiting rule.

The smallest optional three-stage replacement has old slots read before overwrite and advances on **every head edge**, including invalid traffic. After any reset of only its pointer, its result equals the unchanged three-stage shift after H3, independently of slot/data initialization. At H3 both results are the input sampled at H1. Before H3 equality requires a specific initial-state relation and can fail. Downstream memory may have captured different unqualified words during the first three edges; matching its valid stream and later qualification is necessary too.

The exact safe head has inner ML11, LM5, LA4, TAP0=10 and TAPMAX=136. A candidate pointer reset must use the **same actual head `rt` epoch as the existing age/valid state**; an independent pointer reset while old valid state remains live is outside this conditional argument and can corrupt a qualified in-flight word. After reset, packed ML valid is qualified by `valid_boot_age >= 11`, followed by resettable s1/s2/s3 valid stages. Even a continuously asserted earliest `emit0 && live` pin cannot make S3 valid before **H16**: pin valid H1, e_v H2, SRAM write H3, macro read H12, retained capture H13, s1 H14, s2 H15, s3 H16. The corresponding tag data takes the same retained capture plus three edges. Therefore the local three-edge refill is earlier than this existing qualified S3 use. This supports a conditional internal proof obligation; it does not qualify raw outputs or parent identity.

For the default non-SFU class, with the same assumptions and earliest valid pins, the calculated earliest head request output is H3; the affected tail does not drive requests. S3 H16 produces D38 output H21, final v3/adder select H22, D914/tap0 output H26, MC H27, DMC H32, MD H33, DMD/ov H38, head `l_ov`/`retire` H39, and head VM/KV write strobe H40. SFU launch can first occur H27 when selected; actual return timing must come from the bound real SFU. These edge numbers are analytical local port boundaries, not the historical numerical ages, global reset prices, or native latency measurements. They do not replace any programme timing.

Class clear is `accept && i_sfu != cls`, after the real input path. Existing class-age qualification requires the selected tap depth: NONE10, EXP85, RECIP57, RSQRT72, SIGM136. It clears the valid epoch, not the 97 data tails. Neither class switch nor invalid bubbles may stop or rewind the proposed storage. The head has no user or abort identity port. Users sharing this engine require the existing serialized producer/class ownership; there is no basis for per-user or abort-triggered clearing. A warm reset while the head clock stops still resets a new asynchronous pointer if the pulse actually arrives, while unreset data retains history; after resume the local three-edge argument starts again. It cannot establish that the HOPS command/answer epoch or external SFU reset belongs to the same transaction.

## Observable boundaries and unresolved equivalence

The head registers addresses and payload outputs without reset or valid gating. `l_last` resets at the head pin but then copies the unreset downstream tag every edge independently of `l_ov`. Thus canonical raw pins can expose different retained histories after a pointer reset. All-output equality from the first post-reset edge is **not proved** and does not follow from the S3 guard. Existing pair-head testing compares all 30 outputs but starts after `n > 200`; its warm-reset observations use its particular initialized history. It does not establish arbitrary-state equivalence for this unimplemented storage.

A concrete algebraic warm-reset witness exists before qualification: take an equivalent pre-reset old three-stage history `[newest=1, middle=0, oldest=0]`, two slots `[slot0=1, slot1=0]`, result0, phase1. Reset only the pointer to phase0. On the first resumed edge the old output becomes middle0, whereas OLD slot0 makes the proposed result1. This is an internal recurrence witness, not a newly measured RTL failure. Choosing a tag `last` bit sends such an unqualified mismatch into downstream stored tags. Nothing in RESET_WARM18 proves a raw-output exclusion for it.

The actual SU reducer uses `l_ov && l_red != 0` as its valid, row retirement uses `retire && l_last`, and ordinary writes use `vm_we/kv_we`. Those predicates explain why qualified consumption can ignore some raw data differences. They do **not** erase raw pin observations or establish every downstream fault/idle/retirement cone. In particular SFU faults enter head `l_fault` independently through the real SFU fault ports; standalone arbitrary `sy_*_f` stimulation is not a producer contract. Full fault/reset composition and parent consumers must retain their existing semantics.

## Smallest meaningful proof proposal

The existing full-shape pair-head bench is the minimum internal vehicle: WR16/AW24/NW18, every real arithmetic cut, all 13 native 32x64 macros and both native 128x64 TLS macros retained. Before candidate implementation, a passive first-use extension should distinguish raw all-output comparisons from actual qualified consumer predicates, initialize arbitrary retained histories explicitly, and record all 97 capture/tail ages, ML valid, S3 valid, class clear/ages, tap valid, MC/MD valid, and every output strobe. Bind the actual three SFU modules and outer IREG/OREG/reset from the existing native lane fixture for producer-derived fault behavior. Include earliest pin acceptance, invalid gaps, unchanged and changed classes under actual admission, warm reset at both pointer phases, and local clock stop/reset/resume. A valid-gated advance and pointer rewind are causal controls. This is a proposal, not an authorization to change output contracts or to build a candidate.

That head vehicle cannot close parent startup or user ownership. The smallest **existing connected parent** has the actual eight-lane SU controller, its HOPS3 control/answer/request/result paths, config read/GO producer, and real reducer/reset tree. A one-lane scaled controller or replayed fixed schedule cannot replace it for the outstanding epoch question. Source/exe inventory and measured admission are required before any authorized proof build. Parent native clocks/reset origins remain NULL until bound. No whole-die simulation, new lifecycle metadata, reset warm-up increase, or new schedule wait is proposed.

Preserve all 24 mixed/reset/FPU chains (94 FF), all seven unconsumed tail captures, all existing macros, and every original failure. The 83 unsafe roots and reset load1603 remain open. The holding proposal's 301FF/10 phase copies/291 mux2 cost is inherited conditional modeling, with native area/capacitance/depth/reach unknown; this source contract supplies no physical approval or forced storage choice.
