# Native head conditional holding model

MODEL ONLY. No RTL, synthesis, gate, macro substitution or parent activation. Exact head source `5cd31ebb8`, terminal `cd660e13e`, parent first-use ledger `0dd6c84a7` remain separate evidence. Cached generic netlist from the original ep6 trim census was flattened read-only through ot-run; `exact_chains.json` records every candidate bit, alias index, driver, consumer, clock, reset and source attribute.

The old detector overcounts pure holding lines: its `startswith("$_DFF_")` predicate includes asynchronous-reset cells. Of 201 chains / 722 FF, 24 chains / 94 FF cross reset or arithmetic/valid stages; preserve all of those, including every depth-5 chain. The remaining 177 chains / 628 FF comprise 20 depth-3 pin-address chains, 24 depth-3 SRAM-to-output-address chains, 36 depth-3 SRAM-capture/tag chains, and 97 depth-4 SRAM-capture/tag-tail chains. Mandatory SRAM capture, face registers and arithmetic cuts cannot be erased by naming these delay lines. Each exact endpoint appears in model.json and the full per-bit inventory.

The only bounded partial proposal keeps the first SRAM capture on the 97 depth-4 chains, replacing the three following continuously clocked tag/tail stages with genuine two-slot OLD-read circular storage and a registered result. The input to the ring is the existing capture output. On each head edge, read OLD slot[phase], overwrite that slot with the input, then toggle phase. There is no valid-controlled advancement, class-controlled clock, user selector, abort port, new crossing, or data-dependent stall. No new shared FPU or source reset edit is proposed. Ten chunks of at most ten bits cost 194 slot FF + 97 result FF + 10 phase FF = 301 FF, replacing 291 FF, for +10 FF/clock pins and ten new reset sinks if phase reset is eventually approved. Predicted phase fanout is at most 31 including feedback, subject to actual transparent native census. Write-feedback muxes194 + read muxes97 are charged explicitly; mapped cell area, clock capacitance, depth and physical reach are NULL, not zero. This291bit data storage is below the2kb SRAM threshold; all13 native32x64 and2 native128x64 TLS macros retain exact identities and ports. No claim is made that added area fits a parent slot.

`prove_holding_model.py` is a mathematical recurrence proof vehicle only. For both legal phases, all three-bit initial histories and seven-edge binary sequences it checks 14,336 equalities under a bijective initial-state mapping. It demonstrates counterexamples for valid-only advancement, write-first collisions and pointer rewind. This does not prove production reset or first-use. The existing tail data is unreset: resetting a new pointer alone can select different retained history. Class changes must not clear these tails. No head user/abort identity exists, so no independent user/class/abort clearing contract can be inferred. Qualified observation before three uninterrupted native edges remains unresolved, and exact all-output equality there is not established.
