# Re-price with the 2026-10-08 closure costs

`reprice.json` is generated by `tools/reprice_20261008.py`. The script adds no model of its own. It drives the existing composition tools with the cycle costs that today's closures recorded, adds them one at a time, and composes them cumulatively:

- **DS ROM, 1,792 pairs:** `tools/s81/field_phases_1792.py compose` on the measured field phases, with `--extra-wire` for costs charged per field phase. Costs charged per node go through `tools/dsrom_closure_cost_ledger.py`.
- **DS ROM, PQ-adopted basis:** `levers/qelem_pq.json` flipped to ADOPT in a scratch copy, then composed by `tools/dsrom_1m_allmeasured.py`.
- **HBM and Qwen:** cycles multiplied by the per-token counts from the critical paths already composed.

Where the exposure of a cost has not been measured, it is charged as an upper bound. None of these rows is a physically closed rate.
