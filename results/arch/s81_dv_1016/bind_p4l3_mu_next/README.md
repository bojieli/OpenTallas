# MU-S81-2/DIE: multi-user p4l die variants on the next S81 GEN base (10-19)

Branch `claude/mu-s81-2-die-1019`, built on `claude/s81-pilot-next-1019` 198cf1c56. That base is the die-lead branch 08dbb9157 plus main, the SerDes column rev2 and the CH_BOARD 700 coll lane. This branch ports MU-S81/DIE 908a67c18 onto that base.

## What changed against 908a67c18

- **Plan.** The plans keep the `p4l_lkcol` rev2 SerDes column slots (259.2 x 3596.4). `dv_plan.py --lk-slots` copies the slot geometry onto the built plan after every fact has been computed, which is how `p4l_lkcol` itself was derived from `p4l`.
- **Copy-B pair.** Following the copy-B relay plan (`results/arch/mu_s81_1018/copyb_relay_plan.json`, `if_slot_3596`), the A/B pair moves from s_0N to **s_0S**:
  - `lk_WS2` sits at y 11332.32 and `lk_WS3` at y 243.12.
  - Each B lane leaves through the S street, runs along the frame/PHY gap at x 280, and ends on the slot's E-face attach point.
  - Each B lane has 13 stations.
- **hslot binds its CLOSED view.** `dsdv_mu_hslot.sv` is untouched, so it is byte-identical to the source of view `dsdv_mu_hslot-28a8118d5`.
  - The end-slice windows, landing replays and RX tag check (908a's NEV extension) moved to a **new leaf `dsdv_mu_hwin`**. It sits beside the hslot in `dsdv_seq_host_mux` and keeps its own copy of the start table.
  - Window boot words now arrive as host CSR **0x16**, so hslot never sees a window word. The S / RL words stay on CSR 0x15, which both leaves read.
- **Right endpoint per stage.** The leaves come from `rtl/dsrom_sys/s81_dv/slice/ot_s81sl_slice_lep_mu.sv`, a new file. `ot_s81sl_slice_lep.sv` is unchanged, so the lep kit sources are unchanged too.
  - **`ot_s81sl_lep_mu_a`** (kit `s81sl_lepmua`): s_0N, s_7S, and s_0S on non-dup dies.
  - **`ot_s81sl_lep_mu_ab`** (kit `s81sl_lepmu`): s_0S of the AB die only.
  - **`ot_s81sl_lep_mu #(.HOST_EN(1), .AB_EN(0))`**: s_7N. This is still owed: it has no parameter-free top and no kit.
  - **`dsdv_mu_land` at the CLOSED view's parameters** (W 1104, NB 80, NS 1, SRAM 1): in every MU cluster.
- **Vertical relays.** The 512/562 vertical relay stand-ins `dsfd_dvrlyh_512_NS`, `dsfd_dvrlyh_512_SN` and `dsfd_dvrlyh_562_NS` live in the new file, so `dsfd_rly_masters_dvh.sv` is unchanged.

## Benches

All benches ran on Verilator 5.050 (ot-epyc6). Results are in `results/rtl/mu_s81_2_die_1019/hwin`.

- **MU_HWIN_GATE PASS.** Closed hslot plus hwin:
  - 32 starts and 80 fires, all exact, with K 2. This is the same result as 908a's in-hslot form.
  - hslot t_mf and hwin t_wf both stay 0.
  - A bad RX tag raises hwin t_wf[0], while hslot stays at 0.
  - Mutant 3 (ab dropped) and mutant 4 (replay enable ignored) both FAIL, as required. The witness logs are `run_mut3.log` and `run_mut4.log`.
- **LEP_MU_DIE_LINT PASS.** Covers hwin, `seq_host_mux`, the four cluster forms, the five die masters and the three relays.

## Open items

- **Landing views.** The lep_mu_a and lep_mu_ab kit gates (`s81sl_lepmua`, `s81sl_lepmu`) are pending. Their views are listed as owed in `child_views_owed`.
- **s_7N endpoint.** The host-plane MU endpoint of s_7N (lep_mu HOST_EN 1, AB_EN 0) still needs a parameter-free top and a kit. Until then its pair-B inputs are constant 0 inside the cluster.
- **hwin kit.** The new leaf `dsdv_mu_hwin` has no kit yet.
- **S-tier RX tags.** S-tier `mu_rt` is not returned to the seqhost. This includes s_0S, which is the copy-B RX endpoint on the AB die. Fixing it needs an `rt_0S` lane or a die fault fold.
- **Status fold.** The die status fold for `t_mf` is owed.
- **Landing K.** The MU lanes are not in the land plan yet, so they use the default K 1. Re-run `dv_land_pilot` on the MU plans.
- **Copy-B vertical stations.** The 30 copy-B vertical stations use soft relay masters, with no closed NS view. The relay plan says these are die-level flops placed by the repeater flow.
