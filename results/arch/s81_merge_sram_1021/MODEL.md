# Opt-in P.V merge-ring SRAM candidate, before construction

Source baseline e3a16235d / production ot_hdc_v41x_attn_merge_x. The persistent state comprises 4 virtual merge instances × 5 levels × 16 heads × 8 positions × 33 bits = 84,480 bits. NTP1 changes physical dot-product tiles, not the four virtual merge streams. Head controls are equal same-cycle registered copies by construction; grouping their payloads does not combine independent streams.

Each level stores one 528-bit word per dimension (16×33). Five existing real ot_sram_1r1w_32x128_m1 banks provide one read and one write per clock, 640 allocated bits per word, 32 physical words; useful depth8. Twenty level instances use100 SRAM macros /409,600 allocated bits. Unused bits/rows are physical capacity, not removed useful state. Clock energy/area overhead and exact parent fit remain measured obligations; no gain or fit is inferred from bit reduction.

A circular pointer names the legacy ring[0]. On an active v edge, the old registered SRAM output supplies the original add operand on that same edge. Write the old pointer only when store=v&&live&&!fin&&!use; advance modulo8 whenever v. On v bubbles hold the pointer and do not write. The SRAM read address before the edge is next_pointer=(v?ptr+1:ptr), yielding the next head immediately after that edge. Reads are old-data; for depth>=2 the read-next and write-old addresses differ on every active edge. No write-through bypass or extra operand register is used. Non-power-of-two depths up to32 use explicit wrap; depth1 is excluded.

SRAM payload and output are unreset, as the original ring. The pointer is reset to0; a new legal merge job must fill every dimension at its first store level before consuming existing data. Therefore equivalence across reset covers the defined initialized job sequence, not stale uninitialized payload. Startup must provide a reset clock before valid; bench must refill after reset and catch stale reuse. Reset qualification/source clock startup remains open until actual source proof.

Candidate defines OT_SVC_MERGE_SRAM, absent by default. Original FP add order, per-head control pipeline, flags, v/fin/blk arrivals and output age are retained. No arithmetic or token/calendar promotion. Minimum proof compares actual macro read-before-write against the original v-gated ring with distinct dimension/head words, full-store warmup, intermittent bubbles, non-store rotation, repeated stores, reset/refill, and causal wrong-pointer/bubble/read-age controls. Actual selected merge association/FP hierarchy proof and native LP/profile follow only after that mechanism terminal.
