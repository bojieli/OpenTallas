Actual RF2 snapshot062628/062807 (exact_content_snapshot start0b82fbee7, not CLI b88):
xk[3:0] is a top input without an inside-frame driver. Each xk[n] connects to
u_cf/xk[n] (dsfd_cfifo_crs4) and u_xo<n>/ck (dsfd_dvrly_276_NS); each relay ck_o
connects to top output xok[n]. Existing original SDC defines virtual core/r1/r2
and actual ck_r0/r1/r2 clocks only. xk receives core-domain DATA input delay.
That is not an actual forwarded clock. No phase/root can be inferred truthfully.

The API NEVER creates/deletes clocks, changes waveforms/source latency, adds
exceptions, or substitutes DATA paths for propagated clock paths. Opt-in requires
forwarded_clock_ports plus explicit forwarded_clock_bindings per scalar bit:
  xk[0]: {clock: actual_existing_name, root: actual_nonvirtual_root,
           pins: {u_cf/xk[0]: dsfd_cfifo_crs4, u_xo0/ck: dsfd_dvrly_276_NS}}
All declared ports' actual bits and all declared pin bindings must match exactly.
The source owner must supply truthful original interface clock constraints; the
API only validates them. Current RF2 legacy ports-only contract fails admission.

Native checks:
- actual input bit has exactly one propagated clock, with one nonvirtual root;
  canonical existing clock_family ancestry proves any generated master.
- each actual child pin has the same unique source clock (intermediate generated
  clocks are refused in this narrow version), expected immutable master/bit/root,
  and a unique physical path to that input through actual loaded-Lib BUF/INV cells.
- physical parity determines output edge ↔ input edge. For both min and max and
  both sink transitions, require one actual propagated clock path, matching clock,
  scene and source edge. Local delay subtracts the matching actual input arrival.
- per input bit/source edge: child-flop interval is local early+actual child Rmin
  through local late+actual child Rmax. Bound max interval end minus min interval
  start <=80ps at TT/FF for rise and fall separately. SS remains diagnostic.
- freeze pin→bit/clock/root/master/parity and cell→domain ownership; conflicting
  assignments refuse. Enumerate all actual sequential clock sinks of each source
  family; any unbound sink or raw/check-only role without its existing binding
  refuses. Existing native SRAM/raw/co-timed and global native audits stay active.
- IO and clock-output constraints stay present; no blanket output exclusions.
  Existing forwarded clock input bits retain explicit domain ownership and IO
  cardinality is checked against data inputs union verified forwarded inputs.
- no opt-in keys: generated bytes must be identical to current main.

Check positive/inverted paths, non50 waveform and source latency, both edges,
