Source admission and model
--forwarded-clock INPUT:OUTPUT declares distinct scalar boundary names. Existing
clk_in/clk_out discovery remains automatic; absent default ports do nothing.
An explicitly missing pair is an error. Walk backward from OUTPUT to INPUT,
requiring a unique driver at every net, one actual input and output per physical
cell, no cycles, disconnected nodes, foreign boundary roots, or aliases.
For each cell, inspect every loaded Liberty definition for that physical master
at that export corner: output function must be exactly input or its inverse.
All definitions must agree. XOR unary inversion parity across the physical path.
The input must have one primary source clock. Any output clock must be generated
with the same period and the physical polarity's waveform modulo that period.
The canonical native write_sdc source/master must identify the declared input and
its unique source clock. A user cannot waive polarity with a sense flag.

For output edge e and path inversion parity p, the matching input edge is e XOR p.
Preserve the actual root waveform, source latency, input transition/driver,
original output load, all routed SPEF, and original physical driver.
Record actual terminal arrivals before phase normalization:
  local_max(e) = output_arrival_max(e) - input_arrival_max(e XOR p)
  local_min(e) = output_arrival_min(e) - input_arrival_min(e XOR p)
Driver transfer uses the same matching actual input arrival. Output-net delay
is output minus driver for the same edge/bound. Input/output/driver absolute
and waveform-normalized values remain separately recorded. Finite values,
early/late ordering, correct phase indices, and nonnegative physical transfers
are checked. A root SOURCE_LATENCY 17 must shift absolute arrivals by 17 while
leaving local cell/wire transfer and native ETM lookup tables unchanged.

ETM preservation
Record original OT_WS sign-off first, then emit the entire original main ETM
before any forwarding-clock mutation. Remove only output boundary clocks for
native propagated metrics. Delete clocks for a second native clock-free ETM;
its naturally extracted combinational arc must relate to INPUT and carry the
physical Liberty parity's positive_unate or negative_unate sense, with cell
rise/fall and transition tables. Replace only OUTPUT's complete pin group in
the original ETM. Every other pin and FF group remains byte-identical. Preserve
sequential_<corner>.lib.raw and forwarded_<corner>.lib.raw plus hashes. No
positive-arc transplant, label rewrite, timing mask, or physical qualification
is implied by this export repair.
