The wires-only parent has 83 independent child clock entries: front, ktree and score, plus 16 each of stin, stk, nb1, nb2 and lane8. The earlier 67-entry count omitted one family. KP keeps its two-stage return pipeline; the two NB stages occupy separate one-stage leaves. There is no arithmetic reorder or data-cycle change.

`HEAD_R3=1 JOBS=8 bash rtl/test/qwen_split/run_qkh_head_native.sh OUT MUT` runs the existing actual FP32 reference. Source ab32d3a9b passed 3,515 cycle checks (1,716 score changes, 128 node changes, two resets). Node-beat swap MUT=2 failed with 3,330 mismatches; control-direction MUT=4 failed with 290. Receipts identify the immutable source input directory and actual host units.

`plan.json` is generated by tools/qwen_kv_die/head_native_plan_r3.py at 5cbf348bc. It fits the actual exported v1.1 outline 1079.976 x 492.456 um, with zero overlaps and zero outside children. Every recorded data link uses conservative pin-region Manhattan bounds, except the bit-aligned parent ti/e inputs, whose corresponding x coordinates are identical. Worst bound is 470.754 um (lane0 to stk0), below 500 um. Parent data-pin faces, layers and offsets stay assigned by v1.1. Closed lane, ktree and score outlines/pin positions are read from their exported LEFs and retained; orientation is canonical R0, control face S.

This is a pin request and geometry proposal, not a new die contract revision or a physically qualified head. The die lead must assign 83 scalar clock entries to the actual child pins and deliver each at phi minus its measured child insertion. The current published head still has 51 entries and cannot bind this candidate unchanged. New front/stin/stk/nb leaf views require the proposed regions, synthesis/placement fit, exact bench plus observed mutants, and native launch/capture/spread audits. Closed leaves stand; stin reshaping requires slot_change, front reshaping requires slot_change, and the new stk/nb decomposition requires rtl_change. External asynchronous reset distribution, recovery/removal, and native reset paths also require assignment and measurement. No hardening job is submitted before the current slot and these child pin assignments are consumed.

The updated plan supersedes the earlier 438.6-um estimate: it uses the actual exported ktree input groups and S-face output pins, score E-face outputs, and the lane reset pins. It includes stin-to-lane reset and score-to-ktree reset hops. The 18 closed-child clock entry coordinates (16 lanes, ktree, score) come from those same LEFs; the other 65 child clock pins still need assignment and qualification. The result remains a proposal, not a qualified die.
