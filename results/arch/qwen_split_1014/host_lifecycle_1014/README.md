# HOST lifecycle hardware candidate

`qkd_host_lifecycle` replaces the on-chip control formerly retained by `tools/qwen_native_host/host_owner.hpp`: terminal/cancellation snapshot, identity-qualified ACK, held-source rearm, matching POST retirement barrier, native-rank participant and actual drain aggregation, and explicit coherent wrap/recovery transport witnesses. It instantiates the unchanged real epoch allocator and cohort, once on the coordinator KV die. Existing `HostOwner.hpp` remains historical component-driver code; this change does not claim it has been removed from native full-token qualification.

The leaf has one core clock (833.334 ps) and active-low POR. Warm readiness never clears identity. Each native-rank array uses rank=4*(physical HOST ID%2)+physical HOST ID/2. `participant_accepted` is an event receipt from the existing cohort, not an execution scheduling credit. Engine admission and exceptional initialization/retirement/recovery do not alter compiler-scheduled production issue.

A terminal input is sampled and held until the real allocator accepts it with every actual drain witness. Matching retained cancellations receive that acceptance pulse; unrelated cancellations never receive an ACK. A successful or faulted terminal additionally blocks subsequent allocation until a matching external POST retirement certificate. Cancellation can retire an allocated but undelivered grant without inventing a cohort. Link reset and training receipts are collected per rank only after an explicit recovery transaction and its preceding actual drain/reset stages. Recovery requires all real drains and no live allocation/cohort/terminal/POST state.

Run `python3 tools/qwen_native_host/lifecycle_gate.py` to reproduce the source-hashed positive component test and seven observed failing mutations. The test uses the actual full-width identities and all eight participants; INITIAL_EPOCH=65535 reaches wrap without 65,536 transactions. It tests partial participant arrival, an unavailable rank drain, held sources, normal-epoch POST blocking, undelivered cancellation, stale identity rejection and repair through an allocator-owned cancellation followed by real physical recovery, missing rank reset/training and reset pulses predating recovery. `gate.json` records source hashes and outcomes. `verilator --lint-only -Wall` is clean. `synth.log` records the ot-run generic synthesis (306 flops /5583 generic cells, zero memories; mapped area unmeasured).

`pin_request.json` is the exact source-backed 60-port/1516-bit interface and clock/reset census. Actual transport producers, physical boundary registration/CDC, assigned pins/slot, mapped area/fit, reset deassertion and phi-R clock delivery, TT setup/FF hold/DRC and full native static-cycle die composition remain required. This is component hardware/proof, not a die closure or full-token native qualification. The raw program loader and boot completion demultiplexer are separately owned and are absent from this leaf.
