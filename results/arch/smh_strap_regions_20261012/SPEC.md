Production shape is two leaves, each carrying 9+5+7+5 = 26 static slice-position bits (the diagnostic includes the shared clock). Register those 26 bits on the gated cluster clock (the existing ICG is forced open during reset) through five kept stages per leaf. These are configuration straps, invariant during operation. They settle five enabled rising edges after power-up; including the three existing xs local fanout edges, configuration requires eight enabled edges before the first operand capture. The inherited bench uses four reset edges followed by the existing HOLD64 startup clock tail and a 300-edge idle gap; the incoming x-write front/landing pipeline also provides startup lead. The production startup obligation is eight enabled edges before first operand capture; this is configuration initialization, not per-record latency. No data/credit latency or steady-state throughput changes. Added hardware is 260 DFFs, no memories and no new clock gate. The existing child strap fanout stages remain unchanged.
