# Current three-root reset event model and owner choice

Model-only; no reset source/helper changes, proof jobs or gates authorized by this packet. Frozen source f102e8cbc and exact source hashes are in source_binding.json; actual terminal S3 source_snapshot identities remain in the immutable shell_s3_terminal packet. The present current99 clock.sdc1226 refusal is host_rst_n__ot_rl1 CLK(core) -> ot_prs_00000_ff RESETN(ingest). It precedes spatial-spine API admission. No old private integrated receipt is substituted.

The actual spec declares independent clock families core833.333ps,host1000ps,ingest1666.667ps; pin_regs.clock=ck_core; reset_landing enabled, stages2. Frozen ot_pin_regs.tcl generates ordinary, unreset positive-edge flops: L0<=host_rst_n at core edge; L1<=oldL0 at core edge. Both assertion and release propagate only after two sampled core edges. Cold L0/L1 are initially unspecified. The mapped saved3_place source confirms core clock and complementary DFFHQN plus explicit inversion implementing these ordinary registers.

L1 feeds rst_n of the shell wrapper and hence async_rst_n of three original reviewed banks: u_rsh clockhost N4; u_rsi clockingest N20; u_rsc clockcore N4. Each bank has one first FF plus N equal last FFs, all asynchronous assert from L1. On deassertion first<=1 and last<=oldfirst: local reset release occurs after two eligible local edges after L1 rises. Same-timestamp events must retain nonblocking ordering; these are event sequences, not a vague four-cycle total. Core-bank release is two more core edges after L1, i.e. fourth sampled core edge after external release. Host/ingest release depends on their independent phase and edge counts after L1; there is no fixed host/ingest edge age from the external transition.

Fanout source arithmetic: external input drives one landing D; L0 drives one L1 D. L1 drives bank asynchronous controls:5host +21ingest +5core =31 physical reset terminals before any actual implementation replication. Local first drives4/20/4 last D pins; all <=32. Local last reset loads are spread by existing reset_relay_split max32, matching canonical original last scopes. e_rst_n uses dedicated ingest leaves18/19, same edge as rn_i. Final actual native loads, all copied control pins and reset-port loads must be counted; these analytical31/20 counts do not waive census or clock/RDC checks.

A proposed replacement raw-reset -> two ordinary landing registers ON EACH DOMAIN -> original local bank would release at the fourth local sampled edge. For core this matches the existing event sequence. For independent host/ingest it generally differs from two core samples followed by two local samples, and changes assertion time as well. Therefore it cannot satisfy exact old per-domain release ages for all legal independent clocks. Three independent root landings would also give three raw D loads, within native32 but above the generic no-landing raw-reset threshold2 unless an exact supported source admission is granted. No floating alias or assumption that independent copies release together is permitted.

Owner decision required before reset code: either explicitly adopt per-domain2+2 scheduling (including reset assertion latency, first accepted descriptor/credit/fault and occupied-reset behavior), or retain the existing global2core stage and obtain a qualified exact per-domain reset crossing architecture that preserves its assertion event and two-local-edge release. Merely adding local stages would add edges; merely false-pathing or broadening the spatial API would bypass the failure. A direct asynchronous raw port -> original banks retains the RTL bank2local release but removes the shipping2core schedule, and raw fanout31 also requires exact admission; this is another contract change, not a repair by equivalence.

Physical source-bound cold/reset evidence, actual local release/fault/credit behavior and canonical crossing qualification remain required for whichever owner-selected architecture is implemented. No universal cold convergence follows from a conditional copy certificate or bounded seeds. Current shell API cannot repair this functional contract.
