# Lower-latency actual 512-pin streaming candidate

The frozen block-batched reference in `pma512_1015` proves the full coded bitstream can fit the actual 512-pin digital PHY boundary at the required 16:17 FEC/PHY frequency ratio. Its full-block collection costs 49 additional FEC edges. This alternative removes that batch latency while retaining real finite storage, immutable data ownership and fixed issue cycles.

Each direction writes one full source word into one of 16 real register slots every source edge. The destination assembles its registered output from one or two occupied slots, consuming a slot only after its last bit has been used. Per-slot completion and release toggles cross two actual synchronization registers. Data remain immutable from write completion until the synchronized release returns; a failed reservation latches a fault without delaying traffic. This is a bundled-data CDC whose data stability/maximum path delay and synchronizer placement require physical checks; two toggle registers alone do not establish physical CDC qualification.

The duplex pair contains 16×544 + 16×512 = **16,896 storage FFs**, plus 1,056 registered output bits and control. The block reference uses 69,632 storage FFs. Maximum storage sinks on one standalone adapter clock are 8,704; the complete FEC hierarchy's shared clock-root totals still require census. Read selection includes two 16-slot word muxes and a 32-bit-step alignment selection, so physical mux depth, fanout, area and routing remain unqualified.

Declared numerical clocks remain FEC period 17 ns and PHY period 16 ns. The test calendar starts serializer writing on FEC edge 16, physical reading on PHY edge 23, deserializer physical writing on PHY edge 24 and FEC reading on FEC edge 29. The component latency is 13 FEC edges. Full actual rooted FEC/PHY512/decoder/static487-window composition measures age **116 FEC edges**, compared with 151 for the block reference and 102 for the earlier width-unconstrained same-clock diagnostic. Thus the adapter contribution is 14 FEC edges. At a declared 1.2 GHz physical clock, 116 FEC edges are 102.708333 ns and the adapter addition is 12.395833 ns. No source proves the analog PHY frequency, and these numerical clocks do not qualify GHz timing.

Component evidence covers 4,096 exact 544-bit words at all 17 phase offsets 0..16 ns, crossed with -300/0/+300 ppm physical period variation: **51 profiles pass**. This variation changes actual edge times; it is not rounded to one nominal period. Both signs of drift over a requested 65,536-word window fault (observed at FEC edges 9,713 and 11,485). Finite storage is therefore not claimed to support unlimited independent-clock drift. The declared 4,096-word envelope is stress evidence, not a substitute for an actual production clock/window budget. A tail-bit corruption mutant and an early-read epoch mutant fail. Full FEC composition delivers 2,048 user words, checks 2,376 decoded words with physical-wire bit errors and rejects the actual Forney decoder mutant.

An earlier eight-slot, shorter-start exploratory variant passed the nominal 17-phase sweep and full FEC age 112 but faulted at edge 1,674 under -300 ppm: its finite margin was inadequate. The retained candidate increases real storage and start margins to remove that measured defect. This is a structural correction, not a retry of the same source.

The wrapper `clk` remains the FEC family, including TX input and internal finite-window read clock. The endpoint/core remains a separate intended 1.2 GHz domain. Actual core→FEC487 and FEC→core487 crossings are owned by H-COLL and are not part of this proof. H-COLL initially composes the frozen block reference; it must explicitly rebase epochs and costs before adopting this streaming variant. Exact capacity remains 16 coded words per 17 physical edges; no extra bandwidth follows from the latency reduction. No endpoint613, G96 ring, whole-die placement, physical clock, TT/FF or production throughput qualification follows from these component results.
