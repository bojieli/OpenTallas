# Actual SU residual base cut

The immutable 685dad9b5 source and current optimized netlist contain 13,305 residual FF on ck. The actual residual hardtile boundary is 42,538 distinct nets: 20,889 inputs and 21,649 outputs. This includes connections to the actual blackboxed children, rather than counting only the 26,962 outer port bits. No slot, area, wire length or hardview is established for this base. Passing the 15,000-sink flow threshold does not establish physical feasibility.

`physical_cut.json` partitions every residual FF exactly once into source-natural stations. CROM IS owns 4,096 FF (`u_su.crq_q0`); CROM/KV OS owns 5,248 FF (CROM addresses/enables, KV addresses/data/enables); reducer input owns 2,076 FF (`rd_x`, `rd_addr`, `rd_v/mx/sq/last`); the eight merged broadcast names share 244 FF. The remaining control owns 1,641 FF, including instruction/status stations, counters, embedding selection/masks and native issue monitor. The original 256 AW24 offset expressions remain real combinational hardware and are not eliminated by this state partition.

Eight source broadcast declarations are not 4,032 independent current FF. Their 500-bit gb names are identical aliases after ordinary synthesis. Bits 0–255 are constant-zero wrom data; the remaining 244 logical gb bits require 240 independent FF in this flattened source. The four-bit difference is output logic/sharing, and must not be silently assumed to survive separate hardening. gv contributes three FF, rg contributes one. The complete low-to-high field map and variable bitmap are in the receipt. Thus eight physical groups cost at least 1,952 group FF, +1,708 against the merged baseline; independently hardened generic interfaces could cost up to 1,984 group FF, +1,740. Real mapped synthesis must resolve this range.

## Standalone source extraction

Create a distinct opt-in caller, preserving the current 346/347-root sources. For octet g, move the exact existing IS CROM slice `[g*512 +:512]`, OS CROM address/enable slices `[g*192+:192]`/`[g*8+:8]`, OS KV address/data/enable slices `[g*192+:192]`/`[g*256+:256]`/`[g*8+:8]`, and group g's existing gb/gv/rg always blocks into one actual octet station. Preserve non-reset data registers, asynchronous assertion and registered deassertion of rg, and gv's reset from rg. Do not reset data stations or substitute a direct rst_n reset for gv. This is 1,672 declared FF per octet, including the zero-valued weight field before constant propagation. The full logical interface has 1,671 data inputs, 1,671 data outputs, ck and rst_n: 3,344 pins. Pin pruning must be explicit in the source interface rather than assumed in geometry.

Move the exact existing rd_x/rd_addr/rd_v/mx/sq/last registers into a separate reducer-input tile: 2,076 FF, 4,152 data pins, ck and rst_n. Preserve rd_v's original reset semantics and the original independent data always block. Keep the existing reducer's downstream capture, golden FP order and all clocked edges. This tile requires a real view and a physical home; its 4,154-pin interface is a model warning, not evidence of fit.

These changes leave 1,641 control FF but do not remove the offset adders or control fanout. The conservative standalone census is 356 roots (347 + eight octet stations + one reducer station), and residual FF totals 15,013–15,045. These figures describe added actual local copies, not an adoption claim. Any offset-logic migration must copy the same AW24 expressions and prove it adds no sampled edge; station extraction alone does not localize those adders.

## Existing-root replacement alternative

An alternative can retain 347 roots by absorbing each 256-bit CROM IS slice into the corresponding real alignment-root child and each 256-bit rd_x slice into its real regional reducer child. The reducer's 28 metadata FF remain explicit shared/control state unless their replication is implemented and priced. This alternative requires new child RTL, exact gates and new hardviews; the existing alignment/reducer view does not cover the added stage. The shared ck and each child entry must be demonstrated phase-compatible on the actual die, preserving both sampled edges. Output stations and broadcast groups still need real source ownership and hardening; this alternative alone does not finish the base.
