**External escape remains OPEN.** The actual unchanged compiler packs pins at
0.096 um pitch, so the active contact span is denser than the full face. The
native audit records both values; full-face averaging alone is not a route
proof. The isolated `sram_escape64_1019` coupon exists to measure real external
PG/via/track access. A gate is a precursor to routed DRC, not that final proof.

Logical 8/16-row clients use actual 32-row macros with zero-extended addresses:
native8x64 would still have6.91 contacts/um and is rejected. Paid raw bank areas:
8x285 uses5banks/2767.95um2;16/32x546 uses9banks/4982.31um2;
128x256 uses4banks/3719.45um2;256x512 uses8banks/11440.94um2.
These are raw macros, without lattice/channels, pin registers, clocks or parent
repacking. Multiply the explicit `model.json` per-client area by the actual
client replica count; no full-chip area credit is claimed without that census.

The prototype wrapper pads high data/mask bits with zero, retains all physical
contacts, uses synchronous one-edge reads, and adds zero read edges. Controls
and clocks drive at most9banks per logical memory. The client must forbid
simultaneous same-address read/write across the independent clocks; the source
dual-clock macro does not specify deterministic collision ordering. There are
no repair spares on the new banks. Replacing a repair-enabled master therefore
needs an explicit client contract/area review, not an inferred equivalence.

Verilator5.050 fleet unit26857-1792426369 passed all5logical production shapes,
full-address wrap, partial masks, disabled-read output retention and independent
edge interleaving. Both bank-permutation and inverted-mask mutants fail with
`BANK_MISMATCH`; committed witness logs are under `functional/`. Native audit
unit33237-1792426471 checks actual contacts and separate rclk/wclk arcs in each
TT/FF/SS Liberty. These are component contracts, not FIFO/CDC/die qualification.

## Escape coupon safe-design review before gate

- Pins: fixed by generated pin registers on every data/control boundary;
  generated two-stage reset landing. The coupon clock ties both native clocks
  synchronously and makes no independent-clock timing/CDC claim.
- Reach: PASS by construction,108um square, longest geometric diagonal153um.
- Fanout: PASS candidate, one macro; mapped census still required.
- Depth: PASS candidate, no core logic beyond the actual macro and pin registers.
- Storage: PASS, actual32x64 macro, no runtime-indexed flop storage.
- Floorplan: PASS candidate, macro43.2/43.2 lattice; min32.8um side clearance;
  full-width standard-cell band possible.108square is deliberately a diagnostic
  access coupon with low utilization, not a proposed production slot.
- Clock: OPEN measured CTS/native census.03ns route IO hold margin; no uncertainty
  relaxation or data-path exceptions.
- Schedule: coupon pin stages are harness overhead only. Production bank wrapper
  adds zero read edges; parent control/clock/reach/floorplan qualification open.

Do not submit/adopt the coupon as a release element. ROOT reviews its actual
gate geometry before any diagnostic detailed route. Production clients must
