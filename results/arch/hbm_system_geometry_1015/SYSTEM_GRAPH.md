## Physical boundary defect found through this reconciliation

The actual static FEC source pads **487 payload bits to a 512-bit protected message**, then produces a **544-bit coded PMA word**. The real SerDes LEF exposes only **512 TX and 512 RX pins**. Padding the message does not resolve the 544-to-512 physical boundary. The graph records the missing coded-word map explicitly. A real 544-bit physical interface or a proved 544↔512 gearbox/rate/clock contract is necessary; truncating 32 coded bits is invalid. Root and H-COLL have been notified.

A PV-only placement score cannot decide the system arrangement. Query/P local broadcasts, KV staging and expansion, transposer storage and actual NE VM/stack paths must enter the same comparison. The earlier four macro precursors are retained as explicitly partial studies.

Current K/V rows contain **16 interleaved 265-bit groups**, each `{format1, scale8, codes256}`. Existing staging stripes these rows into 17 consecutive 256-bit SRAMs per lane. QK tile `g` needs lane `g/16`, group `g%16`; PV transpose tile `g` needs **both lanes**, group `g/2`, with dimension offset `(g*16)%32`. Thus the two modes have different physical adjacency requirements. Treating the current first 16 SRAMs as independent code banks would be wrong.

A concrete structural successor is now implemented in `rtl/hdc/v41x/static/ot_hbm_attn_staging_grouped.sv`. It repacks each lane into **16 code SRAMs and one 144-bit metadata SRAM**, retaining exactly **34 real 1024×256 macros**, the complete 8480-bit external packed-row ABI, all 320 addresses per lane, independent write masks and the same one-edge old-data read. This permits code-bank placement with its actual consumers while keeping the narrower metadata distribution explicit. It adds no payload array or implicit memory.

The actual-SRAM proof compares this RTL against the frozen original 34-SRAM implementation and an independent flat scoreboard: **3840 cycles, 32,563,200 bit checks**, three complete overwrite campaigns, all rows, both lanes, independent masks and same-address read-before-write. The real DUT metadata-rotation mutant fails at cycle 320. `grouped_staging_gate/` preserves the exact source hashes, original source snapshot, positive and mutant logs. Run admitted through `ot-run --mem 2 --threads 1`, EPYC4 unit `oth-ubuntu-1469756-1792054925`, terminal exit 0. This is component source equivalence, not integration, physical or full native qualification.

A turn is not a routing failure: actual streets or longer escapes may resolve it. The column exposes east/west clients but makes seven of eight north clock entries face another bank. The outward-MY option exposes attention to two sides while moving all other face clients. Neither is globally ranked. This is an actual pin-driven system grouping alternative to develop with ATT, LG, IDX, collective, clock delivery and PG-aware channels, rather than shortening one selected line.

The endpoint source owners are also creating a genuine new store contract with returns moved N→S to face the controller N bank pins, preserving actual SRAMs and explicit clocks. Its 434.72 × 515.20 µm group is a planning reservation. The old store view has blocked pins and stays on adoption hold; no old host cavity is inherited.
