The connected 417-word mechanism is qualified only at its named TEST context and common-clock books. The actual G9 s_0N wrapper is ot_s81sl_slice_lepw_mab_mu_72 at source60881bd5 (7373f3015 actual_source_bindings.json); its endpoint is HOST_EN0/MU_EN1/AB_EN1. Existing full512 CSR0x19/0x17 feeds the KS6 source only; no HBE context wiring is proved. Accepting an ordinary first HBE header and using its own fields as its comparison target would provide no independent configuration check and is rejected.

Recommended explicit authority path

Use a separate bootstrap command stream from the actual off-chip HOST authority through the already measured HSF0 host0 HFWD transport (selected8916 controller, five registered output edges). Give it a distinct HBC1 magic/version and two-record command format, rather than changing the meaning of an HBE1v2 data header. This stream is configuration authority, analogous to the existing class0 full512 CSR writes; it is not claimed to authenticate itself cryptographically. It may run only in a physically identified, statically booked reset/idle bootstrap window, while HBE data selection and the KS starter remain disabled. The caller must supply actual stage/rank identity, programme, transaction and clock-book provenance. No TEST default is accepted.

A bootstrap header names the strapped destination stage/rank, command type, exact payload length, command sequence/index and CRC32C of its raw512 body. Only bootstrap routing is available while unconfigured. A nonlocal bootstrap pair is forwarded NEXT with an explicit per-hop relative body gap; the raw body is never magic-inspected. Each receiver compares the destination to actual stage/rank straps and consumes only at its compiled bootstrap slots. A real local boot-edge counter starts at its actual synchronized reset-release edge; that local zero is not a global epoch. The required build-time bootstrap start/stride/body-gap profile is bound to that clock/reset identity and has no shipping default. The compiler must supply measured per-receiver release/transport timing before runtime. This avoids another undriven bootstrap-window input and avoids deriving an admission date from the first header. It does not use the incoming ordinary HBE metadata as an expected context. Header/body adjacency is an exact compiled local edge gap, not a completion wait. Missing/early/late/CRC/index/range/active-job violations inhibit configuration commit and fault.

Bootstrap writes a shadow configuration and context/slot book. COMMIT is a separately booked command that checks the declared row count, sequence completion, programme identity and required fields, then atomically selects the completed book at its explicitly supplied local capture epoch. This follows the actual KS6 CSR0x19 principle: the HOST supplies a timestamp AT THE RECEIVER CAPTURE EDGE; the real local clock counter advances it thereafter. A caller that lacks a measured receiver phase/transport contract cannot generate an admissible production image. No reset-to-global-zero assumption. Existing full CSR0x19/0x17 payloads remain full512 HOST_WORDs after configuration; inline ARM6 remains selection, not a replacement for those CSRs.

The data plane then uses only the independently loaded book row at each fixed header/body/return slot to drive expected TID/user/token/position, programme/epoch and directions. COMMIT/slot selection never waits for completion, credits or a runtime admission decision. Wrong/missing data faults at its booked date. Late configuration does not move any schedule. Reconfiguration is allowed only at an explicitly compiled idle/disarm boundary; a job in flight faults rather than changing its context. The real HOST producer must emit configuration records from actual programme/descriptor/route metadata, not copy the TEST receipt.

Capacity and storage must be explicit before RTL

The present one-context mechanism is insufficient for six distinct descriptors and multiple live users. Do not add a large indexed flop array. Proposed physical capacity is512 context/slot rows, with an explicitly declared used count; this covers282 rows for47x6 or300 for50x6 only as capacity arithmetic, not a claim that either is the selected programme. A provisional row packs192 bits: actual per-row identity68 (TID16/user10/token21/position21), local header edge48, local body gap16, source/destination stage8, opcode4 and flags/reserved48. The48-bit pattern area can represent a declared word count10, header stride16, inline-KS offset16 and6flags only if the compiler proves that strided contract; otherwise it must emit more rows and reprice capacity. NEXT and PREV may require independent simultaneous book reads:512 rows per direction would mean two separate eight-macro1r1w banks (16macros/262144installedbits), not an invented two-read SRAM. A512-row capacity claim must state whether it counts context windows or individual records, and cannot claim to cover every417-word transaction without its actual pattern expansion. Programme64 and epoch32 can be global to a sealed book only if the actual compiler contract confirms that scope. Otherwise add them to each row and reprice storage. All nonuniform per-hop dates remain separately supplied; no same-counter-offset inference.

512x192=98,304 persistent indexed bits require true SRAM. A conservative implementation budget is eight64x256 1r1w macros (131,072 installed bits) with source-qualified SRAM reset/control and prefetched row outputs. This is a capacity/model choice only; exact available macro ports, read latency, bank select fanout, physical area and clock/reach must be resolved before build. The static compiler must book the measured prefetch edges before each input header; no zero-cycle read promise. Bootstrap loads two192-bit rows per raw512 body if that packing is retained:256 bodies plus their headers and commit records; actual wire and landing costs must be emitted from the final schema. Sparse unused rows are not executable slots.

Minimal proof after owner review is one real417-word programme/checked descriptor and status transaction using the actual HSF0 source, context loader, book read path, current adapters and L0 consumer, with missing/late/wrong stage/rank/programme/epoch/index/CRC/commit/active-job controls. This is bounded mechanism evidence, not full programme/global epoch qualification. No bootstrap runtime or new source implementation is started by this proposal.

Add an opt-in explicit per-beat PREV selector carried with the actual ro IN_PIPE edge and actual TX predicate cohorts. Do not inspect raw body magic to infer direction. Preserve existing MU rules and fault on an HBE beat inside an incompatible MU data window. Exact native/mechanism proof required before using the new endpoint source; no old view alias.
3. Bind real stage HOST/KS/status to the selected sequencer clock region through actual priced landings. The current selected s0N and seqhost are separated by millimetres; the component's one-edge local landing is not a physical route claim. Compare a reserved typed on-die route to the existing host region against an explicit new wide relay corridor before choosing geometry. All clock ownership, relay count, programme ages and calendar costs remain open.
