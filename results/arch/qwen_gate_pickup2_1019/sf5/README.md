# qfd_d2d_static_sf5 — structurally safe MU compute D2D end (QW-D2D, 2026-10-19)

CRITICAL prefix (`qfd_d2d_static` in critical_tiles.txt): gate + review packet only, no REVIEW.json, no submit.

Top `qfd_d2d_static_ovl_sf` (generated by `tools/qwen_split/d2d_ovl_masters.py` into
`rtl/qwen_sys/d2d_static_20261015/ot_qwen_d2d_dies_ovl_sf.sv`; core `qfd_d2d_static_core_s` in `ot_qwen_d2d_safe5.sv`).
Same ports, same TXDP (0x0a010308 = [8,3,1,10]) and cycle-identical outputs as the MU OVL master `qfd_d2d_static_ovl`
(mu1 / safe3 kits). The die GEN binds it in place of `qfd_d2d_static_ovl` and must drive the six OVL ports
(cal_start_rx, cal_seg_rx, cal_user_tx[1:0], cal_user_rx[1:0]) from the sys_face OVL sequencer; no ties
(bench mutant `xovl_mut_rxstart_tied` shows a tie fails).

## SAFE-DESIGN checklist (owner 10-19)

1. Pins — PASS. One pin flop per functional port (PR=1); high-fanout inputs have KEPT pin-flop copies, all FIRM at
   their pin. Reset lands in 2 registered stages at the E pins (RTL `ot_rst_pipe` s0/s1, anchored by
   `local_reset_capture.tcl`); kit `reset_landing` opted out with reason (it would add 2 stages on top).
   POR/first-valid fence: every SAFE5 copy has the same D/clock/reset as the register it copies, so reset copies are
   equal from reset and unreset copies (bypass ages, payload-side) equal the original from the first edge; the
   lockstep bench checks from reset release. Die contract unchanged: rst_n/por_n asserted with the clock running,
   release takes 4 edges (2 capture + 2 region), first compiled start after release.
2. Reach — PASS by construction (345.6 x 216 outline; pin flop to farthest macro < 405 um Manhattan). Gate timing confirms.
3. Fanout — FIXED in source (table above); reset regions by the same-edge copy hook (<= 32).
4. Depth — PASS: logic unchanged except one-hot reads (shallower); mu1 depth ~483 ps at 770 ps.
5. Storage — PASS: 4 x 64x137 SRAM; calendar tables 1 kb each (<2 kb) read by registered one-hot; TXD 1-bit delays
   <= 10 deep waived (a ring costs more than the flops).
6. Floorplan — PASS: macro faces 5.23 pins/um; 2 x 2 macros on the 43.2 lattice ((43.2,43.2) (259.2,43.2)
   (43.2,129.6) (259.2,129.6)), 10.8 um halos; centre channel 158 um, 40.7 um full-width std band between the rows,
   outer 41 / 26 um; all 3,668 external pins at 0.192 um on full faces (N 1674 / S 1170 / W 758 / E 66, 5.21/um);
   aspect 1.6. Utilisation WAIVED: the outline is pin-limited (N face needs 321 um), std ~6.5k um2 in 74.6k um2
   (area -44% vs 475.2 x 280.8).
7. Clock — centre-fed: ck on the N centre track 172.812; CTS sink clustering 20/40; io_hold_margin 0.03; spread
   <= 80 ps TT+FF measured by the gate.
8. Schedule — PASS: 0 added edges (lockstep equivalence), static calendars, no credits/backpressure.
