# Actual TRX1 transpose SRAM port and age model

Baseline2303eec52, ot_hdc_v41x_attn_tr_x: actual TD32/DPT8/NL4/XOFF0,8,16,24. Four virtual streams each store2 halves×32 rows×8 dimensions×18 bits=9,216 bits,36,864 total. Four rows (one group of NL4, one half) write all8 dimensions on an edge, using registered row enables and current decoded elements. Each read returns32 rows at one dimension and half,576 bits. rsel and q.k/p.v select register on the read edge; eib captures the previous selected column on that same edge. Payload is unreset and only initialized legal producer entries may be compared.

Crucial collision semantics: original flops update on the read edge; the combinational selected col sees the newly written cells after that edge. Native synchronous SRAM read-old alone changes those values. A replacement must forward just-written masked lanes into the registered SRAM word after the edge; the next eib captures the same value on its original edge. Concurrent writes to the other half, unselected dimensions and bubbles must not affect the selected value.

A concrete constant-address construction avoids inventing multiport SRAM: bank by dimension8, with one wide1152-bit word holding both halves/all32 rows. Each dimension bank uses9 existing32x128 macros (128-bit masks), address0 only. A four-row72-bit write updates its actual group through native bit masks, with every other mask0. Constant read/write address removes high-fanout runtime row addresses. Both halves read every edge; existing per-row one-hot read controls select actual half/dimension. Original read-before-write is corrected by registered write-mask and72-bit-per-dimension forwarding data, preserving write-through col and original eib age. Forward data is8×72=576 bits per stream, not a second9216-bit transpose buffer.

Control construction must keep each registered write-row copy local to one dimension:18 mask loads+one delayed-forward-enable FF=19; a separately registered forward enable drives18 mux bits. Existing source row enables are same-edge copies, so this division adds copies without an operand edge. The four row writers share a legal group; arbitrary contradictory descriptor/row controls are not assumed legal. Actual runtime descriptor/data scale-bit fanout and pad-source distribution remain source obligations; simply expanding masked words can create high fanout. The model does not waive these native requirements or invent constant tile/tag values.

Minimum actual-source proof must cover nonzero FP8 and FP4 decoding/scales, both halves, all32 rows/8 dimensions, all four XOFF values, same-half collision/write-through, other-half writes, simultaneous four-row writes, consecutive writes, read bubbles, q.k bypass, reset/reassert with full producer refill, and wrong-half/wrong-dimension/read-old/mask mutants.
