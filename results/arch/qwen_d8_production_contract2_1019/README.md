# D8 production binding and whole-storage model

D8 remains a model direction. No new RTL, native gate, timing result, or production schedule is claimed. The previous 384 D4 scenarios and their negative cases remain immutable in 5a266752c. Four narrow 257/258 landing halves closing in 16f76334c do not provide a D8 SRAM, D8 phase contract, or parent qualification.

The current generator source is pinned in model.json and copied under source/. It emits D4 wrappers, three K pins, and modulo8 calendars. The source clock contract expressly leaves actual PLL/divider delivery OPEN. A D8 master cannot silently replace this ABI: every bound instance needs exact ordered fields, four-bit strap, source/receiver root identity and phase, reset epochs, generated bank edge lists, and first-use calendar. All these production bindings remain NULL.

The whole 600-bit D8 write ring alone stores 4,800 payload bits. Duplicated read banks and output add another 5,400 payload FFs; epoch, selection, enable and reset state add more. Seven W96 wrappers retain a coherent runtime ring, so their per-wrapper 1,816-state estimate does not waive the storage rule. The old total 12,712 state/119 ICG estimate is retained, without treating partitioning as approval. Also, every carried control, validity and observation bit must be counted: 600 is the nominal data-bus width, not a certified complete ABI width.

A concrete alternative MODEL uses ten real dual-clock 32x64 SRAM slices for an eight-row, 605-bit nominal word (600 data, four epoch, one validity). This is 4,840 logical bits in 20,480 physical bits, with 35 unused width bits and 24 unused rows. Existing dual-clock coupon geometry gives a reference macro area of 5,535.89568 um2 before any control, pin registers, clocks, PG or channels. A 5x2 array on 43.2um origins plus one full-width standard-cell band gives only an initial 216x129.6um structural rectangle. Source area, legal pin faces, contacts/PG/OBS and an actual parent slot remain unbound; this is not a floorplan approval. The exact macro master/view fingerprints have not been selected.

A real registered SRAM read at the candidate D8 bank-read edge, followed by the existing output FF, might replace the 4,800 read-bank FFs without another receiver edge. That is conditional: actual macro read latency/CQ/setup/hold/min-period/pulse-width, mask/collision behavior, input pin registration and the complete validity/reset protocol must prove it. SRAM cannot be assumed initialized to zero. Clearing eight external validity bits is an alternative only after exact write/read/epoch alignment and arbitrary initial memory proof. The model does not convert this conditional alternative into an implementation.

Previous D8 arithmetic gives minimum write-to-read age 1.25T and minimum read-to-next-overwrite gap 3.875T, retaining setup/hold uncertainty60/25ps and cross-root reserves150/100ps. At T=833.333ps these leave ideal gross budgets831.667/3104.167ps; launch/capture insertion, macro/data arcs and wire costs still subtract from these. This transformation of old scenario ages is not an all-K0..15 D8 proof, and K remains an epoch offset rather than a physical-age guarantee. An extra final output FF cannot repair an unsafe internal bank crossing.

Eight initialization writes cost four additional source edges compared with D4. Absolute first-use and token LU/LS deltas stay NULL until source clocks, receiver ready/warm qualification, inherited reset stages and the following output edge are joined. Both clocks stopping, receiver-only warm reset, producer abort, arbitrary retained payload, modulo16 wrap and mixed reset epochs need fixed-calendar proofs; paired reset cannot be assumed without production authority. Any free-running unequal-rate pair is outside the equal-frequency mesochronous D8 model and must be refused.

ROOT review needed: choose this truthful SRAM direction or another legitimate coherent storage architecture, then bind its real macro/ports/root/reset ABI before a bounded default-off source prototype. No gate or full-array build is ready. model.json records the ordered proof/admission ledger and all NULL prerequisites.
