`prototype/native_pg_binding.tcl` resolves actual OpenDB global-connect rules. Native `getInsts` applies the native instance regular expression; **it does not apply dbRegion filtering**. The prototype separately requires exact native rule-region/instance-region identity, matching native connect semantics. It supports exact literal pin patterns with optional anchors and refuses other syntax. It never guesses a supply name or domain from an instance name. Native MTerm POWER/GROUND roles determine which terminals require coverage. Multiple native pins, physical-only cells and clock instances receive the same treatment. Unsupported/unknown pin mappings refuse; they cannot disappear from final coverage.

`ot_pg_prepare $block` creates the map from current native rules/instances. Rebuild after insertion or any rule/region change. `ot_pg_bind_before_protect $mapping $inst` preflights every native PG terminal before changing any, refuses wrong or ambiguous supplies and protected missing bindings, binds only missing terminals, and verifies every PG terminal. The callback never clears protection. Correct already-bound protected instances are idempotent. Its caller then performs the original `$inst setDoNotTouch 1`. `ot_pg_assert_all_native $block $mapping` independently checks every native PG MTerm after final global_connect, using a freshly prepared final map. PSM, conductor/rail contact, shorts and legality checks remain independently required.

At final_connect, run global_connect, prepare a fresh map, and assert all-native coverage before the existing net-only PSM check. Intermediate missing counts remain diagnostics under the frozen flow; no broad all-stage policy change is proposed.
