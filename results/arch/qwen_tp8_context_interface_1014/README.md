This is a distinct, default-off native TP8 control/core interface. It does not bind a cache or adopt a global delivery ABI.

`op_context[15:0]` and `vm_version[31:0]` accompany offered `ib[378:0]`/`ib_go`. They pass the same IREG1 edge as IB/GO. At the actual `u_me` acceptance edge (`rst_n && go_i && ready`, ready = !active && !pend), current context/version and exact post-IREG descriptor are captured. `cx_op_accept` is registered on that edge; `cx_accepted_ib[378:0]`, `cx_accepted_context[15:0]`, and `cx_accepted_version[31:0]` then report the accepted/current descriptor. Payload has no reset and is valid only after acceptance. Offered IB is never substituted for accepted IB. The event remains at its registered level while the core is paused: a live-loader-domain consumer must use a qualified edge crossing or deduplicate by the allocator identity, rather than count each base edge.

`cx_xre[3:0]`, `cx_xaddr[95:0]`, `cx_xepoch[20:0]`, `cx_xjrepeat`, `cx_xcontext[15:0]`, and `cx_xversion[31:0]` are captured by the actual production request-generation always block. Epoch, read mode (`pre-update xjs_r == 0`), accepted context/version and address all refer to the same pre-update query. Read-valid qualifies query payload. A next offered descriptor cannot change a pending old query's mode or identity. XLOCAL1 still requires the registered local response on `x_response`, before existing ME_EXTRA; no response/arithmetic edge was added here.

`cx_core_idle` is the existing registered local ME idle indication. It does not certify that the tile's extra response stages, sources, all cache recipients, or replay fabric are quiescent. Actual cache accepted-fill/response-consume/quiescent events remain to be implemented and source-bound. Global owner must define stable operation-context allocation separately from per-descriptor source tokens, full VM-version freshness, token reuse and retirement.

The raw dispatch cut is 428 bits (379 IB + GO + 16 operation context + 32 VM version). The query cut is 170 bits (4 valid + 96 address + 21 epoch + 1 mode + 16 context + 32 version). Added logical control state is 525 bits before optimization; its actual mapped/CTS census and pin cost need a fresh source gate. The old 25-root parent and historical fixed masters are preserved. This candidate has no newly measured hard views or assigned faces.
