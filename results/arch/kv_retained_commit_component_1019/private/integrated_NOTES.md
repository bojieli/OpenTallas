# Actual ND8 retained commit component integration

The five bounded component scenarios pass on the three private retained-commit clones, the unchanged selected `qkd_host_ctl_service_pins`, `qkd_host_ctl`, and `ot_qfd_pkgctl`, and eight actual native endpoint instances. These are selected SU MODE0 / NSLOT1 / ENG_CTX1 / NW18 / PLB13 / EVQ4 / FMT1 tests. They make no MU4 claim. No public source, generated root binding, default, constraint, or physical view changes.

Cases 0, 1, and 3 use the actual selected dataflow with a conditional component health producer. Cases 2 and 4 additionally use an **alternate retained-controller environment**: both the legacy reset input and observed warm input fall for three edges, but the unchanged controller seam is deliberately bound to raw POR. Its reset binding differs from the actual root. These tests prove only the three clone mechanisms and this explicitly stated component environment; they do not establish whole-controller or whole-root warm-reset retention. Parent's separate unchanged ingress/CSR/reset/PLL/ownership trace owns production restart reachability.

The scheduler's DMA master is connected directly to the actual packet bridge. The independent memory responder supplies descriptor/prompt words through real `0x12` read requests and `0x13` replies. CQ writes leave as `0x14` packets and complete only through matching real `0x15` replies, queue consumption and credit arithmetic. The bridge's low BAR CSR outputs connect directly to the scheduler's low twelve address bits; this is a **component BAR mapping**, not the actual CSR service/mux or proof of legal SYS_CTRL access. No accepted DMA response or endpoint result is fabricated to satisfy a drain assertion.

The unchanged controller creates the actual HC generation/start pulse and consumes all eight actual endpoint TK words through its original reductions. The eight conditional execution producers independently verify `{epoch7,stage0,token42,position0,segment0}` and return `{epoch7,stage37,token42,position0,segment0}`, matching generation, token43, value100, and real request/result credits. Drain inputs are an explicit conditional all-drained producer contract. The package response arrives fourteen scheduler edges after issue. The independently counted controller busy interval is ten edges, including its registered completion reduction; healthy word1 must be `000000010000000a` and word0 `002b000012340025`. These expected words are constants derived from descriptor, producer stimulus and source pipeline edges, rather than mirrors or DUT result observations. All post-fault word0 offers must be error, including a fault after word1; no early success may be hidden by a later error.

Health identity is independently `{zeroextended descriptor client tag 0x1234, owner generation1, slot0, position0}`. This is typed **HOST_DESCRIPTOR_COMPONENT**, not the native TAG59 namespace. Both actual request identities and the host identity are checked for this fixture; the general accepted native-to-host health identity map is still an integration dependency. `H=64` and response deadline48 are typed COMPONENT constants. The health cutoff is asserted before the cut in this fixture. No production producer inventory, regional phase, lifetime or absolute calendar is qualified.

`integrated_compile_manifest.json` pins all exact sources. `integrated_run.sh` records SHA256 inputs before Verilator5.050 compilation and executes exactly these five cases, through unpinned fleet admission (12GB, 8 threads). All jobs are terminal; the remote directory retains objects and complete evidence. `integrated_preserved_iterations.tar.gz` preserves the initial harness failures (a stale, uninitialized independent identity producer correctly caused failure CQ), the diagnostic iteration, and earlier positive snapshots. The first overly specific CQ-cycle expectation and the intermediate oracle using observed package cycles were corrected; the final oracle uses independent ten-edge gold. No failed result is overwritten or recast as a source pass.

This receipt does not qualify production source selection, complete packet/PHY retention, cache poison/lifetime distribution, production health coverage/phase, analog runtime PLL loss, MU4, or any physical resource.
