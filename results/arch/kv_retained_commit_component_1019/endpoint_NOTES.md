# Private retained endpoint component

`qkd_host_native_token_endpoint_cancel_rc` is a distinct selected-SU clone. The original public source is unchanged; `endpoint_original.sv` is its byte-exact proposal snapshot. ENABLE_RETAINED_COMMIT defaults to zero, preserving original reset equations, predicates, state updates and outputs. ENABLE_NATIVE retains its original default zero. No binding selects this module.

The opt-in uses raw_por_n for every original sequential block, including the input-valid/data pipeline and original trace counter. It retains active/pending/issued/credit/seen/done/fault, jobs/epoch/generation/tag, released/cancel identity, request/native-pr/result-credit/TK outputs and protocol fault. Added state is ever_armed_q and sticky bad_q (2 bits); this is a functional state delta, not a physical area/reset/copy price. No new pipeline stage is introduced. Actual landed health/reset timing and the full state/copy/storage model remain integration dependencies.

Port additions use the common raw_por_n, warm_rst_n, pll_locked_i, health_bad_i, health_armed_i, execution_restart_i and role_fault_i names. Health_bad/protocol faults poison directly. Warm reset, original qualified rst_n loss, PLL/arming loss and restart/role faults poison after ever-armed or real owned lifecycle; initial unqualified boot does not poison. Poison clears only through raw POR. External bad inputs can still make retained_bad_o high during POR; the old initial bench assertion expecting otherwise is preserved as a stimulus/oracle error, with health_bad_i explicitly cleared in the corrected POR stimulus.

Same-edge bad_next gates start/accept/issue and new native_pr decoding. It never synthesizes a completion. Genuine matching result acceptance, response-credit return and matching exceptional cancel release remain live under health poison and protocol fault. Public context_owned keeps the original active-or-pending meaning; retained_owned_o additionally includes pending release, unreturned request credit and actual request/result-credit pulses. Real local_tk completion remains observable but its fault field marks poisoned ownership; it cannot masquerade as healthy success. An original protocol error stays sticky while its genuine later matching response drains. Recovery_clear cannot clear retained poison or fault state while bad.

The bench directly drives the conditional endpoint boundary; it does not prove that warm or runtime PLL loss is reachable in the selected unchanged system reset model. Genuine HC acceptance, tag/generation matching, actual producer return and actual request-credit/cancel-drain predicates are exercised without hierarchical state force. The default-off clone is compared against the original source on every output on the same stimulus trace. This is a component receipt, with no MU4, token/numerical, complete cache/transport, global retirement calendar, native physical or whole-root reset safety claim.

RC_MUT changes only opt-in negative controls: 1 resets the transaction island on warm rst_n; 2 suppresses real completion retirement under bad; 3 allows pending issue under bad; 4 blocks cancel drain under bad; 5 restores the old protocol-fault retirement suppression. Each must fail its named assertion in endpoint_run.sh; actual witness logs are committed with the source. Verilator is fleet-pinned 5.050; compilation/simulation runs only through unpinned ot-run at 32GB/8threads, with selected source and bench copied into one self-contained fleet directory.
