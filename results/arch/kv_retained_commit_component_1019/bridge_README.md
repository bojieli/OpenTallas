# Private retained packet bridge component

The default-off `qkd_host_axi_packet_rc` clone keeps the pinned public bridge unchanged. With ENABLE_RETAINED_COMMIT=0, original ports retain original behavior; added health ports do not change original outputs. With opt-in, all original resettable transaction/credit/input-control state uses raw_por_n. `bad_q` and `ever_armed_q` retain sampled failure/restart observation until raw POR. Startup without armed health does not create a warm-reset poison merely because warm reset is low; actual retained ownership activates the lifecycle check.

New queued CSR admission requires armed health and bad_next false. Valid poisoned CSR commands reserve the sole retained ID/op error record on the same edge that consumes their queue entry. They produce real opcode81/82 SLVERR packets using actual TX credits. A full error record holds the next CSR queue entry. Malformed commands never acquire a fake successful response. Previously offered CSR AW/W/AR are unchanged and their actual responses drain. Master AW/W/AR capture remains original reservation-qualified regardless of poison, because only the scheduler may authorize new or drain offers. Valid matching original opcode13/15 responses drain real outstanding owners; malformed and unsolicited replies set fault without clearing ownership.

Emission priority preserves actual CSR responses, then owned DMA reads and writes, then the error record. Consequently a stream of rejected CSR commands cannot starve accepted DMA. No accepted AXI offer is retracted or rewritten by sampled bad/warm/PLL/restart observation. Broken external credits or responses may prevent drain and retain ownership; this component creates no artificial completion.

Added source state is 27 bits: bad and ever-armed2 plus one pending/id/op error record25. No healthy datapath edge was added. Physical FF area, reset/fanout copy cost, clock load, SRAM selection and global latency remain unqualified; the existing finite RX table is unchanged at2048 bits for RX_DEPTH4. No production source manifest/helper/root binding is changed. Actual transport retention beyond this bridge, coherent MU ownership, native health/calendar deadline and local cache poison are separate integration dependencies.

`bridge_run.sh` compiles actual source and benches with fleet Verilator5.050. `bridge_tb.sv` drives real packet headers, real AW/W/AR handshakes, accepted actual DMA responses, warm and health observations. The scoreboard records actual transmitted packets, IDs, data and credits. The cases cover AW-only and W-only capture, accepted read/write drain despite sticky protocol fault, malformed/unsolicited noncompletion, poisoned CSR errors, independent offer stability, rawPOR clearing, finite error reservation and DMA priority under exhausted credits. `bridge_default_tb.sv` compares every original output against the exact pinned original for2000 deterministic stimulus edges; it is a bounded simulation, not formal equivalence. New retained outputs are excluded from that original-interface comparison.

RC_MUT1 restores the old emit !fault gate; RC_MUT2 corrupts error ID; RC_MUT3 launches poisoned CSR commands; RC_MUT4 retracts preexisting offers. Witness logs must show their named failures, not merely a nonzero exit. The initial oracle failure is preserved: it incorrectly expected retained_bad_o low while external health_bad_i remained high during POR. The corrected test removes that external assertion before checking rawPOR clearing. Combinational retained_bad_o honestly includes the current external health observation.

Final measured result: fleet unit `oth-ubuntu-126813-1792445717` on ot-epyc7 returned0 with Verilator5.050. Positive205edges PASS; all22 original outputs match for2000 default-off edges. Four negative controls have committed port-vector traces: first observable divergence edges24 (accepted DMA stuck),38 (wrong error ID),37 (post-poison mutation),63 (offer retraction); assertion edges48,41,41,67 respectively. `bridge_validation.json` pins exact input hashes and witness paths.
