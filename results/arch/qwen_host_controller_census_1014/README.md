# Current native controller variant census

The native HOST integration requires 128 instances of the distinct `qkd_ctrl_pc_host`, which retains the actual 17-HBM-edge ordered static-column completion observer. Its old-controller 246.24 × 172.8 µm outline is an unverified request for this variant. The g9 planner instead used a 247.512 × 377.976 µm frame and generated pins after detecting a view mismatch. Those shapes and pins cannot qualify the native variant.

HOST explicitly assigned this isolated census and port preparation to the die lead. The exact source and ten-file dependency closure are extracted from immutable commit `2cec08fb0fbcdf25bee4ab77b21d9c89cd83ab2c`; the controller body itself last changed at `38d2ef2a9`. The SHA manifest binds every staged source. No source file in the HOST worktree was modified.

The admitted job `oth-ubuntu-3139789-1791979111` ran on EPYC1 with 4 GB / one thread and exited 0. Yosys 0.52, commit `fee39a3284c90249e1d9684cf6944ffbbcbb8f90`, processed the real default parameter set with `hierarchy -check; proc; opt; memory_map; opt; flatten; opt`. The flattened generic state is **12,719 Q bits**, grouped as **9,780 on pll_hbm** and **2,939 on ck**. The public ABI has **939 input bits and 920 output bits**. Both generic trees are below the 15,000-sink screening threshold; actual mapped sinks, clock insertion and spread have not been measured.

Generic output-source tracing finds `er[260:0]` and all three completion outputs directly driven by ck-domain flops. `po[327:0]`, `ko[32:0]`, `fo` and 293 of 294 `co` bits are directly driven by pll_hbm-domain flops. `co[0]` passes through three generic combinational cells from HBM-domain state; it is the landing read-valid path, not a measured pin-register budget. Constants and bit aliases are recorded separately in the detailed census. This conservative generic graph is not a Liberty launch/capture audit or a gate-level delay estimate.

The registered-port request is logical and source-bound. It keeps the two clocks separate, captures actual ci/pi/ki/fi and embedding es on their corresponding physical domains, and preserves the observer's real completion events. Assigned face, layer, range, XY, mapped outline, power grid, CTS and per-pin 220/190 ps budget measurements are all absent. No early credit er[259], fixed parent timer or old view stands in for static-column completion. No physical job or slot change is submitted by this census.

The next bounded-window prerequisite is a constructive native controller placement with actual memory/logic area, clock roots and characterized boundary pins, plus real CDC/controller seam channels. HOST's station and static-arbiter outlines remain unverified. This result cannot be multiplied into a fit or throughput claim for 128 controller pockets.
