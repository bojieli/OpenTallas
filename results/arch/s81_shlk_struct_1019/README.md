This successor splits the shift-add and base-add, keeps same-phase reset copies, and replaces the three runtime payload arrays above2kb with real SRAM. No timing masks or arithmetic change.

`OT_S81_SH_APIPE9` selects APIPE9; `OT_S81_SH_SRAM` selects the SH SRAM/hop implementation. Both are absent from existing production defaults. The common golden dsfd_host_sd is byte-identical.
