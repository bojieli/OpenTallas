# AHUB source successor, fixed actual GEN7 profile

Source-only preflight; no CTS, placement, route, submission, hardened view, or parent binding. The original a7 RTL and views are unchanged. This successor is opt-in through a distinct module family.

The inherited model/proposal is `f6b606d53 results/arch/kv_ahub_safe_boundary_1019/README.md`. The fixed source profile is AP WS/WN/ES/EN `[-40,-40,-38,-39]` (`64'hffd9ffdaffd8ffd8`), FR `-7`, Z stride4, ZW/ZR0, RS/RX/WF1, RY2. These are the actual GEN7 ordered-table constants, not the historical a7 offsets. The reciprocal loop remains71 edges and publication is issue+75; every external event age, port, arithmetic order, fault predicate and reset-release edge is preserved. Unsupported wrapper parameters, generator profiles and source hashes fail closed.

`qkd_ahub_static_dw_safe.sv` is a separate RTL family. Its LM word mux uses same-edge one-hot selection per stack/eight-bit slice, and the reciprocal write bank uses the same local selection structure. Static head elaboration replaces the original guarded dynamic zseen writer references: Yosys had inferred conflicting low/high-head writers despite the guards. Final synthesis now runs `check -assert`. The old exploratory synthesis and its warnings remain in the fleet run's safe1/safe1b logs; they were not admitted.

Synthesis merges identical local selections, so attributes alone did not bound the resulting distribution. The coordinator-approved deterministic fallback is committed as `tools/qwen_kv_die/ahub_safe/distribute.py`, with emitted synthesizable native-cell source `rtl/hdc/nearhbm/qkd_ahub_static_dw_safe_native.v` and profile guard `qkd_ahub_static_dw_safe_gen7.sv`. It normalizes only recognized INV/BUF/HB paths to their exact root and polarity. It partitions loads and duplicates actual native source cells, retaining exact masters and all input tuples. Three monotonic passes reach a fixed point including all newly added D/reset/source loads. Hard children are never copied. Source cells carry keep/dont_touch and were re-read and re-synthesized with ordinary `synth -flatten`; this is not a census of an unoptimized emission.

The independent verifier reads that re-synthesized source and compares all26,226 real input connections to the mapped original, including D, CLK, SETN, RESETN and feedback logic; every original nontransparent cell is represented. Exact same master and full Boolean input relation preserve enabled-reset priority and polarity. There are no explicit mapped initialization bits; duplicated unreset state becomes equal on the first common capture, and asynchronously reset state on its original reset.
