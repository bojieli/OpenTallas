## Whole GQ ownership model before any build

Source structure in rtl/hbm_next/coll/ot_hnx_coll_gq.sv and ot_hgi_coll_aq13.sv exposes independent requirements beyond the worst path:

1. Two AQ blocks each accept 32 FP32 elements per stream edge (1024b =128B); combined input 2048b =256B/edge. Each emits256 code bits,10 exponent bits,512 BF16 bits plus valid/fault; the issue leaf keeps its static two-of-three issue phase. Preserve exact maximum/floor, FP32 scale multiplication, signed exponent subtraction and RNE. No algebraic rewrite or truncation is authorized.
2. Replace each coherent 1024b x9 element delay with an actual SRAM ring. Existing GATED0 hc bank implementation uses 10240 FF per AQ (20480 total incl input/output staging), and a bank pointer bit controls 1024 data enables. A transparent buffer tree or renamed banks does not meet the source rule. Logical payload is9216b/AQ; physical depth, width banking and port concurrency must be priced from native macro contracts. Avoid coincident same-address OLD: distinct read/write rows and explicit registered stage accounting, or a characterized macro with proven OLD. SRAM timing currently remains unqualified. No zero-cost SRAM timing or automatic D-1 conversion.
3. Descriptor rf[16][137] is2192 runtime-indexed bits, also requires SRAM. Current calendar reads cur and launch reads base/per. Choose one read port with a separately installed launch-period scalar (16bits) or explicit dual read macros; hold the current row in a register and prefetch next row before fire. Configuration/launch overlap must retain current checks. At least one genuine read-capture edge must be installed in the compiler calendar; adjacent-row same-edge behavior must be proven, not presumed.
4. TT structural candidate: split S9 into signed ev formation and subsequent dd/clamp/shift-count. Additional minimum register payload per AQ is32*(11 ev +24 significand +1 sign)+13 valid/fp4/nf/e =1165bits, total2330FF. Make the S8 exponent a genuine retained same-edge local result for each element:32x10 per AQ versus10 now, +620FF total. Those D cones require ownership all the way back through scale exponent/product and format controls, including reset. Blindly duplicating Q with one common high-fanout D is insufficient. Count every driver BUF/INV-transparent and prove <=32 on the whole mapped graph before a gate.
5. This split increases AQ latency13→14, II1 unchanged by construction only; all downstream QBG capture, pp_code, exponent packing, VM/ring calendars and drain must move coherently. Minimum QBG record exposed cost is one stream edge (834ps in the measured PLL vehicle, nominal833.333ps) before descriptor/memory stage changes. Further rows retain payload3K/2 only if the full calendar proof confirms it. Added stages increase exposed span/occupancy; no current token rate is claimed.
6. FF q→aq_q_q is an existing real boundary. A successor must jointly retime quantizer output ownership and code assembly or install a real owned landing-storage stage with its added edge/calendar cost. Arbitrary data logic/delay cells are not a structural solution. Exact choice and price remain OPEN, so this model is not ready for RTL/gate. Fallback is a hard AQ child with native neighbor references and landed code/exponent crossing, priced for all added edges and 2x1290 child pins; if footprint fails, split issue into control plus two physically adjacent AQ children. No same-source timing-knob retry.

Async assertions and release over ring pointers, valid/fault state, target and local ownership copies require original-phase lockstep. All >=3 control delays need genuine independent pointer rings.
