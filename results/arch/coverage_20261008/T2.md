# T2 coverage: DeepSeek-V4.1-Flash on the DS ROM S81 array (AR + MTP)

Stream cov-T2, 2026-10-08 (PT). This pass only looks for gaps; nothing was fixed. The method is `/home/ubuntu/claude-takeover-20261007/coverage/METHOD.md`. The node-by-node ledger is `T2.json` in this directory: 97 nodes, and 95 of them have at least one gap.

## How the graph was built

The graph was derived from the model first, not from the hardware lists. Two sources define it:
- the released config `compiler/models/deepseek-v4.1-flash/config.json`, which sets:
  - 40 layers;
  - `compress_ratios` 0/0 then 2 on L2–L19 and 1 on L20–L39;
  - KV sources L2/8/14/20, index sources L2/8/14/20/24/28/32/36 and the candidate source L20;
  - Engram on L1 and L14;
  - hc_mult 4 with 20 Sinkhorn iterations;
  - 384 experts, top-6;
  - DSpark: 3 stages, block 5, targets L37–L39, Markov rank 256, 128 experts, top-3.
- the arithmetic golden `tools/hdc_golden_v41.py`:
  - for a decode step: `Model.layer`, `attention`, `compressor`, `indexer`, `candidate_blocks`, `attend`, `moe`, `engram_layer`, `hc_mixes`, `forward_positions`;
  - for MTP: `dspark_seed`, `draft`, `generate_spec` and `truncate`.

The ISA is `results/rtl/hdc_v41_mtp_isa_evidence.json`.

Each operator was then matched to the following:
- **Die recipes:**
  - the S81 layer1 m221pq floorplan and its 145-master view index (`results/rtl/s81_die_view_index_20261008/index.json`);
  - the head-die plan (r9m215khdc);
  - the rack, `results/arch/dsrom_s81_rack_20261006/rack.json`.
- **The closure loop:** `/api/elements` read at 2026-10-08 22:00 PT, with 271 rows.
- **The token-path views:**
  - `results/arch/token_path_20261008/ds_rom.json`: AR, 828,878.4 cycles, 1,447.7 tok/s;
  - `ds_rom_mtp.json`: one MTP step of 1,146,896.4 cycles, τ 4.159, 4,351.6 tok/s.
- **Audits, logs and system-RTL records:** MTP_AUDIT.md, COMPLETENESS_AUDIT.md, the mtp-rom / mtp-die / mtp-exact / engram / s81-dies / ingest logs, and `results/rtl/dsrom_system_rtl_20261003`.

**Cycles.** A node's `cycles` value is its critical-path contribution, attributed by regex over the token-path node ids. The note on each node also gives the off-critical sum. Only two nodes are aggregates and are excluded from this sum: C12 (all collectives) and C13 (all hops). Without them, the decode nodes attribute 828,866.4 of the 828,878.4 AR cycles (12 cycles of rounding).

**What the evidence does show.**
- Every backbone data operator of one AR decode step has RTL and a bit-exact bench at full shape:
  - field phases: 19,312 region runs on the released weights;
  - SU chains: wired RTL;
  - select tree: all 40 layers at 1M;
  - candidate select, head bundle, TP4 collectives, link_rt.
- The control plane passes an end-to-end functional token simulation (`results/rtl/dsrom_system_rtl_20261003/system_gate_*.json`). That simulation covers:
  - host queue, package controller, stage guard, link replay with injected CRC errors;
  - KV in a timed HBM model;
  - 2 users and up to 4 positions.
- **That system simulation runs on the reduced V4.1x HDC-core array, not on the S81 field / hub microarchitecture.** No S81 die carries any of those control blocks, and no S81 run issues a whole layer as one sequence.

## Points the hardware lists missed (found top-down)

- **Main-hidden capture at L37–L39.** It happens on every verified position (M01 / M02). Neither the S81 composition nor the MTP view has a node for it.
- **The ratio-2 compressor open slot is rollback state, not only a dead row (M22).** `Model.truncate` rebuilds it from `slotrec`. The dead-row invariant covers HBM rows only.
- **Speculative Engram history (M16, M24).** Draft tokens enter the n-gram hash of positions q+2..q+6, so a rejection must restore the history. The restore exists only as testbench logic.
- **Stop condition (C14).** The stop is a fixed `gen_len`. No EOS compare exists, and γ is not clamped against `max_seq_len`.
- **RoPE cos / sin (C09, B03).** They come from an HBM table that nothing loads at boot and that no token-path node reads.
- **Selection reuse across stages (C10).** Layers 3–7, 9–13, 15–19, 21–23 and so on reuse an earlier layer's top-512 selection. When the source layer is on an earlier stage die, the selection must travel with the hidden state, and the hop payload record does not show it.
