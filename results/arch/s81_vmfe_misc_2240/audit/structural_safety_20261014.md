## Concrete safety conclusions

- Numerical correctness, a local timing gate, global geometric legality and actual native timing are separate obligations. Current packets preserve these distinctions. Positive TT/FF with negative SS is reported explicitly, including the newly CLOSED FCN command-stage route.
- CDC changes retain writer ownership, stable payload until consumption, every-step Gray publication, actual first-stage synchronizers and real per-domain reset. No new whole-clock false-path/group waiver was added for these repairs. Existing broad raw reset exceptions still require the true refclk driver, phase and mapped-pin analysis.
- Reset readiness observes real final local reset/live state and raw epoch in the consumer's actual source clock. Missed stopped-clock pulses leave ACK low. A constant delay, `t_rdy`, receiver-clock label, external reset mirror or producer planning artifact is not a readiness/clock-binding substitute.
- Fixed nominal **TT** clock reference is used at both TT and FF in the BGR diagnosis; actual per-corner residuals are retained. Driver-delay changes that improve one corner but break another are preserved as rejected experiments.
- All physical successor requests preserve historical CLOSED views. New raw/ACK ports or source definitions require new source-bound physical interfaces; a preexisting CLOSED view cannot qualify extra ports/FFs. Shared rstsync ACK parameter defaults to zero, including a proof under simultaneous HROW/SPVM guards.
- Actual unselected variants are recorded separately: MD9 and EP1/MD11 BE, NS2 BGH, H1/H2/MC40 alternatives, retired idx_ksub, host_protected/PINREG2 selection questions and six SU rows. SU ownership stays with the ROM/die leads. Parent closure is not inferred from those classifications.
