That plan uses the older priced SU/collective durations. `dv_layer.py` composes different durations but does not feed that fixed-issue emitter. Its own source labels admit that tile_first40 is a parameter and native KV attention is priced, not measured. Therefore the four mismatches cannot presently be genuinely resolved by substituting the composed numbers.

These are source arithmetic, not qualified producer deadlines. HEAD0=3 is the existing same-clock compiler convention; it does not convert W5 edges into CTLM cycles across regional clocks.

Do not infer first write as `done-16`, nor apply the current global `su_first_write=12` to every family. `ctlm_image.py::xpf_ev` currently does both. Dynamic trace observations validate a statically emitted graph; they must never supply a run-time waiter or substitute counter reset phase.

Retain the 406/1009 body and exact ROM hashes while collecting these relations. For each selected XPF head, the generator must enumerate ALL actual writes covering the consumer's x address set and their transaction owners. Initial QKV needs the actual INIT/embedding or prior-stage residual publication and its persistent handle; it cannot be assigned the current layer's unrelated event merely to remove the qkv/GU compact-ID3 collision.

For a private four-record minimum with proved one-producer-per-epoch coverage, existing records stay188 bits and the12-bit identity field changes semantics under an explicit opt-in ABI. ## Phase, reset, installation and actual first use

Source graph phase contains actual rising/falling edge, local cycle origin, clock net, reset root, reset release event and every relay/landing epoch. The selected CTLM n_clk_r54 / n_rst_seq_ctlm__t25, reset relay r55, and SYSFACE n_clk_d2d / n_rst_d2d__fo2__r4__t24 are distinct. Internal XPF monitor_rs adds its actual reset synchronization. For a common-clock subgraph NBA capture relations can be derived; for a ring crossing the relation depends on its actual write/read resets, pointer warm state and regional phase. Keep that relation unresolved until the real crossing proves it. Hash a canonical manifest only after checking every required field is populated and every dependency is proved; hashing null fields or all-zero placeholders is not binding. Keep measured native insertion/skew/setup/hold in a separate manifest with NULL until native evidence exists.

Use the existing qkd_program_commit sinks/join: BEGIN already revokes source ready. The cfe2 84-bit install sideband must travel with the exact PW/DW payload through the same launched/captured bundle. At each local destination, BEGIN or PW0 revokes eligibility before any start; auth must match the locally installed context/image and all39 template words plus actual final PW/DW receipts. Reinstall requires all genuine reader handles drained. A same-edge revoke/start is a causal fault, not an implicit successful withdrawal. A stopped destination cannot be assumed to have seen BEGIN. Its first resumed use requires the transported revoke/reset and fresh local seal, or the statically scheduled source must forbid that start with a proved epoch relation. No extra handshake delays data; inability to prove a fixed legal first start rejects the profile.

First-use observation points: actual resource `go&&ready`, actual first operand capture, first template write indexed by record_index, first pick/pending_user read of rr and first active/cycle feedback. Preserve 5a3 arbitrary-old-Q first-edge failures: same canonical next-D does not make same-edge consumers equal. No internal copy repair is enabled by this proposal. Carry last-read markers through actual ME MEM_PIPE and actual XPF request/leaf/QD capture; `busy&&last` freeing XPF st is earlier than the final leaf read and cannot release the context. Native/stopped-clock/reset-epoch and complete source first-use remain HOLD.
