Optional capture-before-select retiming for the measured ROM→CID critical path. The register cut moves from the selected CID output to the 32 bank/word choices and a same-edge saved tag. The pending enable is unchanged, so held CID values, output dates, reset windows and static schedules remain identical. Defaults preserve the previous design. One map word per clock; +612 analytically counted FF, zero public cycles.

The actual source helper is extracted by eng_tmap_capture_eq.py. All 34 outputs (17CID+17SEL) match on every one of299985checkedcycles across3seeds, with resets, stalls and legal/invalid commands. A wrong-tag negative control fails. Native synthesis, actual bank-local F6 placement, CTS, route, LEC and TT/FF signoff remain required; this is not a closed view.
