# Source-owned tag lifecycle component

Next bounded component owns all32 actual owner tags: valid, generation12, length3, seen4 and sticky fault. Per-entry first-Q capture of allocation tag17/length3/valid and return tag17/beat4/valid bounds each external input root to32 actual D sinks. Each entry has independent kept hierarchy; local predicates update<=20 state bits. Immutable generation/length are deliberately duplicated here (480bits total) to validate consecutive beats without a delayed read/update hazard. This is paid state, not an unpriced table replacement.

At H0 each entry captures actual allocation and response controls. At H1 exactly the matching entry accepts a legal response, updates seen and clears valid only on the last required beat; it faults wrong generation, duplicate/out-of-range beat, inactive slot and same-slot allocation/response collision. A vector of32 accepted-entry Qs is the H1 result; a registered OR publishes the scalar at H2. Later owner composition must align these events with actual metadata/data rings and static reserved link delivery. The source must not speculatively advance seen while an unpriced downstream rejection can occur. Reset clears validity, event qualifiers and faults asynchronously and releases in two edges; unreset metadata is always initialized before validity. Reset does not authenticate a stale PHY response identical to a new post-reset tag: real PHY flush remains a parent contract.

Retained model per entry:17+3+1 allocation capture,17+4+1 return capture, stop capture1, generation12/length3/seen4/valid1, response accepted1 and sticky1 =66FF;32entries2112FF plus32 second-stage reset FF,2 retained first-stage roots and scalar output/control. No runtime-indexed table exceeds2kb; no payload shift delay line is introduced. Clock roots and <=405um source reach remain physical obligations. Dynamic readiness/issue publication, full owner composition, issuer/cohort and collector remain OPEN. Source tests must include finite32slot capacity, all lengths1/4, arbitrary beat permutation/back-to-back same-tag beats, duplicate/wronggen/range/collision, generation reuse and occupied reset.
