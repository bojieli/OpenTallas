# Native frontend source plan

Model precedes RTL. Four distinct owner-to-pair links replace the global eight-bank/four-owner response mux. Link j has only owner j as producer and only banks j and j+4 as destinations. It preserves the full 285-bit ordinal/bank/epoch/data packet. The ring also captures explicit target and two preallocated target permission bits (288 total); the permission is a static reservation promise at injection, not reactive ready/backpressure. The first bounded implementation proves this boundary; it does not qualify the current unsafe issuer, PC owner, collector or crossing clocks.

The link is a four-slot indexed ring (1152 data bits per link), not a shift register. Forty-eight <=6-bit slices retain separate two-bit write/read phase registers. Ring data is unreset; validity is reset and reset cancels all occupied traffic. A separate output Q adds288 bits. Each link has at least192 local pointer FFs,4 ring-valid FFs, one output-valid FF, and51 reset-state FFs. Exact retained controls and mapped loads replace these estimates before admission.
