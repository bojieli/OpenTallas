# HC and norm takeover evidence

Current main contract v12 contains four `hfd_hc` reservations, 352 legacy `hfd_hc_tile_xl` child slots, and one `hfd_hc_eng` reservation. These legacy shell reservations do not prove functional native HC coverage. It contains no norm master slot; the 1,612.656 x 972 norm candidate frame is a handoff only. Accepted norm children remain untouched.

The retained HC B2 engine bench used RP=8/W2=8 on the original VM unit, whose core derives complete lane groups as RP/32 and W2/32. Both counts become zero, so preload and engine writes/reads cannot be accepted. Existing runs showed preload hangs before the engine cases. Source `7103633eb` corrects only that backing interface: each local eight-bank memory is embedded in native banks 0..7, with local `{row,bank3}` converted to `{row,00,bank3}`. Capacity checks reject addresses above 8191 and wrong-lane traffic. The original ECC, credit, macro, arbitration and read/write latency paths are retained. Exhaustive address checks cover all 8192 local sectors and prove unique bank/row identities. This is a test backing-memory adapter and does not qualify production VM8 composition.

Recovered engine and collector candidates come from `claude/el1013-hbm-hc@52163bbcc`, restricted to the seven source/bench/vector files. Neither engine RTL nor its mathematical golden was changed. Exact and bank-association mutant runs use 4000 engine watchdog cycles: a hang remains a failure, while successful cases measure their true cycle count. The original 200000-cycle preload watchdog remains. Original live simulations are preserved.

Closed norm gtile8 has TT +52.14 ps, FF +16.16 ps, DRC 0. Measured child insertion is TT 460.9 / FF 376.7 / SS 598.7 ps; boundary spreads are 32.9 / 29.6 / 40.0 ps. Its future parent must provide independent child clock entries and earlier trunk taps with the real insertion metadata. Common parent-pin phase is not adequate. No norm route was submitted because there is no current die slot.
