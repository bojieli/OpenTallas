Compact-first SM transport candidate

The old `pt_w` / `pt_e` hard frames consume 2.953 mm2 per SM because their 3,705-bit transit bus fits on one pin layer. Those modules also implement four transit edges, a first-edge landing to each leaf, valid reset semantics, and separate reset release at each west/east module. Removing their boxes cannot remove those registers.

`OT_SMH_COMPACT_PT` selects the new wires-only west/east transport parents in the real hierarchical SM tile. Include `rtl/hbm_accel/sm/ot_hbm_smh_compact_transport.sv` alongside the ordinary SM source when enabling it. Default SM RTL and every closed kernel leaf remain unchanged. The replacement factors the buses into 128-bit register slices, including width tails and valid/x_ce reset masks. West beat landings have distinct north/south slices; transit remains four cycles and leaf landing one. Reset release uses the original `ot_rst_relay` depth in every slice.

Run `python3 tools/bench_smh_compact_transport.py` for the production 1,636-bit row input / 2,069-bit beat input against the original west/east module bodies over 4,096 cycles, with mid-stream resets. `--no-reset-relay` proves the alternate original mode. `--mutant` bypasses a transport register; it must fail the exact same comparison. Builds and simulation run through `ot-run`; its shell removes only its own terminal temporary build directory.

This is an RTL candidate, not a published physical replacement. `candidate.json` gives the die lead all 96 slice instances and ranges per tile and the retained closed kernel outlines. The die tools still need to assign slice pins, signal layers and exact origins. Hardened slice wrappers, mapped areas, port capacity, local clock roots with phi-R arrival, native launch/capture/reset checks, same-domain timing, hold pads, complete cut windows, parent exact/cost proof, and slot fit remain required. M6/M7 over-kernel routing requires actual obstruction/PG-aware permission and verification. Every old kernel child remains a real closed view.

The remaining 4.285 mm2 of closed kernel/front/back leaves excludes the replacement transport state. The old transport cells alone occupy 0.126336 mm2 per SM, or an illustrative 0.280747 mm2 at 45% cell utilization. The compact slot must reserve that state plus reset replication, parent state, wire channels, clock/PG and legal placement. No 4.3-mm2 fit, routed closure or throughput qualification is claimed.
