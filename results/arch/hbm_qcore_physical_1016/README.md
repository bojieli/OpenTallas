# HBM qcore native physical candidate

The source-bound native mapping has **76,220 flops and 339,152 cells**, with **52,285.27976 µm² total area**: 44,502.12584 µm² standard cells and 7,783.15392 µm² in **two actual reducer 128×256 SRAM macros**. The 64 RF banks are small flop structures, each with six bounded four-word payload replicas; they are not 64 SRAM macros. The native shared keep-register hook preserves all declared payload copies.

The candidate outline is **330.48 × 330.48 µm**, about 49.2% core fill using that measured mapping. It supersedes both the original 250 × 2671.92 µm reserve and the first 276.48 µm square sizing estimate. The preliminary generic mapping reported 38,176 flops / 37,186.64 µm² because its staging omitted the shared keep-register hook and allowed identical copies to merge. Those original records remain diagnostic evidence; they are not the native physical footprint.

The production source baseline is `a89a10d1f`, `MUT=0,COLLPORT=1`. Its actual input-to-fault path had ten logic levels and its input-to-RF-bank write capture had eight. The opt-in `PHYS_RF_INGRESS=1` correction captures the raw RF/read/relay/RR inputs at actual `clk_ctl` pin registers, then bypasses the matching existing RF bank input rung with `PIN_RUNG=0`. Normal RF commit remains n+1, qcore RF read output remains n+3, and reducer scalar output remains E+11. Defaults preserve the original integrated source. The write-conflict sticky fault flag alone reports one edge later; the bench checks the exact exceptional edge. No production scheduling, ready or backpressure mechanism is added.

The component bench instantiates the complete real qcore, RF, reducer, FP32 arithmetic and real SRAM functional models. A second complete real qcore/RF copy preserves the exact original S source, changing module names only. The native candidate matches every output on 1,108 normal edges and passes 4,514 checks, including 1,024 RF word checks, seven exact scalar returns and five guard cases on the same 1,164-edge timeline. Legacy default mode also passes. The new MUT256 control retains both input rungs and fails 1,217 checks. Drain-source, RF-valid-tag, SFU-operand and RR-bank-order mutants remain bound to physical route jobs.

The actual clock topology is 64 RF roots plus `clk_ctl` and `clk_red`. Physical timing uses the 900 MHz serial period, 1111.111 ps, with 961.111 ps available after setup uncertainty and skew allowance. All roots retain related phase-zero operation and actual per-root phi-minus-insertion delivery. The RF raw input capture endpoint in the new option is `clk_ctl`; its next-edge commit paths to all 64 real RF roots must also be measured. A synthetic direct input-to-bank capture arc would be wrong.

The proposed master has the RF relay tuple and captures on N, RR/SFU on E, and slice interfaces on W. RF clock bits span E from 5 to 244 µm across the RF body; RR/SFU pins use E from 247 to 327 µm beside the reducer/front. The proposed SW parent home is (12313.64, 7619.84), preserving the N boundary at 7950.32 µm. Parent geometry study `1c372d83f` supports this as a diagnostic overhang above the low join column without die growth; it is not physical adoption. Parent instance mirrors must transform every real signal and clock pin together.

The first native attempt rejected `rst_n` because its actual synchronous data endpoint is the reducer clock, while the spec assigned the controller domain. It failed before floorplan, so **no actual placement PNG exists for that attempt**. Its exact source snapshot, native synthesis report and refusal are preserved here. The successor assigns that input to its actual reducer domain and enlarges the outline from the measured retained-copy area. It does not alter the reset signal or waive any timing check.

**Not qualified:** this evidence proves component source behavior and records an actual native mapping. The real compact gate, per-root insertion, native port/internal timing, routed TT setup, FF hold, DRC and parent RF36/slice seams remain required. It does not establish whole-SU or whole-die closure. The existing XC route and its artifacts are unchanged.
