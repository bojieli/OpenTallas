# Full mapped provider physical import

This private helper carries every mapped FF, combinational cell, counter, reset cell and inverter into the physical source. It does not infer physical cost from a FF-only rectangle. No shared flow file is changed.

1. `export_constraints.py` reads actual OpenDB LEF dimensions/pins, placement rows, existing clock cells, actual lower-layer PG/OBS and planned hard-core/PHY halos. It mutates nothing. Future exports pin the exact input ODB hash.
2. `make_budget.py` writes an explicit inventory-pinned, all-cell stage allocation under the owner-declared policy. A changed/reset-expanded inventory invalidates the old budget. QC's declared diagnostic policy is18x4.32um perstage, roots32x8.64um. KV proposes all body corners<=25um Manhattan from each actual clock node, with350um point reach reserved to400um after two25um endpoint moves.
3. `plan_place.py` allocates ALL mapped bodies on actual technology row/site dimensions without moving existing cells or overlapping hard cores/halos/PG. Original stage FFs prefer their declared FF rectangle; fresh explicitly tagged `role=reset` cells use additional rows. No reset role is guessed from an anonymous synthesis name. Actual soft OBS collisions are emitted as pending explicit island requests, never ignored for an actual import.
4. `emit_islands.py` writes the existing `ot_island_windows/1` type-union request and exact part/type/type-frame/die-frame body records via the existing explicit island constructor. It never edits a LEF or cuts a hard core. The die owner regenerates the soft abstracts and grafts the same frozen clock bodies into a fresh source.
5. `reach.py` traverses the complete mapped combinational graph between actual FF LEF pins, including output inverters, reports every registered reach and preserves unresolved external boundary bits. It records actual clock-load pin shapes separately. No external boundary is assigned zero distance.
6. `preflight.py` checks the fresh actual lower OBS/hard keepouts/PG/body geometry, mapped JSON vs exact inventory wiring, actual source hash, and explicit topport-to-native-net bindings. Missing clock/reset/START bindings, undriven mapped bits, mapped constants, alias shorts, old raw-reset stars or stale source/budget inputs HOLD the import.
7. `apply_cells.py` requires clean fresh-source preflight plus a visual review record. It preflights actual LEF masters/pins and placement rows, verifies real native boundary drivers, appends all mapped cells/nets and explicit supply bindings, and checks every original cell/master/position, native ITerm connection and existing wire/pin record remains unchanged. It exports actual all-cell bodies, actual added clock loads, actual PG contact shapes and mapped-bit/native-net correspondence. Actual all-cell import is still NOT RUN until a freshly regenerated source and corrected bounded reset/boundary bindings are supplied.

Boundary binding schema is `ot_provider_boundary_bindings/1`, with `source_odb_sha256` and `ports`: each exact mapped scalar topport maps to `{ "net": "actual_existing_ODB_net", "role": "clock|reset|start_input|start_output", "native_endpoints": [{"inst":"actual_inst", "pin":"actual_pin"}] }`. Existing aliases must name the same actual native net; the importer does not merge frozen nets or invent boundary drivers. Fresh reset source is owned by KV/QC, not this importer. All outputs need actual producer connections; fake primary-input placeholders are rejected.
