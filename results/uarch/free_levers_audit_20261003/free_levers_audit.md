# Free-lever audit: V4.1 ROM (also Qwen ROM and HBM), 2026-10-03

This audit looks for gains that already exist in source but are not used: a field cap that splits an operation, a default-off path, or an emitter that does less than the model assumes. Each lever is priced against the V4.1 ROM model token at 1M:

- **Basis:** `results/uarch/v41_rom.json`, design `proposal`: 262.55 µs at 1.0339 GHz, which is 271,449 cycles. The 1% gate is 2,714 cycles.
- **Data:** `free_levers_audit.json`, regenerated by `bench/price.py`.
- **Boundary:** every lever below is a gap between the RTL program and a model that already assumes the fused behaviour. Closing a gap brings the RTL token toward the model rate; it does not raise the model rate. Nothing is adopted and no default has changed.

## Result: there is no AR256 analogue in V4.1
- No descriptor or ISA field width forces a serialized split in the shipped V4.1 program. The FULL profile has 21-bit counts and 30-bit addresses.
- Two fields sit exactly at their caps. Any growth in shape would split there first:
  - `he_k` 2,560 = `KCMAX` (`ot_hdc_core_v41x.sv:1178`);
  - `COLL_TOPK_MERGE` n = 2,048 = cap (`hdc_replay_v41.py:346`).

### 1. Same-x phase merge (measured)
**Emitter.**
- `hdc_replay_v41.py:781-793` (`project_gate_up`, exact-TP) emits w1 and w3 as two LINQ ops. In the bound L20 trace these are PCs 84/85 and 97–124.
- wq_a and wkv are likewise two ops, at PCs 7/8.
- On the W17 runtime die every LINQ op runs on the ROM field through `ot_v41_rom_adapt` and the spine. The spine runs one phase at a time, and each op is one phase (key = weight base).

**Model.**
- `decode_critical_path.py:1069/1201/1214` (`a_proj`, `shared_gu`, `experts_gu`) prices each pair as one matvec.
- The bank map (`v41_rom_ksplit_bankmap.py`, phases `a_proj` and `gu` = w1+w3) does the same.

**Hardware.** It already supports this: a phase may hold several matrices that share one x, which the gate's own `fp4_expert110_w1_w3` case already uses.

**Bench.** `measured/phase_merge_flat_bst{2,17}.json` runs the flat W17-runtime field RTL on real layer-0 slices. At BST 17, the routed broadcast depth:

| pair | split (2 phases) | merged (1 phase) | saved |
|---|---|---|---|
| expert 110 w1 + w3 (12 + 12 rows, K 5120, FP4) | 282 + 283 = 565 | 290 | **275** |
| wq_a + wkv (8 + 8 rows, K 5120, FP8) | 288 + 291 = 579 | 309 | **270** |

- **Exactness:** 80/80 golden rows bit-exact, and the merged rows are bit-identical to the split rows.
- **Where the cost goes:** a phase costs about 200 fixed cycles (configuration, x load at 64 elements a cycle, broadcast, return drain) plus about 80 stream beats. Merging removes one whole phase.
- **At BST 2** the savings are 260 and 255 cycles.

**What remains.**
- A default-off emitter option: one op per pair, with KVAL allocated directly after QAL.
- Merged phases in the die images.
- A W17 runtime layer A/B, because exposure on the critical chain is assumed, not yet measured.

**Area:** none.
