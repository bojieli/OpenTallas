# Selected scan codec handoff

Confucius owns corrected scan insertion, real restitch, ATPG, scan-off equivalence, and route. Codec source is `rtl/dft/ot_scan_edt8to1.sv`; use ENABLE=1, CHAIN_COUNT=32, CHANNELS=4 only after a real 32-chain restitch. ENABLE=0 is the default and emits no scan drive; the integration owner retains the original scan path until selecting this codec. Existing 31-chain binding may use CHAIN_COUNT=31 but its ratio is **7.75:1**, not 8:1. Pinned scan, element and shared ATPG sources were not edited.

Ports: clk/rst_n, scan_en, pattern_reset, edt_in[CHANNELS], chain_out[CHAIN_COUNT], chain_in[CHAIN_COUNT], edt_out[CHANNELS]. No generated clock, seed port, tail masking, counter, or serialization. All internal chains shift on every actual scan edge. Fixed zero seed is deliberate; arbitrary dense patterns need not be encodable.

Edge sequence: set scan_en=1 and pattern_reset=1 for one **real shift** edge. chain_in is physically zero, edt_out still compacts the OLD captured chain outputs; the codec state clears on that edge. Then deassert pattern_reset and apply the L encoded words on L shift edges. Captured response observation starts on the reset-shift edge and continues through the next L-1 edges; the final load edge is not an old captured response. Then perform the existing real capture sequence. Never add a functional edge just to clear the codec. Pattern latency is L+1 shifts plus actual capture/control/flush edges, not an 8x clock reduction. Actual L remains the restitch owner's measurement.

Bit indices are low-bit first. For chain c, phase bits are state[(7c)%64] XOR state[(7c+19)%64] XOR state[(7c+43)%64] XOR edt_in[c%CHANNELS]. At each non-reset shift, low state bit j becomes old state[64-CHANNELS+j] XOR old state[32+j] XOR old state[16+j] XOR edt_in[j]; higher state bits shift upward by CHANNELS. Compactor output j XORs every actual chain_out[c] with c%CHANNELS=j. It is combinational; compare its preedge value.

`tools/dft/edt_pattern_encode.py` exports encode(load, channels), decompress(words, chains, channels), compact(response, channels), response_check(good, faulty, channels), and import_gate(path, scanpath, pattern, channels). The GF(2) solver starts from the fixed zero state and eliminates only explicit care equations, then replays every care bit. UNSAT returns the cycle/chain witness and CLI rc1. No dense input is converted to don't-care.

CLI `--input cube.json --output result.json`: cube has chains, channels, load[cycle][chain] with 0/1/null, optional good_response and fault_responses {fault_name: response}. Caller supplies actual capture/fault responses under the full edge protocol; generated component fixtures do not establish ATPG coverage. Alias/lost detection causes rc1. Result reports only PASS_SUPPLIED_RESPONSE_SET for the supplied set, never 95%/99.5% coverage.

CLI `--gate-dir DIR --scan actual_scan.json --pattern INDEX --channels 4 --output result.json` imports the existing gate_sim load.hex/unload.hex/mask.hex, retaining its actual polarity and cell order; shorter-chain load padding alone is unconstrained. Imported response starts at the reset-shift edge. Response masks are tester compare validity, never hardware masking or substituted values. Real shorter-chain/tail/new-load effects must be supplied by the integrated simulator when asserting expected bits. Unknown XOR inputs propagate in RTL and invalidate the affected tester bit. Any fault with aliased/unknown-only observation is not credited. Legacy independent PPI ATPG and old wrong-source coverage remain historical.
