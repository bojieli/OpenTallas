Source-owned RD64 return / VM calendar support for Nash, Rawls and Arch

This package adds only a symbolic control calendar, tests and source-pinned evidence. It changes no reducer, VM, tree, current wrapper or running job. No arithmetic, leaf gate, compiler or simulation is run here. Source snapshots bind base 3467bcd0831c29d3eeb1463b84f05f779cc0526e; they do not enroll the selected current combined-top binary/program.

At edge N, consumers sample old signals. Registered NBA outputs are available to the next synchronous consumer at N+1. With RD64/RST1/BYPASS1, aligned sibling FIFO inputs take seven edge intervals to the next stage acceptance (one FIFO residence + five adder registers + RST1). Complete bypass takes three, lone incomplete WAIT2 forwarding five. These exclude extra queue residence. Root complete FIFO input reaches spine capture at N+2 and legacy VM post-NBA write at N+3. Root sibling re-add has an extra registered adder launch: second sibling input to legacy VM is nine intervals if the first sibling is already buffered and there is no queue wait. Six all-sibling tree levels plus complete root/spine/legacy write take 45 intervals from first node acceptance; seven take 52. These are conditional path calculations, not a GO deadline or timing closure. Padded return-leaf geometry, not active element count, determines levels.

Root return has no ready: each physical PAR2 island can emit 64 rows/edge (4416 record bits), both 128 (8832 bits). The source permits consecutive complete results. The retained legal control calibration injects two complete rows/root on consecutive edges, yielding 256 rows at spine sampling edges 2 and 3. Reserving only the peak 128 seats rejects the second edge. Reserving 256 captures both but leaves all 256 debts pending; this is NOT VM completion. Continuous worst-burst length for the actual selected phase still requires its admitted row/root plan and accepted journal. Neither FIFO depth nor the 128-row peak supplies that length.

Native field writes are grouped into 512-bit words: bank=(scalar address>>4)&3, not scalar address&3. Batch count is max distinct words in any bank. Aligned contiguous 128 scalar addresses require two batches; a maximally bank-concentrated packet requires 128. Provider earliest retirement has elapsed 1+6B intervals, inclusive 2+6B service edges (13/14 for B=2; 769/770 for B=128), excluding grant wait, related-domain transport, checked mutable-protection validation and sink stalls. This is a no-external-stall raw-provider calculation; unbounded refusal is never made finite by this model. Raw accepted N yields raw visibility receipt post-N+3, read reply post-N+4. That raw receipt is not checked winning publication. The related interface has one owned field transaction; D4 transport depth is not four transaction credits. The current owner is 228 bits and the field payload is 8064 bits.

`capture_calendar(events,releases,seats,roots)` replays a supplied single-phase source-domain stream. Release requires a matching captured row, separately supplied checked-visible edge, and strictly later captured-credit edge. At an edge, arrivals use old occupied seats before credits return; same-edge freed-seat reuse rejects. Duplicate root pulses, duplicate phase rows, wrong-row/shard-root identity, duplicate release, raw-only visibility and nonpositive feedback reject. Source clocks/reset/context enrollment must be checked by the caller. This checker does not manufacture the missing callback qualification.
