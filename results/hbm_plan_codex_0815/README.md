# HBM folded-plan work while Claude is limited

This is a source and diagnostic package, not a routeable plan. `status.json` names the open failures and owners. The complete fleet candidate remains outside the release tree until the ONE HBM plan event has its native quarter/VMS/SM/FUSED composition and geometry.

The existing pin-window census found 58 violations across 129 referenced core/partition views. Keeping pin faces and native port identities, spacing eligible failing faces fixes 11 core views; 47 violations remain. Both native HCOL halves retain their appropriate 218.592 x 187.488 lots, 1,179 non-clock inputs on N and the exact 35 outputs on E. Two distinct M5 clock pins are preserved at the planned centre, backed by the actual single-domain quarter source. Their actual physical connection still requires the die adapter; metadata alone is not closure evidence.

The original quarter split manifest proves that the old die contains only two of the four canonical quarters. Actual mapped source supports 64 HCOL + two tails + 227,684 soft standard cells and 17 real SRAMs per quarter. The proposed restoration preserves all four native logical VMS roles. It removes the 32 invalid hard-keybuf query proxies rather than inventing aliases or adding an unpriced face shell. Native key stages are kl_r, f_key, rkey, key_p, then two existing register stages per following chunk.

The free-lot capacity probe fits all additional lots without enlarging the die, but its viewed layout FAILS data-flow review: some key consumers scatter across 3 mm. `native_restore_lots.png` is retained as this failed planning vehicle. The regular native-stage layout is separate work; no route, STA or freeze is authorized by this package.

Scripts take explicit candidate paths and refuse to guess a new logical clock bus or change a face that lacks perimeter capacity. The before/after numeric records are retained separately. The macro-sidecar fix merges the full inventory with the OUTL and EP overrides, revealing three real clock-island/SRAM overlaps rather than hiding them behind unknown macro positions.
