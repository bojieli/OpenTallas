Decode specialization and query lifetime
========================================

The default frontend remains generic. Explicit `execution_mode="decode"`
compiles span_tokens=1, dispatch_rows=TOP_K, and one-query CSA masks and index
selection scratch. context_length and committed KV/index/compressor state keep
separate source bounds. The bounded-prefill mode requires an explicit chunk
size and streams each source index-score/candidate/top-k chain one query row
at a time, retaining every query mask until the last CSA Reuse. Kernel inputs,
outputs, arithmetic contracts, stable selection attributes, phases and state
ownership remain identical to the released graph.

This is a software compiler/planner repair, not an engine or physical change.
No matrix native handler or numerical oracle was changed. Legacy deployments
without query_execution notes retain their request admission. Specialized
programs have both host admission and ordinary ABI predicate/TRAP checks before
mutable state work. ROM lowering refuses this new mode until its phase planner
and admission are separately qualified.

Use `tools/build_deepseek_v4_kernel_ir_v3.py --model deepseek-v4.1-flash
--execution-mode decode` with the normal actual checkpoint arguments. For the
released initial prefill operation, use `--execution-mode bounded-prefill
--prefill-chunk-tokens 128`. Later prefill chunks at nonzero position_start are
explicitly refused: they require a separate causal streaming source contract.
The generic full-span prefill remains available explicitly/default. This
milestone does not implement full-prompt multi-chunk continuation.

`storage_model.json` is generated by the production storage planner over all
40 released layers and authenticated tensor shapes, with synthetic metadata
bindings only. No checkpoint payload is injected or allocated. The 1M result
is an O(N) storage model, not admission to the current 262K HBM capability; the
unaltered capability still refuses a 1M deployment. Its 262K deployment passes
full ABI lowering and the independent verifier. The actual phase-bound KV
exchange reserves its complete source-declared prefix and window; serial DMA
reuse permits one largest exchange, not an undersized query-only reserve.
