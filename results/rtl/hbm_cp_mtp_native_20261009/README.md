# Fresh CPsouth native MTP facade

`hfd_cmdproc_s_mtp_native` is a fresh physical master. It instantiates the original AR south source unchanged, then adds the actual full201-bit native MTP transaction guard and an eight-entry emitted-token queue. North and all old closed LEFs remain unchanged. This is the native17-bit DS contract; it does not narrow Qwen TOKEN18.

MTP input f_mtp517/output t_mtp179 exactly follow frozen f90d728da/f49a3d30f fields. The backend carries all eight17-bit tokens, tok1, position32, ncol4, index8 and opcode4, plus job32/generation4/sequence32/epoch8. A tagged completion must match all four identity fields. Native engine ACK adds one cycle.

The facade atomically admits one job into guard and queue. The queue exclusively drives e_ready; external f_provider139 is ignored. Native e38 `{generated_token_index20,token17,valid1}` enters the finite queue and becomes host data81 `{epoch8,generation4,job32,index20,token17}`. Host completion waits for all accepted tokens to leave. f_emit_host2 supplies token and completion ready; t_emit_host108 carries data/valid, done/status/count/fault. t_provider43 carries `{f_addr23,p_addr20}` to real prompt providers. Provider/config/backend endpoints are explicit ports, never translated into the legacy single-token doorbell.

Cross-faults abort both guard and queue and remain sticky. t_abort requests actual MTP/backend cancellation. Recovery requires coordinated reset of both cores, native MTP and backend, a persistent epoch increment, and true backend_quiescent before job admission. The facade cannot fabricate cancellation or tags from an untagged done. Those physical reset/cancel endpoints remain an integration obligation.

The pre-build source model prices600 guard registers, queue648 storage bits plus160 other state bits, and one-cycle tagged ACK. The facade itself adds no registers or cycles. The new source-owned S/M5 collar adds1656 literal endpoint tracks and preserves all previous pins. Its generator checks outline bounds and every same-layer pin overlap. All new endpoint groups remain in an explicit obligations ledger until bound by their owners.
