# Scheduled Q/KVN mux, source-exact leaf proof

Normal transport has no credit, ready, backpressure, demand arbitration or retry ports. Compiler inputs `slot_v` and `slot_q` select the preassigned dispatch cycle/source. Sources write two registered 523-bit entries each. The selected output has one registered stage; the compiler must include it in the receiver capture calendar. Source tags are checked (Q 001; KVN cannot produce Q). Overflow, empty scheduled slot or invalid source tag sets a sticky fault; no slot is postponed or assigned to another producer. Reset explicitly starts a new schedule epoch.

Actual admitted EPYC4 run `oth-ubuntu-1053192-1792030426` exits 0. Two fixed 4096-slot calendars each deliver 1024 Q and 1024 KVN full 512-bit words, with exact tags/order and output-valid cycle assertions. Empty reserved slot faults without a later valid beat. Wrong scheduled source and data corruption mutants both fail. `sources.sha256` binds all executed sources; raw logs are included. Earlier failed attempt completed the two normal epochs but its testbench incorrectly required normal output validity during deliberate empty-slot fault; corrected checker separates the intentional exceptional phase without changing the hardware.

This is a tested physical-leaf candidate, not a whole-token or physical closure result. The compiler-generated production slot table, real producer/receiver composition, die assigned pins, CTS/native launch/capture checks and route must still qualify. The two-source calendar in this bench is explicit fixed stimulus, not a claimed production schedule.
