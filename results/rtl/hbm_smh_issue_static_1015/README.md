Offline issue-control compiler, not full SM qualification. Commands use the existing 83-bit ABI. The actual issue_pq is the reference with production IL8, RMAX4096, XD128, DBF11 and SLAT7. No production runtime launch, credit, readiness or retirement gate is introduced.

Gate: `python3 tools/hbm_smh_issue_static_gate.py --out /var/tmp/hbm-issue-static-gate`. 236 exact control cases cover all group counts 1..16, group-slot and row-major order, ragged rows, slot phases, and immutable production sequence shapes. Nineteen two-operation locksteps exercise column and retirement latency hazards, including BF16 G16 -> FP8 G1. An address-bit mutation to actual reference RTL fails. One-cycle-early launches are refused by the compiler.

Committed programmes are immutable priced SEQS shapes, with deliberately conservative 64-cycle inter-op spacing, and no packet or HBM requests. They do not establish production throughput, dependency, x-load, outstanding retirement capacity, SRAM allocation or service feasibility. The enclosing compiler must schedule those resources and can call issue_slots/compile_manifest using its own launch edges. First issue is ceil((launch+2)/8)*8; programme output is start+4 and original S1 hop is start+6. The local issue-slot xa is optionally offset by x_base for the successor absolute-address command plane; lockstep reference tests use x_base zero.

Source hashes and terminal ot-run evidence are in source_evidence.json. Full generated calendars (including aliases) are retained at /var/tmp/hbm-issue-static-collected and remotely at ot-epyc4:/var/tmp/hbm-issue-static-remote. No seeded data or released checkpoint payload is included: integration must bind actual 1088-bit scale+weight lines and their checkpoint provenance. INT8 fmt3 is explicitly rejected pending the separately owned converter. Original arithmetic and immutable prices are unchanged.
