# HBC production receiver source and component evidence

The source now supports real HOST-loaded contexts, actual sequencer/Engram descriptors, real issuer busy/status, and a booked local return emitter. Existing default HBC1 mode remains one-shot/417 words and passes all six original acceptance/identity/CRC/COMMIT cases. Opt-in VARIABLE_WORDS=1 accepts the existing10-bit count field (1..1023), with33/515 indexed HOST streams measured. ALLOW_RELOAD=1 uses the existing LOAD/body/COMMIT protocol: after old receiver PREV input+3 and actual idle, a new LOAD invalidates the old context; only valid COMMIT activates new identity/epoch. BOOT body/commit dates remain distinct from receiver dates. The producer must also price actual END+4 status readiness and enforce HOST/KS guard dates.

Exact native compiler A33/B515 HOST and KS packets passed through the real receiver plus consumer source: payloads and sampled consumer edges match +4 from HOST body and +2 from KS header. The committed consumer dumps are reusable by the actual walker test. The native compiler's all_stage_ops_lowered=false remains explicit, so this is not a full layer/token claim.

Full production-top Yosys hierarchy/check passed both the original N0..3 CRED12 parent (55 ports/32 cells) and the faster R4D paired KA/KB parent (53 ports/26 cells), with0 check problems. The derived busy net is actual hb_status_t_host[65]. The R4D first composition omitted parameter declarations; its original failure log and corrected passing source are retained. HBC logic and K reset age are unchanged between parent alternatives; each gets its own existing-age reset leaf.

Current production direction uses HOSTB_ENABLE=1/STATIC_KS6=0: raw externally booked HOST/KS pulses get the existing one consumer landing edge. The optional unchanged7e9696145 static6 mechanism was tested with an explicit64-edge fixture, and is not the corrected8020 pipelined MTP graph. No production tag or armed state is fabricated.

The local return emitter samples actual status_t_host/status_t_kd at committed status_sample and sends at return_send. Its upstream arrival deadline is a separate explicit compiled authority; local PREV input is never substituted. Enabled invalid defaults refuse rather than inventing a route. Test dates and clock profiles are explicitly component fixtures. Actual production clock book, full die source binding, native synthesis/gate/route/clock closure and complete token execution remain open.
