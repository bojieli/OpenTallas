# KV D2D safe fan-out source (claude/kv-d2d-1019, 2026-10-19)

Structural successor of the codec2 KV D2D link end 353123a8d (TXDP_K 0x03030416, NTX3, SAFE_RC1, PR1). New masters
`qkd_d2d_static_sf` (ordinary) and `qkd_d2d_static_ovl_sf` (MU overlap master) are generated by
`tools/qwen_split/d2d_safe_fo_masters.py` into `rtl/qwen_sys/d2d_static_20261015/ot_qwen_d2d_dies_sfo.sv`; the end,
calendar, slot link, STATUS consumer and recovery live in `ot_qwen_d2d_safe_fo.sv`. As-built modules are unchanged
(hierarchy names unchanged; `ot_rst_pipe` gains an opt-in COPIES parameter, default 1 = as built).

## Rule: every copy takes its master's D net

The gate-level fork of 58f622b46 / c9c068a71 could not prove its copies equal at power-up (SAT: 19 TX calendar seg1[1]
copies hold their own state). Here every copy register's D input is the SAME NET as its master's D (or the same input
pin), never the copy's own Q, and copies of reset registers share the master's reset. After one clock edge every copy
equals its master from ANY initial state. No register, edge, latency or calendar slot is added: outputs are
cycle-identical to the as-built end, so nothing is handed to the compiler schedule.

| Root (353123a8d transparent loads) | Structure now |
|---|---|
| slot-store bypass hit_age0/1 (1096) | registered one-hot selects (dq / dqq / macro) per 16 bits; each bank compares its OWN slot-counter copies |
| calendar seg1 (1027), ptr (862) | one-hot base (2 copies) and one-hot pointer + lap bit (2 copies); tbl[seg1]/tbl[ptr] as AND-OR |
| capture strobes fire[p] (553) | last delay stage copied per 24 payload bits (D = previous stage) |
| epoch_begin (276), halt, epoch_abort, end_fault | NEB=12 copies from recovery_sf; 9 halt copies (= epoch_abort copy OR end_fault copy) |
| cal_start / cal_seg / cfg pins (148/139/66) | identical KEPT pin-flop copies: 4 start + 4 seg per calendar, cfg addr/data/base per calendar half |
| image write decode / STATUS capture enable (264/302) | per-calendar cfg copies; STATUS written in 10 groups each enabled by its own (rx_event, rx_slot, fault) copies |
| written-map set/clear (64), recovery counter (49) | per-quarter cmd_wv / v1 / epoch_abort copies; recovery_cycles in two halves on (st, counting, eb) copies |
| reset regions (158/136/...) | 12-copy `ot_rst_split` families per region; physical/common_flow/ot_rst_copies spreads loads (<= 24 each) |
