# Production PQ operand storage

The actual KMAX=6144 / VRD=64 buffer now has RTL backed by real compiled SRAM models. Four `ot_s81_pq_ix_sram` instances contain eight 128x256 macros each; `ot_s81_pq_qb_sram` contains four. The total 36 macros and 96 used rows match the production design's bijective map. This replaces BF16 flop memories and FP8 flop memories without adding a read cycle. Four BF byte groups have independent read-port replicas; FP8 reads and writes use the proved bank map. Exponents remain in four local flop banks.

The leaf benches compare every consumed output every cycle with the unchanged parameterized production flop tile from physical/s81_pq_hier/pinned/rtl/v41die/ot_v41_pqc_tiles.sv. Both BF parities pass 16,480 halfword checks each; FP8 passes 343,672 bit checks over all 384 words. Wrong-row SRAM mutants fail. The benches corrupt a real SRAM bit and an exponent bit and verify sticky parity fault propagation. Runtime assertions reject read-before-loaded, out-of-range addresses, bank collisions and read during same-address writes. Side parity covers each 64-bit SRAM slice and every 10-bit exponent; fault leaves from a register.

Run under ot-run: `bash tools/s81/pq_ix_sram_bench.sh <work>` and `bash tools/s81/pq_qb_sram_bench.sh <work>`. The committed gate record lists the exact source/model hashes and admitted remote units. These are production storage leaf functional gates, not an end-to-end core or physical qualification. Production control/quantiser, return groups, die lane transport, clock gates and real-view die timing remain required. New leaf slots and pins must be assigned by the die lead before route submission.
