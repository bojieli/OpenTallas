# Actual production PQ core

`ot_s81_pq_core_native` is a wires-only functional composition at PHW=9, SAW=11, KMAX=6144 and R=128. Its four IX leaves and QB leaf contain 36 real compiled 128x256 SRAM macro models. It exports the controller configuration and twelve fault/count interfaces to the die's return groups rather than placing 128-region return registers in the core. Its children have separate die clock entry pins. Fault reduction is a separate small registered leaf.

The production controller is generated from the pinned hierarchical controller with no control state or broadcast cycle change. It exposes explicit stream-advance, valid, family-qualified operand reads. The old flop tiles inspected head indices speculatively while stalled and inspected the other family's fields. Those values have no consumer under the stream-valid protocol. The SRAM leaves capture the consume indication alongside the existing read-index pipeline; strict loaded, address-range, bank-conflict, read-during-write and parity guards apply to consumed words. Invalid other-family payload aliases are discarded rather than presented as valid reads. No SDC or timing gate is changed.

The exact core gate compares every consumed Q/BF payload bit and every control, metadata, ROM and issuer output every cycle against the unchanged production flop tiles. Sixteen operations cover all four tags, one/two positions, both families, all 6144 load words, 36 real macro models, and the twelve count groups: 5536 compared cycles, 2304 Q beats, 2304 BF beats, 2304 VM reads and 768 returned-row counts. Telemetry distinguishes 2304 consumed reads per family from 318 Q / 586 BF speculative head cycles. Wrong IX addresses and wrong QB bank/address selection fail with data mismatches; removing the consumed-valid boundary fails the strict read-before-loaded guard. Separate leaf gates cover every SRAM row and injected SRAM/exponent parity corruption. Source hashes and admitted units are in the gate receipts.

Run under ot-run: `python3 tools/s81/pq_native_core_bench.py --work <dir> [--mut IX|QB|CONSUME]`. The negative runs must exit nonzero for their recorded mismatch or guard failure. Generate source using pq_native_ctl.py and pq_ix_sram.py. Both storage leaf bench scripts are portable to fleet hosts without rg.

Physical qualification remains open. The inherited control aq_vin output and quantiser v capture/tree spread need structural pin stages, the new storage leaves need assigned die pin files and CTS/route gates, and the native core/return-group/transport slot bindings must replace the screen interface in the next validated die contract. `core_contract_request.json` lists actual ports and children; it proposes no pin positions. No native PQ route has been submitted, no actual root/RWB/layer composition or throughput price is claimed, and the screen-shaped cluster is not substituted for this production core.
