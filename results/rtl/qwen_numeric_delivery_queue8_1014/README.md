# Isolated eight-entry numeric delivery capacity experiment

This is a distinct default-off component, not the production all-numeric binding. The delivery worker owns the live-base two-entry queue and actual immutable 0c81 identity join. This candidate preserves the alternative eight-entry capacity hypothesis without changing an existing parent, clock ABI, or closed master.

Every accepted queue word includes numeric data512, context16, version32, has_query1, and current query sequence40 (601 bits). Both query and non-query numeric words enter the same FIFO. A sink acceptance is the actual sink_clk edge with sink_valid && sink_ready; only an accepted word with has_query may contribute a query retirement. A cache response or held posted numeric-valid level is insufficient. The recipient/global ledger must independently bind real numeric acceptance, metadata provenance, and node/output sealing.

The producer clock is explicitly LIVE while the arithmetic family pauses. output_step must identify exactly the coherent producing edge and be the actual clock-gate enable, stable before the source clock edge. The producer must reserve output_credit before that edge and present the real pre-TOREG word with matched context metadata. No production seam supplies those signals in this experiment. The live sink has an independent declared clock; there is no assumed clock ratio. Gray-pointer synchronization continues while output_step is zero, so a full FIFO can regain credit without arithmetic progress. Reset is a common transport fence and cannot erase outstanding words while a global allocator remains active.

The test delivers 160 words exactly once through different clock periods, initial/full pauses, bursty sink service and held payload checks. It includes 107 query words and 53 non-query words. Mutants that force every word to carry a query, truncate query sequence to32 bits, or stop credit synchronization with the coherent step all fail. These are unit/component facts, not native arithmetic or timing proofs.

Logical state is 4808 data bits +32 pointer/synchronizer bits +1 sticky overflow fault =4841 bits. The data array has no reset; pointer state resets in both domains. The leaf contains two genuine clock domains. CTS/source binding must retain separate source_clk and sink_clk coverage. The combinational storage read face, physical registered output admission, synchronizer placement/CDC constraints, source clock gate phase proof, actual parent numeric/tag alignment, measured outstanding peak, and loss/cost ledger remain OPEN. The eight entries do not imply one word per coherent edge under every sink service rate. A full guard incurs explicit stalls to be measured; no frequency ratio or cost waiver is adopted.
