# HBM fixed-latency pad storage candidate

`hbfd_pad SAFE_STORAGE=1` preserves the exact N-rising-edge API and asynchronous active-low zero reset. Default remains 0. There is no enable/valid/ready input: every edge carries an arbitrary word and advances. N=0 is the existing wire exception; N=1/2 use unchanged ot_hdc_delay. N>=3 uses an exact-N circular store, with a registered input copy per 16 rows. Logical stores above 2048 bits instantiate actual characterized ot_sram_1r1w_128x256_m1_r2c2 macros, never inferred replacement arrays. Native input/clock ports remain unchanged.

The production inventory model covers 315 instances, 103608 legacy bits, 283 stream and 32 serial clocks. Seven large instances require nine SRAM macros, 35024.19 um2 hard area. Macro clock-to-Q is 351.8 ps TT / 286.1 ps FF / 455.3 ps SS sensitivity. The macro has one synchronous read edge and read-first collision behavior in its provider model; the production address sequence forbids read/write address equality. Registered input, lookahead address, synchronous read and output capture are paid inside the existing N, adding zero edges at II=1. Finite warmup age counters suppress all stale contents until the first input reaches its original output edge after every reset.

Evidence at 88c19e8eb and 245a7b6e2: 72 actual and boundary shapes, 7000 edges each, 14 repeated/reset epochs, golden differential PASS. Four mutants are witnessed for each N>=3 shape: wrong read slot, early warmup, added output edge, and same-address read/write collision. Initial one-bit stimulus gap was fixed and its failure log retained. The 0c3eecf04 successor explicitly poisons every real macro cell before the test and uses exact-N allocation with kept ingress copies. Its source-pinned fleet job and five synthesis cases are in job_exactn.json and pending_results.

Synthesis of 245a7b6e2 confirmed two actual macros for W274/N14 and one each for W136/N28 and W34/N73, and distinct kept warmup groups. It exposed W17/N115 ingress fanout 128 and power-of-two row waste; 0c3eecf04 structurally replaces those with exact-N storage and local copies. Historical synthesis_summary.json refers to the earlier source and is diagnostic, never a qualification receipt.

Safe-design preflight: pins PARTIAL (registered ingress/output except required N0/1/2 compatibility; exact asynchronous-reset ABI retained); reach OPEN (candidate dimensions below405um, actual placement required); fanout OPEN (latest 16-row ingress/32-bit warmup groups need mapped proof); depth OPEN (actual TT path required); storage FIXED in source (N>=3 finite ring, >2kb actual SRAM); floorplan OPEN (43.2-lattice candidates in model, synthesis area and full-width std band required); clock OPEN (TT/FF spread<=80ps, native neighbour references and >=0.03ns hold budget required); schedule PASS functional law (zero added edges, II1), production differential successor pending.
