# DVM DX9 behavioral proof

Source 2a6a65f12 separates tap merge/classification from RNE carry addition and moves beat rotation into the column head before its existing leaf-write register. FILL_LEAD is 5 and DX is 9. This repairs the prior tap gate path (-524 ps, 23 levels); it adds one fill edge compared with DX8 and eight x-read edges compared with the vehicle priced at XVM1.

The completed EPYC4 runs use /srv/opentallas-scratch/claude/qwen-dvm-r3. source_binding.json verifies SHA256 equality with the committed source for all 20 executed runner, RTL and bench files. Production shape (48 columns, 768 tiles, 3,072 groups, 14 operations) passed 4,571,136 element checks. The current production ownership mutant failed with 1,309 errors. Mid-size actual arithmetic passed at GAP0 and GAP4, including nine address-reuse operations; rounding, ownership, wrong-line, head timing and leaf-select mutants all failed. The dropped-write check observed the fault as required. Full observed logs are retained here.
