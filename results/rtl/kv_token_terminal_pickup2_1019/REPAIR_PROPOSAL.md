Minimal repair proposal has three changes, only in a distinct future bench/helper:

1. Generate an observation-authority frontier for each actual monitored valid signal from its resettable producer, actual target clock and exact intervening unreset FF chain. A frontier becomes known only once the producer's real reset has taken effect and cleared its valid and that reset-cleared qualifier has propagated through every actual sampled edge. It remains armed through idle and all legal transaction activity; re-arm only on an actual reset episode. Do not use A0, KGO, expected deadline, programmed age or a guessed fixed warmup as a gate. This derives when a real consumer can trust a qualifier, independent of programme admission. Derive separately for d2d TX, each K/V request and sequencer request; do not transfer nine to other paths. Verify source reset polarity/landing and repeated async reset, not just rst_n at the parent pin.
2. Before each frontier is known, do not mutate transaction scoreboards, enqueue model responses or consume a seq-request ordinal from uninitialized valid flops. Continue observing and asserting actual reset propagation at the source/frontier. Once known, the original protocol checks run on every authoritative valid including idle before A0. Mirror the existing trace_on predicate only for diagnostic activity display, and assert that trace_on implies every required frontier is known. Never use trace_on to suppress an already-authoritative protocol fault. A STATUS without a real admitted/owned request after that frontier is a protocol error and must not increment the completed-request count. Keep a separate raw record count and error witness; this is checked identity/ownership, not a ready/backpressure change.
3. Make the runner inspect SMOKE_FAIL/SMOKE_PASS, requiring exactly one positive terminal verdict per case and rejecting FAIL, absent verdict or conflict even when rc0. Preserve the unchanged raw results.json and logs. No RTL, gold, original case release dates, reset length, trace_on date or programme deadline changes.
