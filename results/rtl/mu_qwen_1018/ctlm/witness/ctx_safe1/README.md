Fresh-context consumption is the first LOCAL EMB or SEG bank read. Production INIT/steady variants must be selected by explicit compiled admission metadata, not the guard. New full-identity context validation is being folded into sys_face and its bank-load age must be composed separately.

The new admission interface is opt-in. `INIT_U0=1` enables a registered `init_u0` input aligned with the ordinary DH input register. The compiler must supply an aligned, nonempty `INIT_FIRST`/`INIT_CNT` range that fits the ten-bit calendar address/count ports. A pulse selects that immutable range only on a user-zero stage-zero start; any other pulse raises the sticky operation fault. The ordinary zero flag keeps the descriptor path unchanged. The flag has no dependence on context-pending, completion feedback, SEAL, or inferred first execution. The landed wrapper adds one 18-flop HR-to-core landing: 26 landings/5,098 flops with legacy landing emission, unchanged output offsets. The separately qualified direct24 physical wrapper has its own larger control-state census.

`OPSEG_EXPANDED=1` selects the compiler's 23-bit period/14-bit address/three-ROM leaf. `OPSEG_VIAMAP1/2` and `OPSEG_INST1/2` bind the additional images. `OPSEG_PINREG=1` selects the compensated registered-ROM pipeline; the leaf proof in `admission/witness` establishes the same fire edges and requires a minimum three-edge entry gap. All new options default off, preserving existing callers. Actual F16 source artifacts are in `admission/F16_P2`; their DW boot record is under integration correction and must use the final committed hashes.

The minimum real-GI admission bench is owned by CALPIPE and remains required before integration acceptance. It includes actual PW/DW/three-ROM data, the accepted context receiver/observer, cold and repeat admissions, first EMB/result preservation, and fault mutants. Absolute prefix origin, full programme/store, arithmetic/full-token behavior and native physical clock closure remain open; the older witnesses above do not discharge those obligations.
