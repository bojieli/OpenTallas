# Expanded cyclic admission compiler and three-bank leaf

ROOT selected F16, fully expanded repeating admission/retirement. The packet
F16_P2/admission.json contains the actual command-class image, three ROM masks,
absolute active units/link starts, canonical context slots, known quiescence,
source/artifact SHA256 values and the required cold-prefix contract.

This is a BLOCKED production certificate: full per-user arithmetic/table images,
qualified512-seat Q producer/read times, full validated context receive age,
physical phase and full INIT-to-token proof remain with their respective owners.
The ordinary image is generated by mu_opcal; the complete36-layer tensor-programme
store is a separate workstream. UVM_STRIDE4096/PIDX_STRIDE128 are recorded explicitly.

Actual compiled shape (paired MU logical slot, physical leaf gap3, opt-in measured
SAFE root capture1): T251676, base H4026816, repeating H8053632,8216 leaf entries,
three4096x72 macros with14-bit address/23-bit timestamp. Completed tokens per cycle
are32/29/15/12,13112.0965 tok/s versus13708.1009 before lifecycle overhead. The
latency user's periodic unit sequence is retained. Initial/recurring filler
contexts use distinct latency-user head MU slots0/1/3; first INIT is selected
only after its accepted load and before its first L0. A normal retirement head
emits the completed inference result, followed by an explicitly empty interval.
All known resource reservation ends are checked against the next context load.

INIT_FIRST52/INIT_CNT3, serialized entries at8 NOP,12 AMAX-clear,61 LOCAL EMB.
The aligned appended range consumes5 entry positions including alignment pads.
The compiler selects this range in the list; no context-pending flag suppresses
an instruction or selects a cycle. The ROOT-owned controller guard faults an
unexpected result write before a fresh context is consumed.

The cold user0 prefix requires INIT stage0 at L0-334 and EMB at L0-273:
known head reservation span333 plus one explicit cold guard edge. Absolute epoch
edges and initial context/embedding acceptance remain unbound. Origin0 and D0=16
are required; the previous rotated steady origin misses early cold user0 work.
The shared list/face owner binds measured launch ages and prefix/WRAP_BASE.

Leaf ABI (EXPANDED0 remains the legacy default): EXPANDED1 uses header
{magic13=13'h13A9,H23,nent14,T22}. Entry fields retain their positions except
reserved bit69 is timestamp bit22; bit70 remains reserved0. Three raw-ROM
instances are g_op.u_rom and g_op.g_banked.u_rom1/u_rom2. VIAMAP/INSTANCE select
bank0; VIAMAP1/2 and INSTANCE1/2 select the additional banks. The existing
synchronous macro read and rq capture pipeline are unchanged. Three hierarchy-
kept bank tags select independent24-bit chunks. The parent propagates these
parameters through flat/lpf/gi/LP specs and binds all three real macros.
Each macro is38.016x62.910um,2391.58656um2, total7174.75968um2.
