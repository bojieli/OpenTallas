# Qualified TT source handoff guard

The sole73 compiler now requires the existing TT receipt status `QUALIFIED_SOURCE_LOCAL_EDGES`, in addition to its selected master, receipt/RTL/LP hashes and producer-relative GI ledger. Missing status, `SOURCE_ONLY_NOT_SELECTED`, and `UNKNOWN` are refused before creating an output directory. Nine pure CLI checks pass, including qualified-local4 candidates missing selected master, actual Q/K GEN identities, transports or header age; no calendar, image, simulation or GEN was launched.

The exporter already required this status when consuming `opentallas.qwen.tt_emb_source.v1`. Matching producer commit fb63191c3 preserves that same field as `tt_source.status` in its exported head-prepare receipt. No parallel status schema is introduced. The raw TT diagnostic path has no forged qualification and is refused by the final compiler.

Actual selected21 TT local qualification, final GEN transports and full K descriptor-to-header ages remain absent. This guard does not qualify the source-only XPF20 fixture or any historical595 chain. All other required actual-source/GEN/deadline checks remain in force, and no sole73 image exists.
