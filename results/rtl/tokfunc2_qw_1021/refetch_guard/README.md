# Local legacy STG refetch normalization

The one-command collection path now fetches the run's own required calibration outputs, case logs and fixture manifests, then invokes the current local collector before composition. The remote legacy result stays unchanged and its exact bytes are archived locally under a content hash. No objects or executables are fetched, and no corrected calibration is substituted into an older run.

Each requested stage is fetched into a fresh directory. A prior local snapshot is preserved separately, so absent new evidence cannot be supplied by stale files. Missing remote results or failed fetches install an explicit INCOMPLETE/DIAG stage instead of retaining a historical PASS. Required missing local evidence or a collector/schema failure also produces INCOMPLETE. Fixture symlinks are dereferenced only within the run root; their bytes are copied at their logical stage path. The local evidence fold does not invent binary/source identity: the separately published original-build receipt remains authoritative for that scope.

The focused pure check uses the actual committed legacy STG3 report and raw527-case corpus. It exercises file discovery (527 case outputs,36 fixture manifests, required original calibration, zero objects), sibling shared-fixture symlinks, copying to the stg alias, and local re-fold. Complete evidence yields exact FAIL solely for original pos MAT calibration rc1, while all527 numeric outcomes remain expected and all144 VM-delivery ages stay unknown. A missing original calibration output or a corrupt fixture yields INCOMPLETE, preserving the original raw report. Collector failure cannot masquerade as a successful fold: the normalizer requires its STG completion marker and current calibration/delivery schema.

No remote program, simulator, compiler, image or replay was launched by these checks. The manual STG3 terminal packet remains the authoritative source-bound receipt; this collection repair keeps a generic refetch honest.
