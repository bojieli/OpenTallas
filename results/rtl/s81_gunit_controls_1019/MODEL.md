Launch: preserve ln0->ln timing, replicate the first launch rank four times at the ln0 edge and use at most 26 consumers per rank. One kept same-edge enable per 16 payload bits for 24 t, 24 base and three scale words: 102 enable FF. Each drives <=16 logical mux bits (mapped actual count must be <=32), with four first-rank FF, replacing the data loads of the existing ln control. Capture: 48 kept enables for 768 result bits, each <=16 logical mux bits. Two decoder modules each produce 24 enable FF; decoder inputs remain shared at <=2 module ports. Enables are validity-only, not new payload stages. Exact reset/startup behavior must prove no visible stale writes; no added external edge.

Reciprocal: retain original S8 T capture, replace broad 9-bit seed/square case decode with three 3-bit one-hot groups registered AT S8. Five independent fixed kept banks per row (c0 low17/high16, c1 23, c2 13, square14). Each bank has two copies of 24 predecode FF, with replica choice splitting each 8-way group bit across 32 row products. Each product drives <=23 coefficient bits. Shared combinational predecode terms drive ten FF D loads, and raw T_d bit drives only its small 3-bit decode. 240 FF/row, 960 additional unreset FF overall. Existing S9 coefficient registers and S10/S11 seed stages remain unchanged. Four kept 34-bit T banks per row preserve quotient locality; no added T pipeline stage. Individual quotient/control cones still require complete mapped census, not just address inputs.

Provisional explicitly new state: 1114 FF (960 predecode+102 launch+4 first rank+48 capture), before elimination/replacement. Preserving four independent 34-bit T banks per row can additionally restore up to 408 FF that baseline optimization had merged; reserve 1522 extra mapped FF in total. Any further restored existing copies must be charged from the actual census. No runtime indexed storage added; lookup truth tables remain immutable coefficients (512x83 bits, same ROM semantics as baseline). Do not change physical kit before measured actual synthesis, native geometry and parent slot approval. Additional clock sinks provisionally <=1522; no new root/domain. New payload boundary bits/cycle: zero. Added cycles: zero, contingent on exact full-shape/HOP witness. Energy rises from added clocked state and distributed decode; no performance credit.
