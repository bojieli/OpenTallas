The bench instantiates the actual opt-in ZH wrapper at both opaque widths (268 command and 68 return), with the exact source reset pipes. It checks every accepted full word at four edge intervals, immediate first legal acceptance, continuous wraps, sparse traffic, idle fault words, transmitter-only drain, and receiver-reset discard. The top return nibble changes on every word so the stale-fault-owner mutant is causal. All other bits are compared without arithmetic interpretation.

Reset authority is established by witnessing two consecutive actual all-bank transmitter and receiver regional reset-clear observations while both raw resets are asserted. The first such completed consumer edge clears stored validity; every subsequent edge is checked against an independent reset recurrence and expected-word queue. There is no release, trace, programme-start, or idle masking. Unqualified power-up behavior before that witnessed assertion is HOLD. Three randomized two-state initialization seeds sample startup state; this is not a universal arbitrary-state or four-state proof.

Mutants 1/2/3 run at both widths: wrong indexed slot, first-bank valid skew, and falsely valid reset slots. Mutant 4 runs in the real return wrapper and substitutes the previous word's fault nibble. Each negative must terminate nonzero with a TRANSPORT_FAIL witness; positive executions require an explicit TRANSPORT_PASS and successful exit. Retained health semantics and child arithmetic are outside this transport-only bench.
