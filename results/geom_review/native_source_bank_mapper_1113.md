# Native source register placement — private source capability

An explicit native-source manifest now joins the existing clock.soft_reg_banks allocation without changing its fields. Sites follow the manifest's actual scalar identities. The runtime resolves each scalar net through at most four unique unary output aliases to one unique DFF, validates all mapped clusters and all bank geometry, and only then moves cells. It rejects missing or ambiguous nets, merged drivers, unsupported combinational paths, oversized clusters, and illegal or overlapping sites.

The optional kit_istations --native-source-banks FILE hook validates the original body and wrapper hashes, actual wrapper instances/declarations, complete live scalar coverage, and each excluded constant bit against literal procedural drivers. Only private kit wrapper copies may receive attributes; run kit_rsync first. The source body and wrapper drivers receive keep attributes because keeping only register wires does not prevent identical native words merging. The manifest receipt explicitly does not claim physical realization. Without the option, the old CS Tcl and bank specification are byte-identical.
