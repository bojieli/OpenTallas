# HEAD tile local CTS feasibility trial

This trial measures one hd_tile local tree with its five already SIGNED A/B core views and six actual soft grid clock inputs. It does not qualify the die feeder: the previous r2b feeder's unequal core branch delays remain a structural failure. No full HEAD timing claim follows from this trial.

Actual synthesis: 64,565 leaf cells including five hard-core instances, approximately 64,560 standard cells, well below the 400,000-cell run limit. The 708.48x1036.8um tile has hard-core fill 0.667. Grid pitch is 400um; the nearest grid-root split bounds local soft wire reach, with the existing 3000 sink/root cap. The five functional core pins have dedicated early inputs, so CTS does not balance the soft tree to the obsolete ETM maximum. Signed means: A255.24TT/208.27FF, B230.71TT/189.31FF; existing internal spreads max44.4ps.

Local timing estimate, conditional on the published input phases: soft window20ps + maximum core internal spread44.4ps + A/B mean difference24.53ps =88.93ps. Use the APPROVED clk_aocv_table_g021.json, not a flat clock derate. A conservative two-stage, all-cell255.24ps branch bound over1250um gives worst paired OCV43.90ps (FF classA; TT classB43.75ps); real wire share lowers this bound. The design must have at least two buffer stages on any such full-length path; a short one-stage tail must be charged its actual delay, not a255ps lump. Differential droop is zero only within this shared tile PG region per12.4a b1; the PG budget remains an actual gate. Applying the larger calibration1.0552 to88.93+43.90 gives140.16ps against150ps. This is a feasibility estimate, not a replacement for measured stages/OCV/droop and actual source arrivals. It leaves only9.84ps for input-phase mismatch. The existing r2b source does not satisfy that condition; a matched local feeder remains necessary.

Four A macros in two rows and the B macro above leave open central and horizontal soft channels; no macro wall across the tile. Current region input lies in the horizontal corridor. Five core input points lie at real signed pins; incoming feeder matching is still open. Landing input has its own macro-free band and403um maximum pin-to-band path, close to the405um relay limit. The actual prior PG-cut DRT fixed5M6 shorts to0; this trial retains that opt-in and real macro-PG connections. No pin or PG spacing waiver.

Verdict: PASS for one gated local CTS diagnostic using the declared input phases, with normal pre-floorplan and post-CTS hold/insertion gates enabled. HOLD for full region or die timing until the real feeder input phases are brought within the remaining budget and included in OCV/droop. An actual placement/clock failure will be preserved and corrected before route; this trial stops at CTS.
