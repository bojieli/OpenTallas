# Private STM geometric proposal — review only

This is a concrete **private type-geometry proposal**, not an adopted die plan, measured placement or authorization to run CAD. Only the actual measured `slw_stm_v3` parent is covered. Its frozen pre-D13 source is `d90b10921/event1131_fixed`:209,148 standard cells plus four ROMs; native PORT_BIND17,874 and FACE_GUARD17,698 pass. No other STM type inherits a count, proof or physical view.

The original613.44×1339.20µm frame has3.985% standard-cell fill of free core area and remains a real fill failure. The proposed311.04×613.44µm frame has aspect1.972 and20.266% nominal free-core fill. This modest fill is **pin-limited**:17,671 data pins retain their existing M4/M6 east/west and M5/M7 north/south contracts. No extra external layers are assumed. The smaller311.04×609.12 draft failed west-edge length by2.225µm after the real guards and track origins; the next4.32µm row step leaves2.095µm west clearance.

All17,874 actual named contacts are allocated:17,671 data,52 edge infrastructure and151 interior infrastructure. The latter are76 local clock inputs,74 constant count-strap bits and `cland_tstart_in`. Native forward-clock/start contacts are placed with their corresponding data bus; north/south M7 data slots explicitly reserve holes for those contacts. Each bus retains its actual bit/layer assignment. The model uses5.95pins/µm/layer,0.128µm bus padding,0.96µm inter-bus guards,4.32µm core rim and2.16µm guards at **both** ends. Exact snapped inclusive10µm windows contain no more than60 edge pins per layer. Actual pitches/origins are M4/M5=0.048/0.024µm and M6/M7=0.064/0.032µm. This is stronger than an averaged perimeter count.

The four actual121.848×62.952µm ROMs form one R0 column at x60.48 and y142.56/237.60/332.64/427.68µm. Their vertical extent is348.072µm;4.32µm halos and32.088µm inter-row channels are explicit. All twelve inherited landing-band rectangles keep at least their frozen declared area, avoid macro halos and each other, and are separate from the ROM capture and north publication windows. The source has duplicated landing-band metadata; composition must update both the primary bands and collector-local copies. The existing 167 collector/reset relay vertices also have proposed coordinates with identical d/q connections and registered depths; their largest planned relay hop is 380.16 µm. These are coordinate targets, not measured reset timing.

Actual mapped JSON graph analysis finds209,152 native leaves,68,857 DFFs and four ROMs. Of the flip-flops,52,609 use local `clk` and16,248 use twelve forwarded clocks; all roots resolve. The old QC49 placement bins contain48,065 local sinks and are not reused as a current measured layout. The private clock model assigns every actual named local FF exactly once among76 nonempty estimated groups, with at most1,095 FFs in a group. Four ROM clock pins and twelve clock-only gate-input-net incidences are separately recorded on the native root, along with twelve clock-export obligations. These are **estimated consumer target windows**, not actual post-placement sink counts, capacitances, skew or achieved insertion. The exact existing per-port clock arrival/offset contracts must be retained. Source type defaults are recorded as defaults, not substituted for effective per-port values. Forwarded write-clock roots above1,200 native FF loads need ordinary internal CTS branching; the count model estimates19 branch groups, without adding clock ports, functional stages or source offsets.

The actual ROM publication path has three existing registered edges: loader capture → STM capture → native output boundary register. Bank-specific target windows use those actual register families; they introduce no pipeline stage. Entire-cell bounding-box constraints give conservative Manhattan bounds of86.712µm ROM-to-loader, at most378µm loader-to-STM capture and about301µm STM-to-north publication. Every target rectangle is a whole-cell window: for example, a609.12µm top permits a0.27µm cell bottom only up to608.85µm. Actual row orientations must be read from the ODB; no R0/MX or upper-endpoint placement is fabricated. Native DFF dimensions are1.08×0.27µm (HQN/LQN) and1.404×0.27µm (ASRHQN).

Macro escape is explicit. Each bank has a separate32.4µm M4 escape span, giving405 tracks at60% use for at most280 terminals including clock. The west publication corridor uses the already allowed **internal** M3/M5/M7 layers:1,332 tracks at60% use versus at most1,064 ROM publication bits. M5/M7 alone would provide756 tracks and fail an798-bit cut. This use of internal M3 changes no external pin layer. `core_pg_connect` remains true; the standard named macro grids connect the ROMs’ actual M4 PG shapes to M5. M5 strap-site lattice phase is preserved. Proposed M7 clock entries avoid the existing PG stripe phases. These are geometric feasibility statements; actual pdngen connectivity, PG DRC, IR, pin access and detailed escape are **not run**.

Actual ROM views are recorded faithfully: TT0.7V/25°C, FF0.77V/0°C, native clock pin `clk`. These match the normal ASAP7 corner convention. Methodology “TT0/FF25” refers to setup/hold **uncertainty0/25ps**, not temperature; no PVT mismatch hold is claimed. Physical geometry does not qualify an archived MIF1 view, new source/profile, selected programme masks or a default-inferred namespace. Those source/asset/view obligations remain independent.

`proposal_v2.png` was personally viewed. `private_proposal_v2.json.gz` contains the complete named-contact allocation, actual named consumer assignments and target windows; `proposal_v2_summary.json` omits the large per-cell lists. `source_type.json`, compressed original geometry and the actual native graph packet are inputs to `build_private_proposal.py`. Native graph support is structural, not a proof that a path is programme-active; no cached functional view is transferred.

Before CAD, parent allocation and neighbour/die-port composition must be reviewed, the proposed same-topology collector/reset coordinates must be composed into the standard metadata, and the approved current generator’s frozen explicit clock report must preserve the76-port native ABI. Then ordinary PLACE may measure fit, pin-register reach and actual consumer occupancy. Actual clock GEOM gates CTS; clock-inclusive GRT, real timing and the standard fresh async type LEC gate later stages. No P&R, extra synthesis, waveform flag change, generic I/O wrapper, current-plan adoption or physical SIGNED claim occurred in this proposal.
