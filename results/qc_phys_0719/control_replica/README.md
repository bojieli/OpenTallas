This is the smallest control-only lockstep vehicle for the RP1 CROM regional clock repair. It compiles the actual `qfd_dv_s8x_kff` module extracted unchanged from the frozen f57r4 `qfd_dv_s5_vm8x.sv`, and reproduces the `u_c1` ID3400 -> sixteen `g_cbk` ID3500+gk chain in `qfd_dv_s8_crh_rp1.sv`. Source paths and hashes are in source.json. No arithmetic or SRAM model is introduced.

The candidate replaces one scalar C1 source with two identical scalar copies receiving exactly the same D on the same cycle. The actual placed W1 subset is mask ABBF (bits0,1,2,3,4,5,7,8,9,11,13,15); the remaining bits6,10,12,14 use W0. Both copy outputs are also compared with original C1 every checked cycle, so equality does not depend on the particular fixed subset. Six subset masks include the actual map, all-W0/all-W1, alternating and sparse cases.

PASS: 4,096 cycles after original two-stage initialization, 24,576 lockstep checks, +0 data/control cycles. The original primitive has no reset; the test does not invent one. Directed toggles and deterministic LFSR input drive the actual D port. Nominal exits0. Altered W1 D and extra-cycle W1 mutants both exit1 at cycle2 with ABBF mismatches, demonstrating sensitivity. This is RTL exactness evidence only; the parent's physical clock/hold route gates remain required.
