# WBQ conservative split candidate

The 161.6k-cell WBQ switch exceeds the conservative 150k-cell target. This candidate moves its sixteen two-word K-port skids to a separate output core and puts one elastic register stage at the main core output. The composed top keeps the original ports. Source and every mutable queue state stay exact; this is a transaction-equivalence change with an explicitly added cycle.

PIN CYCLES: selected group to K output +1 hbm_clk edge, while sustained capacity remains one write per PC per edge. GIN=1 is the separate previously proved +1 edge on g_v/g_d. HREG=2 has no cycle delta. Adoption and scheduling wait for both physical views to pass sign-off.

Proof on the existing full WBQ reservation vehicle, HREG=2/GIN=1, source against native flat reference: m0 40234 writes, slow 40563, east 40234; each exact write set, no duplicates, no wrong PC, zero mismatches, zero faults, 48/48 completed reservations. New stage bit-flip mutant produces 40234 mismatches. New stage overwrite-under-stall mutant loses a word and fails the vehicle progress bound. The original driver waited forever for its next free bank in this case, so the new bench applies its existing final-drain NB*8000-cycle budget to the complete 48-reservation vehicle. This is a simulated-cycle liveness assertion, not a build/simulation walltime cap. The first unbounded mutant run was stopped by exact own PID1853398 and is not proof evidence.
