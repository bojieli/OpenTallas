# WBQ conservative split candidate

The original 161.6k-cell WBQ switch exceeds the conservative 150k-cell target. This opt-in source keeps the original top interface and moves its sixteen two-word K-port skids into a separate output core. One elastic output stage in the main core supplies registered data/valid at the internal seam. Default files used by the existing builds are unchanged.

PIN CYCLES: selected group to K output +1 hbm_clk edge, with sustained capacity one write per PC per edge. GIN=1 is the separate +1 edge on g_v/g_d. HREG=2 adds no cycle. The opt-in wrapper defaults HREG=2, GIN=1, matching the proof. Adoption and scheduling still require both physical views and parent sign-off.

The existing full WBQ reservation vehicle passes exact write-set comparison against the native flat reference in three modes: m0/east 40,234 writes, slow 40,563; zero duplicates, wrong PC, mismatches or faults, and 48/48 completed reservations. The new stage bit-flip mutant produces 40,234 mismatches. The overwrite-under-stall mutant loses a word and fails the existing NB*8000 simulated-cycle progress budget, now applied to the whole 48-reservation vehicle so the free-bank wait also terminates. No build or simulation walltime cap was added. The first unbounded overwrite run was stopped by its exact own PID and excluded from proof evidence.

Actual ASAP7 mapped sizing: MAIN 118,502 cells / 16,502.693760 um2; OUT 54,313 cells / 7,336.830960 um2. MAIN sizing includes the old complete shell with GIN=0; proposed GIN=1 adds 2,296 registers while native seam pass-through removes 4,576 internal output face registers, so that probe is conservative. Current slots are MAIN 86.4 x 544.32 and OUT 43.2 x 544.32, both about 0.396 synth fill before CTS. The 34.56-wide OUT candidate failed at 0.528 fill and remains recorded in OUT34_REJECTED.md. Parent q0 has a clear west cavity; q1 aqhi shifts 25.92 um left to leave a 15.12 um channel. No placement, route or sign-off pass is claimed.

Pin packets interleave valid1 + address30 + data256 + ready1 for each PC. Each packet spans 27.648 um, avoiding the old bus-major valid-to-data reach over 400 um. Matching MAIN W and OUT E pins preserve each bit. MAIN head/queue control registers use a central band; send-stage and PC control registers use sixteen disjoint W-edge bands. OUT native head/tail captures use sixteen local PC bands. Pass the corresponding reg_guide_boxes JSON to generation, then review the actual placed endpoints and clock/reset/PG geometry before route.

The internal seam must have zero extra wrapper cycles. --face-stage BUS=0 and --face-in-stage BUS=0 are NOT sufficient: those options mean zero EXTRA stages and retain the base face register. The concrete default-off --face-pass candidate is codex/wbq-face-pass-1106 @ 1df47d346e6, pending root R2 scoping approval. It preserves the native source/capture flops, records face_cycle_overrides per bus, applies the existing R2 endpoint census only on the explicit native seam, and retains ordinary strict guard checks on every external face. All parent data/valid/ready paths remain timed.

MAIN native buses are w_k_v, w_k_addr, w_k_wdata and w_k_rdy; OUT native buses are in_v, in_addr, in_data and in_ready. w_k_wr_done remains an external MAIN input with its ordinary face flop. Expected face counts: MAIN 7,352 raw pins minus four clock/reset pins minus 4,608 native seam bits = 2,740 wrapper flops; OUT 9,218 raw pins minus two clock/reset pins minus 4,608 native seam bits = 4,608 wrapper flops. The sum 7,348 matches the original whole-block count. Generated freeze/face_shell.json will be authoritative if anything is pruned; no production freeze exists yet.

split_spec.json and ot_wbq_sw.conn.json supply the concrete parent composition. Physical paths append .u_main/.u_out to the old u_wbk_Q__q0.u_fcore.u_core.u_sw prefix (q1 analogously). Run run_eq.sh for the reservation vehicle and run_mutants.sh for both new stage controls. The generic native-seam helper has its own smallest elastic/skid lockstep and ready/data latency mutants. Existing failed physical records remain unchanged.
