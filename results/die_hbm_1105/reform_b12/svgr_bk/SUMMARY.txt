  head data bits load on !empty&&!stop&&!sticky (no identity term; bank bits keep fifo_pop), one-hot replicated
  read select (9 slices x 8 kept flops), pointer next = mux of precomputed +1, mem write without reset term.
  Estimate: 345+16+18+8 endpoints lose the identity->enable tree (~270 ps) / rbin tree (~400 ps) / reset term;

vB (safe by construction): registered identity check (head loaded -> id_q next cycle -> take next cycle; reserve

  PIN CYCLES vs B8: landing write / complete / bank fault +1 stream_clk per packet, credits follow the later pops.
  Credits: the FIFO still never pops past a failing head (same credit count after a fault as B8).
