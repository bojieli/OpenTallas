# Full dispatcher and calendar component evidence

Scope is a private functional component, with ENABLE_FIRST_EPOCH_GUARD=0 / FIXED_IMAGE=1 defaults. It instantiates the unchanged actual dispatcher, streams targets 1 through 9 and target 11 in their actual accepted order, preserves two 40-bit cfg relays, the BC input/output captures, and all actual SF parallel pin copies: 190 cfg and 18 start bits. It retains 4,118 original declared state bits and adds the planned 269 metadata/guard/reset FF. No public binding changes. Unmodeled sink_applied and local_configured are zero; overall setup readiness is not qualified.

Source epoch metadata captures boot_image_epoch on the same edge that the dispatcher emits target-11 cfg. Validity is incoming boot_pr[74] && target==11 && !boot_image_fault && !dispatcher_fault. Actual downstream write enables remain the acceptance authority. Metadata follows each actual payload/request capture, including the originally unreset relays and SF pins. Local raw reload reaches SF guards directly and reaches BC through its original reload input capture; these are distinct actual consumption edges. Common reset is a functional fixture, not a native regional reset-arrival certificate.

Bench3 ran 15 Icarus four-state cases and 15 Verilator 5.050 cases. The extended binary healthy case compared every actual reset-release edge for 257,115 edges, all 36 layer anchors, both first and next ordinary token (249,600 edges apart), and 1,411 calendar events. Zero errors. The first token start is anchored at the actual SF calendar consumer edge 6300, and first RX port 2 / kind 15 event occurs at 6315, exactly +15. Disabled original BC/calendar outputs are checked against the untouched family continuously. Healthy enabled outputs are anchored to that same original family; no golden schedule is changed.

Negative cases omit an accepted entry/base; corrupt the actually consumed upper data half or base; change accepted epoch or valid metadata (including X in Icarus); alter request epoch; send an early epoch request; reload or reset completed receipts; and present incoherent start copies. Negative checks inspect both actual running states, pointers and their copies, lap bits, current words, repetition/beat state, and interval counters. They do not accept only an output mask.

The unchanged real ot_qwen_d2d_status_rx_sf is a verification dependency from frozen current_safe_fo.sv SHA256 9b3694353d39abc17f83e52f2f6de4273fa3dbe498a138dbee147e436bcefb67.
