The opt-in `tools/die_plan/post_route_drv/prd_filler_preclean.py` prepares a derived cold final seed before DRT initialization. It does not change shared ECO drivers. Run it with OpenROAD's Python bindings and normal measured `ot-run` admission; keep the source immutable and require the successful manifest plus output hash before using the new ODB. Ordinary refill, PG, timing, clock, DRV/DRC, and routed equivalence checks remain required.

The actual N4 final database had 3,732,364 instances. Paired profiles of ordinary post-route filler removal spent 95.94% and 92.81% in `drt::DesignCallBack::inDbITermPostDisconnect`. Separate-DB preparation removed 3,554,800 typed PG-only fillers in 6.76 seconds, 66.45 seconds overall, at 4.15 GB peak RSS. All 177,564 remaining placements, 4,215 ports, 91,357 non-PG nets and 7,057,128 exact wire opcode/data pairs matched before/after, including 1,560 clock nets. The original ODB and SPEF were retained. ROOT reviewed and approved one normal N4 recovery from that derived seed.

`positive_manifest.json` records that actual pilot. The generic successor retains its algorithm and adds usage documentation and refusal of output/manifest path aliases. Its two negative controls passed on the same immutable source: a cold filler VDD pin reconnected to a SIGNAL net was refused, and a shared output/manifest path was refused. Neither unsafe output was written. The reconstructible 1.29 GB mutant was deleted after retaining the generator and receipts. To reproduce the controls inside the OpenROAD image under normal admission, run `bash test_prd_filler_preclean.sh HELPER_DIRECTORY SOURCE.odb FRESH_OUTPUT_DIRECTORY`.

The source commit contains only new helper/control/evidence files and can be cherry-picked independently of its private parent branch. No RTL, cycle, clock-budget, production dispatch, or signoff-policy change is included.
