# Timed HOST reset-command entry proposal

The current exact native b2 has 141 active HOST command-spine outputs:113 die_rst_n and28 hbm_rst_n,141 receivers across27 physical types and5620 leaf reset-pin uses. No receiver has a planned matching-family input bus or a matching HOST-family lane comment. receivers.tsv lists every actual endpoint. Full current graph and old ot_dp_rsync cut: epyc3:/srv/opentallas-scratch2/claude/codex-kv-kits-1713/reset_census/reset_census.json. Regenerate with g3/host_reset_census.py --bind-out BIND --plan PLAN --out FRESH_DIR.

qkd_host_reset_command_rx replaces only the private two-flop command entry. Inputs are timed control signals: the registered local wavefront and the ordinary plan-routed HOST command. It samples both at the clock edge, clears the two control bits on a low input, and releases after two high samples. There is no asynchronous sensitivity, CDC declaration, exception or additional START. All original functional leaf bodies and HOST boot/fault behavior remain intact. Ordinary recovery/removal remains timed at those leaf pins.

Cycle contract from a HOST output changing after edge N: transport contributes the declared routed stage count H; private assertion occurs at N+H+1, release at N+H+2. Relative to the actual old async-assert/S2 receiver on the same transported command, only assertion gains one sampled edge. The 141 ordinary command routes, per-type physical pin/relay placement, native binding and compiler/boot/recovery repricing are not yet integrated; this receiver is off-default until those contracts land. In particular T_HBM_GO160 must be checked against the actual new HBM-reset-vs-boot_go route skew, not assumed sufficient.

Proof uses the actual qkd_host_rst_role_pins + ot_qwen_sys_rst_seq producers, actual bind_cells ot_dp_dly/ot_dp_rsync cuts and actual hub_C qkd_astk_fault_join recipient. The reference is the actual old conditioner with the explicit one-edge assertion change; release is compared without an extra allowance. BASE PASS949 cycles/941 checks covers cold release, HBM boot, warm software reset/replay, real HBM-check fault and role fault. Route bypass, command bypass, polarity reversal and wavefront bypass mutants are all CAUGHT. Re-run under ot-run with g3/run_host_reset_command.py --rtl-root CANONICAL_REPO --out FRESH_DIR. It rejects reused output directories. Not a whole-die token, route, STA or signoff claim.
