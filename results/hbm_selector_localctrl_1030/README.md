# Selector quarter-local control prototype

The existing selector on k26a/k26b has cross-quarter control and compact-buffer placement: A r2r906.88um/9091captures, B823.66um/5496. The parent owns the physical fix. This prototype adds opt-in `LOCAL_CTRL=1`; default0 leaves the original capture/update paths selected.

Four same-edge retained copies each of op4/pass2/addr8 (+56FF) and threshold16 (+64FF) allow quarter placement, +120FF total, 0 latency cycles, unchanged16entries/quarter and unchanged SRAM/port throughput. Threshold copies execute the identical priority/update expression on the identical capture edge. No external ports or SRAM organization change. `MUT=5` corrupts quarter3 op capture only and must fail the lockstep bench. Existing mutants1..4 keep their roles.

Physical status: NOT RUN. This is source-only, not geometry closure, a signed view, or adoption. The parent must keep quarter registers/buffers and the appropriate histogram indices together and resolve west-face input to eastern SRAM paths in its plan before route. No per-quarter-control replica can be claimed at a face merely because the global pin flop remains nearby.

Placement identities: wrapper `grctrl[q].local_copy.{op_q,pass_q,addr_q}`, core `gthreshold[q].local_copy.value`, `gq[q]` local storage/logic, histogram linear indices q*64..q*64+63 (verify actual synthesis spelling). Do not fence unrelated input/output face flops into these regions. Quarter macros are currently q0SW/q1NW/q2SE/q3NE. Fill→buffer locality is tested with quarter affinity first; no speculative160FF fill replication was added.

Proof: `tb_sel_localctrl.sv` compares current default master against LOCAL_CTRL1 on full4quarter architectural state and outputs at each edge, varied opcodes0..15, pass/address/history, asynchronous resets, production-style bursts, and directed15word compaction/pack-write. `old_sel.sv` is the exact base master with module names changed. Inputs use the real behavioral SRAM model. Test receipts and command below are collected after completion.

Threshold replicas use their quarter's already proven identical two-edge reset release.
