# HBM SFU drain-only interface candidate

The actual SFU output-store instance uses only lane writes and two sector drains; its unused lane-read, stage-write and single-word landing inputs were tied to zeros at the parent. The drain-only wrapper applies those same constants internally and removes those inputs from its public interface. This preserves every retained cycle and bit, and avoids presenting 2,048 live tied input bits as die interfaces. No latency change.

The actual shape (16 banks, 16 lane writes, two 8-word drains, 32,768 words) passed 12,304 cycle-exact lockstep checks, including 6,145 nonzero drain observations, all rows, three reset interruptions and write/read conflict fault cases. The seeded candidate write-data mutant was caught at check 2,052. This tests the wrapper mechanism with behavioral SRAM; physical sign-off is not claimed. Logs and bench are adjacent. Inherited strict bind using the wrapper (intel1 hbm-bind-3-1029/b1) reports zero tied bits, 158 unplanned partition pairs and the unresolved native128 reset EMIT; that run does not qualify the whole die.

The wrapper is a candidate for the SFU parent output-store specialization, not a relaxation of R7. Source assembly substitution must require the removed ports to equal their declared zero values, as the existing substitute_inst mechanism does.


Native128 parent source preparation generated 128 exact pair cores across 16 banks and split 32 original capture-vector FF cells by their existing D/Q indices. Re-elaborating these full banks renumbered 61,416 Yosys primitive names. The scoped rebase checked all 63,067 preserved cells, 6,756,789 terminals and 2,578,524 canonical nets for one consistent bijection before updating the old exact-terminal composition/map; the 16 old opaque bank leaves are the only unmatched original cells. This preserves every retained connection and adds zero cycles. Initial failure artifacts remain in scratch.

After resolving the original native128 reset EMIT, source emission reached 12 previously masked `$adlatch` cells. These are the 32-bit loop-local integer `j` (three latch fragments per scorer quarter), with no Q load or module-port export. `dead_scorer_loop_index.py` creates a separate prepared JSON after checking all module ports, loads and keep/dont_touch attributes. The retained 71,041 cells keep every terminal, parameter and top port identical. The mutant that exports one Q on a module port is refused. No latch emitter or RTL storage change is proposed. Remaining genuine emitter work includes dynamic `$shift`/`$shiftx` primitives and the SU four-slot injection array memory ports; this source preparation is not whole-die bind closure.

`dma_native_edges.py` records the actual 16 directed DMA/bank groups for each quarter. Current NW and NE sources each have request136 (8x17), response2056 (8x257), RR_RT80, and direct source connections with no transport FFs. Directions and bit equality come from the actual flattened source. Current D18 physical pin widths agree; older 137/258 station declarations are stale. Clock/reset net IDs and source expressions are retained for the station materializer; transport/reset delivery and latency qualification remain separate.
