Default-off ordinary START/RAW data buffer source preparation

`start_stage_emit.py emit --data-manifest MANIFEST` inserts literal noninverting BUF8s on every owned START edge and, with reset-wave, every virtual RAW edge. No clock, flop, cycle, edge selection or native interface changes. Without this option the existing emitter is unchanged. `start_data_emit.py MANIFEST --out OUT [--plan PLAN]` validates the route/cell ledger and writes explicit FIRM placement plus retention/source-load audit Tcl.

Each edge names src_region, dst_region, signal (start/raw), source_inv, cells, capture_pin_um and routes_um. Source records require actual mapped INV instance/master/orientation/home, source QN flop identity/home, actual QN/A/Y pin coordinates, complete all_output_sinks and outgoing_edges. RAW also requires its existing kept_buf2_instance. Cell geometry and pins are supplied from the locked library with its SHA256. Buffers have deterministic instance names from ident(src,dst,signal), actual sites/orientations, A/Y pin geometry and individual axis-aligned pin-to-pin routes. Ledger fields include site_grid_um, optional site_origin_um, occupied_rects_um and wire_exclusions_um. Source QN-to-INV is bounded by1um, each distinct first BUF8 by3um, subsequent wire segments by100um. Every actual source sink must match after mapping; unexpected native reader loads fail closed. The postmap Tcl checks actual source QN→INV connectivity, gate/flop homes and RAW keptBUF2, and preserves source/data cells and nets. Complete graph coverage is mandatory; unsupported direct native-to-native edges fail instead of disappearing.
