# Qwen G4/W4 explicit-arrival CTS diagnostic

The completed CTS probe is pinned to source and driver commit `2e9996d2f74710a358b59e576a98c8fad5d6396c`. It uses the reduced G4/W4 memory tile at 1.5 ns, ASAP7 RVT TT, two same-phase clock ports, and explicit **assumed** 0.75–1.15 ns min/max arrival for all 26 core command/control ports and six ingress load ports. The port sets were checked against the RTL header and are disjoint and complete. The focused split-clock differential RTL test passed all 16 × 16 output slots and ingress commits. The run stopped after CTS by design.

The outcome is **NOT_MET**: placement-estimated CTS setup WNS −181.954 ps, TNS −10.6067 ns, 176 violating paths; hold WNS −17.486 ps, TNS −0.278099 ns, 50 violating paths. The limiting core-clock Fmax is 594.547 MHz; the separately reported ingress-clock Fmax is 1,955.12 MHz. CTS had zero max-slew, max-capacitance, and max-fanout violations and zero placement violations. It inserted 6,654 hold buffers. CTS standard-cell area is 21,160.2 µm² and analytical macro area 113,104 µm². The saved [physical.json](physical.json) contains the precise source, library, clock, constraints, and metrics. [cts_final_snapshot.rpt](cts_final_snapshot.rpt) preserves critical paths and violation counts from the report while the flow was finishing; power reporting had not yet completed when that snapshot was copied.

Compared with the separately pinned split-ingress CTS checkpoint (`03a5570d`), which had 728 hold violations, −590.117 ps hold WNS and 10,765 inserted hold buffers, this input-arrival assumption substantially reduces *placement-stage* hold repair. It still fails setup and hold. These figures do not establish a routable or power-efficient improvement, and the input timing window is a proposed external contract requiring package and upstream logic validation. Its 6,654 CTS buffers cannot be compared as a final hold-fix cell area to the routed W4/G2 tile's 18,810 final buffers.

No global or detailed route, extracted timing, routed DRC, antenna result, or final slew/cap/fanout verdict exists for this probe. The memory LEF and Liberty views are analytical proxies with no characterized internals or macro GDS; ASAP7 is an academic predictive PDK. This is a reduced block diagnostic, not closure of the two-reticle Qwen3 8B package with 8-bit weights, UCIe layer partitioning, eight HBM3E stacks and 6,144 lane groups per die.

The first attempt at this constraint probe, source `cb99e7b8`, failed before timing analysis because the pinned OpenSTA did not accept `remove_from_collection`. Its raw [invalid-SDC record](invalid_sdc_cb99e7b8.json) is retained separately; it is not a physical timing result.
