# S81 VM current-source geometry audit

This package is an **explicit READ_PIPE=4 / CAP_PIPE=2 native candidate**, elaborated from `c3fc1a4a2a9fe2722ba5f9e7bf938a8802c3c381`. The die generator currently supplies no parameter overrides, so its actual defaults are **0 / 0**. `default_vs_native.json` and both frozen elaborated ASTs preserve that distinction. No parameter adoption, RTL change, route submission or die closure is claimed.

The generator default has **568 hard boundaries**, with **616 hard clock pins**, 72 unused read-root bits, and five active inline clock regions. Its referenced hard-rectangle area is **11.9223587664 mm²**, excluding legacy core and WFC/XIO inline hardware. The legacy core output stage contains **25,650 declared sequential state bits** on one clock; this source mode cannot inherit the native candidate’s root/footprint qualification. See `default00/inventory.json`, `default00/summary.json`, and `default00_inline_state.json`.

The explicit 4/2 candidate has **640 hard boundaries**, with exact hierarchy identity and parameters in `inventory.json`: 352 memory leaves, 150 write edge leaves, 72 read leaves, 46 CDC halves, 17 capture leaves/control, and three sequencer/scheduler/landing leaves. Their actual kit or source-pin candidate rectangle area sums to **13.5055274832 mm²**. All 640 have source-matched port shapes and physical pin coordinates. Kit existence is geometry evidence only: explicit parameter mismatches and current RTL versus frozen gate snapshot hashes are retained. In particular, the 16 actual scatter instances use PIPE=0 while cb4 kits use PIPE=1. Old F4 x34 source bytes differ from current RTL. Current routed netlist identity remains unverified here.

The independent wire join accounts for all **693 raw clock entries**: 688 reach actual hard boundary pins; four reach inline WFC/XIO control regions, and the legacy core clock has no native hard sink. `clock_root_join.json` records every bit. The inline source state is separately recorded as WFC stream 1,725 / serial 4 bits and XIO stream 1,374 / serial 6 bits. These are declared state bits, not mapped FF or area measurements. Their hardened outlines, pin homes and parent combinational glue remain absent.

The historical 4168.8×3715.2 rectangle does not cover this source. Initial complete-known-hard-rectangle candidates are 5529.6×4903.2 for 2×2, and 3542.4×9828.0 for 1×4 vertical. They preserve 468 exact current local bank/q8 write/payload rectangles and place the other 172 known hard leaves in a side strip. They are neither lower bounds nor complete VM footprints.

Actual free-hole packing places 580/640 known leaves in the 3952.8×4903.2 body with 21.6µm clearance to newly inserted leaves; 60 remain, totaling 1.79532288 mm². A 540µm spill strip accommodates those leaves, giving **4514.4×4903.2**, zero body overlaps and all 640 known rectangles. This is a capacity candidate, with missing parent hardware explicitly retained. It is worse electrically: **213,441 of 451,846 measured internal functional pin legs exceed 500µm**, versus 189,816 in the initial larger side-strip arrangement. Maximum compact-candidate pin distance is 8905.434µm. Rectangle compaction is not a timing or routing improvement.

`pin_producer_join.jsonl.gz` preserves exact bit identities. It resolves 508,632 consumer endpoints to one source, separately identifies 634 constant endpoints, and leaves 5,432 endpoints as parent behavior or unsupported expressions. Internal functional reach covers 451,846 bits with zero missing physical pins. Another 55,458 endpoint legs have external die pin homes missing. Clock/reset legs are excluded from functional reach. `boundary_rank.json` ranks actual producer/consumer ports and clock domains, source pin fanout, crossing net widths and geometric minimum extra stages. The 500µm stage rule is a screening lower bound; actual related-clock timing, uniform compiler ages, new physical relay hardware and the token-cost ledger are mandatory before adoption.

The `core.p_src` source packing is clockless static loop wiring. A fail-closed evaluator executes its integer control and ordered blocking assignments before emitting the final 29,203 bit aliases. The 53 source slots each have 512 payload bits; `write_source_map.json` preserves their actual producers. Every SU/HC/MIX4 external bit and landing/capture hard-source bit is checked against the source slot and physical 128-bit slice. Runtime control is rejected rather than treated as a wire. Three focused tests cover ordered overrides, distinct loop bit identities, and runtime-control rejection.

`coherent_groups.json` provides 23 actual source-derived atoms: 16 capture plus CDC three-leaf groups, and seven other related CDC pairs. Capture atoms are 345.6µm square, R0, with cap at [0,86.4], writer at [194.4,0], and reader at [259.2,0]. All **48,857 internal atom bit legs are ≤424.128µm**, with no RTL, pin ordering, edge, or orientation change. All incident external/parent legs still require audit; related-clock STA remains open.

Source ownership proves that each of the 64 read data leaves consumes exactly one physical memory slice. `packing_producer_local.json` places sixteen data leaves, four return lanes, and four FSR leaves with each corresponding slice, while keeping the CDC atoms intact. All 640 known hard rectangles fit its **3542.4×9828.0µm** outline, with no overlaps. On the same strengthened pin graph it reduces >500µm legs from **189,816 to 177,504**, and total functional pin L1 from **509.278M to 483.859M bit·µm**, compared with the initial vertical candidate. However, maximum distance grows from **12559.290 to 12833.178µm**. This is a tradeoff, not a selected improvement.

The new complete source join exposes long capture-stream packet → W0 payload legs that were previously unresolved. The candidate’s mask leg reaches 12833.178µm. Merely closing a cap/CDC atom moves its distribution problem downstream: one whole 512-bit cap frontend supplies four 128-bit W0 physical slices. `boundary_rank_producer_local.json` therefore records uniform packet-age lower bounds across all row/data/mask/valid fields. Real RTL staging or repartition, matching compiler ages and measured token cost are required; no extra stages are adopted here.

`clock_candidate_homes.json` exports all 693 ABI clock entries and the 688 real hard clock-pin coordinates for the producer-local development placement. Routed insertion measurements are references only; source/parameter mismatches and missing parent phi−wire−R proof remain explicit.

The reviewed q8 pin plan explicitly selects W-output capture variants for banks0..3 and E-output variants for banks4..7, plus the existing source-bound south-drain E/W storage pin candidates. Native W capture is a physical master override; the die binding is not adopted. Every pin source path, git source and SHA are retained.

The full 640-leaf pin inventory uses routed LEFs when available, assigned pin Tcl otherwise, and source-bound candidate pins for the 150 write leaves. Every per-bit reach file identifies which source pin supplied the coordinate. Native timing/DRC, whole-die obstacles, clock/PG/reset routing, complete cut capacity and all-source functional calendar proof remain open.
