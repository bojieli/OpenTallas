# KV plan of record: event28w_c

`plan_c.json` is the current event28w_c plan, with portable filesystem references and the explicit E0 equivalent-view orientation correction described below. The original byte-identical plan is preserved in `plan_c.original.json.gz` (SHA256 16980115aa4afb56; full SHA in relocation.json). `eW_sidecar.json` is the unchanged native crossing sidecar. `pins/` contains the 36 exact pin tables referenced by the plan; relocation.json maps every source path and payload hash.

This package replaces host-dependent references for consumers; the older ../die_plan.json is historical and does not define the current interfaces. The publication initially relocated paths only. The later E0 correction changes ten raw-pin/MX entries to the existing signed fMX view at R0. Every parent-frame signal pin, all exposed PG rectangles, and all LEF obstruction shapes remain exactly the same; origins, outlines, clocks, reset, nets and cycles are unchanged. The clock.mesh.sites_file reference is historical and its payload was absent beside the source plan; this package does not claim a fresh clock qualification. Existing clock results are on the separate kv_e26a_w243 tree.
