EXACTNESS ARGUMENT (WDECOUPLE), checked in the RTL: sticky is assigned only <=1 (reset clears it). A sector compare miss sets
sticky at the same edge the word/present write lands; the gather/complete read those regs one edge later at the earliest,
when row_write (=row_slot&&complete&&!sticky -> w_q -> SRAM w_ce, WPIPE 0 or 1), read_ok/out_valid (&&!sticky), open_ok
(&&!sticky) and the whole running&&!sticky branch are off; present[] is cleared only by open_ok or reset. A WPIPE write in
flight at that edge carries w_data_q captured from the pre-miss words. So no port sees a word/present bit written in a miss
edge. GSEL: head changes only at reset/open_ok (->0) and running&&!sticky&&row_slot&&complete (+4/+5); one-hot vectors
follow it by rotation, invariant gsel[j]=onehot((head+j)%16).
