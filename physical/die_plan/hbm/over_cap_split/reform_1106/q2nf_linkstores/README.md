# Q2NF three-child source form

This is an opt-in structural extraction of the current `OT_Q2NF_TGTQ1` Q2NF rest. The original `reform_1105b/ot_q2nf_rest.sv` and every existing recipe remain unchanged. New source `rtl/hbm_accel/cores_split/reform_1106/ot_q2nf_linkstores.sv` contains `ot_q2nf_control`, `ot_q2nf_linkstore0`, `ot_q2nf_linkstore1`, and their wire-only `ot_q2nf_linkstore_parent`. It adds no register or cycle. Existing A physical run and routed-proof attempt are preserved.

Actual native RVT TT mapping uses the canonical ABC speed script,833ps and the same prohibited tiny cells. Controller:85,672 standard cells,13,490.71362um² and11SRAMs. Link0:21,211 cells,3443.12532um² and4SRAM64x512. Link1:21,216 cells,3445.89552um² and4SRAM64x512. These are mapped counts; actual placed counts remain unmeasured. The128,099 mapped-cell total is not substituted for the retained A's209,669 actual placed cells. Macro area is separate from the reported standard-cell area.

`tools/hbm_die_v15/q2nf_linkstore_extract.py` uses existing canonical Yosys submod grouping. It assigns complete named link state/macros and their private anonymous combinational cones; shared named drivers remain once in controller. `prepare --split-rest` prepares the three groups; `trim` removes only unused child input bits and records every original packed-bus index; `compare` checks the exact sequential cell/parameter/driver graph, independently of hierarchy and net numbering. Preparation input is the proc/flatten/opt_clean/splitnets/rename-wire JSON; source flags must be explicit. `native_gen.sh` records the submod, input trimming, replay comparison and final module names. SRAM blackboxes stay real instances.

Full production shape comparison after three-child reconstruction and ABI trimming: **PASS,9928 hardware cells**. No original cell, parameter, register state, input driver, output connection or cycle changed. A96-cycle RTL lockstep miter on the smallest two-store/shared-control extraction passes; dropping the first child's write enable is caught at cycle12. The component fixture deliberately has small memories; production shape is covered by the exact graph identity, including all19SRAM instances. An earlier bounded-SAT prototype was rejected because its negative control was not sensitive to an unwritten, uninitialized mutant SRAM under optimization. That prototype is not used as a proof gate or claimed as a pass; retained diagnostic artifacts remain on epyc6.

Raw clock ownership is explicit in `boundary_clocks.json`. Clock buses are indexed: link0 control3303 clocked items use original `clk_link[0]`, four bank domains587 items each use `[1..4]`; link1 uses `[5]` and `[6..9]`. These are actual parent clock-port connections, not an assumption that all ports are independent async domains or interchangeable clocks. Controller retains scalar and vector-indexed control/program/issue/reduce/upipe/qslots/link clocks. Child input ports are packed after trimming: `split3.json.ports.json` maps each new bit to the original index. For example link1's five packed clock pins map to original `[5..9]`. **Never assign every R2 face to the factory's first clock.** Preserve the actual source/sink ownership and existing CDC/reset semantics; common-clock compatibility is insufficient for native async qualification.

The inspected parent proposal retains786.24x622.08 and all19A SRAM positions, with224.64x414.72 west/east link children,224.64x606.96 center controller,21.6um inter-child channels and substantial parent shell row reserve. Before P&R, the owner must bind the three actual hard children into a native R2 parent, assign bus faces from the exact ABI/clock ownership, and review actual PG/OBS/layers and fixed anchors. This source change does not activate a B route or claim that signed children or a qualified parent already exist.
