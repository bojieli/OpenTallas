# SU operand-face variant

Distinct optional source, no canonical recipe or signed view changed. Use the five new modules together with the byte-identical support files captured in the existing l1r5/i3 signed kit. The combined bank owns operand read enables locally; index reads and address/data/reset phases retain the native internal path. Only external operand metadata gains two edges.

Production vectors and real SRAM tests are in results/die_hbm_1106/su_opf4. Dense, idle issue gaps, permuted programming, reset/reseed and varying VI index paths pass. Operand, external enable, index-delay and payload mutants fail. The old signed faced master fails this naked native programme, so its physical view cannot qualify the new master.

Physical qualification and selected source-profile scheduling are required. The direct FO4 vehicle first output changes41 to48; indirect new first54. These measurements are operation-specific, not a blanket added core latency.
