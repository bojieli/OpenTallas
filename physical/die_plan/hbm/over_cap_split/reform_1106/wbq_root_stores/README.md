# WBQ_ROOT eight-store family proposal

The eight-macro M6 alternate failed with113512 global-route overflow despite73% aggregate usage. Parent fit work rejected straightforward north/down/east expansion. This profile keeps the old432x129.6root slot and proposes eight103.68x60.48store children in4columns/2rows, with shared controller as soft parent glue.

Each store contains the existing128x256SRAM, W288/AW2CDC FIFO, row/pending state, sector adder, and its existing256-bit WD input face. The other input faces and g_d output face remain in the controller. Relocating those WD registers preserves every capture edge; ordinary extra face shells on all helper seams would change behavior and invalidate the area estimate. `family_profile.json` records each connection, widths, cycles and candidate rectangles. The native R2 peer/parent glue binding is still required before helper P&R. This is no global face/STA exemption.

Default source and recipes stay unchanged. `ot_wbq_root_stores.sv` is the optional raw decomposition. `OT_WBQ_ROOT_STORE_FACES` chooses store_face with the relocated input capture. `ot_wbq_root_store_family.sv` is the outer composition shell derived from the actual old routed shell, with WD faces bypassed exactly once. Compile that composition with this define, the variant source and its separate ot_wbq_root_store_leaf.sv, the existing ot_hbm_face_reg, CDC FIFO and reset_sync.

Async full-shell exploratory proof alsomatched but traffic was reduced by violating that common-clock basis; raw-body async proof is separate and active. Artifacts under proof/family. No added interface cycles. Benchmark shared SRAM model is the same old/new; valid outputs are compared exactly.

A second targeted mutant removes the relocated WD input capture; all768writes mismatch at9636checks. This directly checks the no-added/no-removed-edge contract. Final source split is a byte-preserving extraction of the raw store module into ot_wbq_root_store_leaf.sv; proof staged combined source is otherwise identical apart from explicit mutation controls. The proposed drawing is a source-sized layout estimate, not a routed-kit review.

Clock qualification: raw WD/reserve/fill/copy state is fifo_clk; g_credit/h_stop and g_v/g_d arbitration are hbm_clk; root_ready is fifo-reset derived. The historical factory outer faces all use fifo_clk. Parent verified actual retained t11_top.wbk_NW binds stream_clk,hbm_clk,allfourstream_fifo_clk to hb_ckgen__pll_stream[0], resetsPLLpor_stream, so the common-clock composition proof is appropriate there. This is not blanket qualification for any distinct-clock profile. Every native clock pin/CTS root, PG and seam context must remain correctly bound before physical adoption.
