## SAFE-DESIGN checklist (owner 10-19)
1. Pins: PASS. tx lands in face reg u_txf (ck_tx); rx / st leave lp out_regs (ck_tx); child pins are closed-tile pin regs;
   PMA pads (pma_tx/pma_tck/pma_rx) are the analog PHY pad pins (off-die). Reset: rst -> root stage + 4-stage run per
   region + t(child) pads (>= 2 registered stages at every child).
2. Reach: PASS by construction (gate lint measures). TX enc -> r0 -> r1 -> landing ring -> read (E = 2 multicycle) ->
   PMA TX: ~1.3 mm over 4 single-cycle hops + one 2-cycle hop; decoder landings between abutting tiles; reset runs sized
   by lp at 405 um/hop.
3. Fanout: PASS. Every child reset pin has its own pad; live flags drive one pin; landings per reader region.
4. Depth: PASS. Parent glue is registers only (landings, pads, relays, syncs); no parent combinational in -> out path.
5. Storage: WAIVED with reason: u_rm's 8 x 512 elastic FIFO is a flop array (as in the closed s81lk_rate_match tile;
   a dual-clock SRAM raw macro is not a supported landed-cluster sink); the 13 lp landing rings (D 4, 12,734 flops) are the LANDING-CONTRACT primitive
   (fixed-rotation write ring, no runtime-indexed storage); e_flt 6-stage 1-bit status pad is trivial.
6. Floorplan: PMAs (43.2,43.2) W / (345.6,43.2) E and all six children on the 43.2 lattice; pin densities tx 3.0,
   rx 3.2, pma 4.35 pins/um (<= 6); util measured by the gate. Aspect 7.4:1 WAIVED: approved die-edge SerDes slot
   (column of 6 local clock regions, each region near-square); E strip + PMA gap carry the std-cell band.
7. Clock: PASS by construction (gate measures). 6 regional roots, each port on the face beside its region; landed
   crossings; pin-flop spread <= 80 ps TT+FF judged per linked child pair; io_hold_margin 0.03.
8. Schedule: PASS. Static; every added edge in the lp record compiler block; the only elastic element is the rate
   matcher at the off-die SerDes boundary (owner hbm-static-onchip: flow control kept at off-die boundaries).

Die obligations: drop rck (from the pma_rck pad / partner pma_tck) at ck_syn/ck_dly/ck_chn/ck_out (W face) and clk at
