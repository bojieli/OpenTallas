# KV RoPE73 embedding physical implementation

Actual accepted compute-native per-head CONTEXT owner and epoch start two static HBM sweeps. The second sweep reads the appended RoPE pseudo-token row; eight selected words are staged separately and sent after the embedding header and64 code words. The table/image source is the sole EW1627 R16 RoPE pair.

This kit has its own source/master, HOST record face, service-word proxy and two SRAM macros. Earlier embedding views do not bind this source. Source generation, native control update and physical closure are in progress. No behavioral or timing closure claim is made by this draft spec.
