# qkd_d2d_cal_seq_pin_bc4w (KV-DCAL 10-19, PARALLEL FALLBACK (owner PARALLEL rule: different kit name, same RTL, lower utilisation + denser pin pitch))

The KV link-end calendar sequencer for the MU release die (kvs14 MU), on the coherent codec2 **K22** image (`d2d_cal_image_mu.svh`
SHA e7d4d2d0, `D2D_TXDP_K 0x03030416`, from 5ae543bfa).  Top `qkd_d2d_cal_seq_pin_bc4`, generated by
`tools/qwen_static_kv/gen_dcal_bc4.py` (it refuses any other image or primitive) into `qkd_d2d_cal_seq_bc4.sv` +
`ot_qwen_d2d_cal_seq_bc4.sv`.  Function = bc2 (`qkd_d2d_cal_seq_pin_bc`): boot target 11 cfg (`bcfg_*`) merged with the
sequencer's runtime SEG1/SEG2 base writes into one registered cfg producer; sticky faults COL / RUN / STALE / EARLY + the
sequencer's own, OR-ed into the registered `fault` output.  Structure = Codex bc3safe (190b12e9f): RTL-owned 2-stage reset
landing with kept copies and per-use kept selector/control copies.

Why a new tile: the bc2 native audit (15c5583ad) found source reset fanout 206/45 (> 32), an unread `fault`, and the bc2
E-face pins at x = 18.72 inside a 21.6 um outline (stale io_pins.tcl from the 18.792 kit).  bc4 fixes all three in the tile:
reset sources <= 23 loads, `fault` on the E face for the parent fault lane, pins regenerated on the real faces.

Outline 28.08 x 34.56 um, no macros.  Pins: W = link-end face (cfg/cal words, epoch_go, halt), E = status + `fault` +
boot cfg in, full-face centred on M4; S = ck (centre), rst_n, reload on M5.
