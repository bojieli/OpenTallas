# Defined first use and reset role

This contract describes the unchanged BTAB S4 source from `3f0f4b600`. It changes neither RTL nor the closed timing record. The scoped evidence is in `results/arch/qw_btab_firstuse_0720`.

The component has no reset port, resettable storage, or promise of an initial zero value. Its actual mapped FF masters have no Liberty clear or preset roles; the physical SRAM functional model has no reset operation. Constant-zero repair configuration pins are configuration, not resets. The proof disables the physical model's optional initialization and gives the reference and candidate independent initial FF and SRAM state. This is an explicit no-reset role inventory, not a synthesized reset waiver or a framework typed-reset receipt.

A kind-2 write sampled at edge W installs a complete 1024-bit row group across all four 256-bit banks at address `tw_addr[8:2]`. A read sampled at edge R is defined when that row had a complete prior write. Its selected 256-bit response is visible after edge R+1 and may be captured by a downstream FF at R+2. Concurrent read/write to a previously installed row returns the old word, following the actual physical model's read-before-write order. A first write concurrent with a read of an uninitialized row does not define that read's response; a subsequent read is defined. There is no reset or hold-value promise outside commanded responses.

Initialization is per row. A selected row may be installed and consumed while all other rows remain independent and uninitialized. The parent must prove that every consumed read addresses a previously installed row and uses the stated response age. No global warm-up contract or fixed startup mask is claimed. Liberty clock/setup/hold timing supports the sampled-edge model; Liberty alone does not specify collision data semantics.

The standalone leaf stores 512 logical 256-bit words: 16 KiB. Four physical 128x256 macros provide the same nominal capacity. Including modeled physical spare rows and columns, their aggregate array is 134160 bits, or 16.376953125 KiB. Any parent BTAB/BSCALE reader replicas must be charged separately; this is not a whole-parent capacity claim.

The new finite proof uses the actual physical SRAM model with `OT_MEM_NO_INIT`, three independent random seeds, and no fixed-cycle or full-table warm-up mask. Each seed checks 921 defined outputs and every one of 512 row/bank first uses, with 507 comparisons before global initialization. The first defined read is sampled at edge 3 and checked after edge 4, with only row 37 installed. Actual select, output-age, and dropped-first-write causal mutants each fail at that first defined output. Raw logs and hashes are preserved in the evidence directory. An additional 16384-cofactor source-equation certificate checks the selection equations with arbitrary bank data. These are finite RTL/physical-model checks plus source equations, not universal mapped-state formal equivalence.

The earlier warm bench and closed physical receipts remain immutable. Parent installation provenance, replica count, nominal clock compensation (leaf TT/FF means 209.1/171.0 ps), and neighbor composition remain integration obligations. This leaf contract does not qualify a parent composition.
