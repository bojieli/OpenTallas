# s81sl_xr1f (ot_s81sl_xr1, FOREG=1): PARALLEL fallback of s81sl_xr1

This kit has the same top, RTL, outline and pins as `s81sl_xr1`, built with `--param FOREG=1`. Spec: `spec.json`. Generated by `tools/ref_tile/ref_tile.py gen`.

- XR6 registers the sticky-fault terms per region (`fa`/`fb`/`fc`). `fcore` is sticky, and `fault <= fcore` is a dedicated output flop with no recirculation at the pin, so `io_flop_at_pins` anchors it and pin_reg_split is off.
- Fault visibility is +2 cycles. It is a diagnostic flag, not a schedule input.
- SAFE checklist: identical to `../s81sl_xr1/README.md` (XR5 + XR6 tables). Item 1 differs: there is no pin_reg_split, and the fault pin flop is a plain flop->pin.
- Benches: `results/rtl/s81_slice_1019/xr6/fb_*` (base) and `fm_*` (mutants), with `XR_FOREG=1`.
- Bind whichever of s81sl_xr1 / s81sl_xr1f closes first under the checklist, and cancel the other. If this one wins, flip the `ot_s81sl_xr1` FOREG default to 1.
