Fallback for qkd_kvs_grp_h_s3a/s3b: both s3 gates were WARN with reg->out -345 / -350 ps on rsp[527] (TT placement RC).

AND krsp[1+i], E-face pins ~196 um apart, so the flop sat between them and both pins paid a long output wire inside the
0.2 T IO budget. s4: the output stage is built twice as KEPT exit copies (u_rsp_x -> rsp, u_krsp_x -> krsp, module
qkd_kvs_rsp_exit_s4: unparameterised, (* keep_hierarchy *), and in SYNTH_KEEP_MODULES so opt_merge cannot fold them),
same D (the registered internal stage idata / it / ivv / ie / il / iv) and the same edge: +0 cycles, +1062 flops.
Everything else (floorplan, pins, macros, clock a, SDC, boundary) is the s3a kit.

DOMSPLIT MU/BOOT_AGES tiles with the s3 ages; m0 must PASS; m1..m8 (s2/s3 mutants) and m9 (krsp exit copy data bit 0
inverted) / m10 (rsp exit copy t bit 0 inverted) must FAIL. Witnesses results/rtl/qwen_kv_die/kvs_grp_s4_1019/b1.
