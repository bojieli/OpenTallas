# ot_qkh_ktree_lk (KV-DCAL2 10-19, K.STA.ECTL KPV_LOCKSTEP)

KV-DCAL2 10-19 K.STA.ECTL KPV_LOCKSTEP (ROOT: no blanket lockstep admission, apply misc_b): ot_qkh_ktree_lk = the closed ot_qkh_ktree (ot_qkh_ktree_m5, same RTL + the m5 fastfp snapshot) wrapped so all 16 lane kpv are read: lane mismatch vs lane 0 -> lane fault into the existing gf_r -> g_f path (XOR16 + OR, 2 gate levels before an existing input flop).
