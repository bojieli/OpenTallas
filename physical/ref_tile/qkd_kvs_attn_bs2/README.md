## Pin registration (CTS-authorization item "first/last physical-pin registration", closed by KV-ATTN as delegated authority)
Census of 6326ff81a (ffb895c67 census.json.gz, re-derived by check_pinreg.py): 511 input bits reached logic before a flop --
d2d__rx_payload[511:0] minus 5 (507 b) -> OR5/OR4 zero-test partials -> 17 plain DFFs (codec status_nonzero), and ufk_{WS,WN},
ufk_{ES,EN} -> OR2 -> 2 async-reset fault-root DFFs; 107 output bits are tie constants (no timing arc).  pinreg.py:
* RETIME (17): each zero-test flop F is removed; its QN net is driven by a copy of its cone fed from the EXISTING plain RX landing
  flops (L_p, D = pin) through an inverter: F(t) = cone(p(t-1)) = cone(L_p.Q(t)).  Zero added edges.
* SPLIT (2): each ufk pin gets its own flop (same CLK/RESETN, own TIEHI SETN); F.QN = AND2(QN_a, QN_b) (OR is idempotent, the
  reset value is preserved).  Zero added edges.
* OUTPUT launch chains (pin_reg_split.tcl semantics done IN THE SOURCE, because the hook's deletion of the old chain hits the
  native dont_touch cells -- first gate 1dcf21fbb FAIL ODB-0362 in pre_gpl): 366 output ports whose flop was shared or also
  used internally get a cloned flop + buffer chain (same D/CLK/RESETN/SETN; constant set/reset via fresh tie cells; any clone
  load on a net already at 24 rides a BUF copy); 395 load-less old chain cells (incl. 1 flop) deleted.  0 cycles.
Result: 34,576 cells / 6,390 FF; every input pin -> flop D only; every output <- an EXCLUSIVE flop chain (<= 1 BUF/INV) or
tie; every native cell is keep-only (Yosys preserves it) and NOT dont_touch: the pin hooks / iohold / CTS hold repair and the
timing-driven resizer must reconnect and buffer (gates 1dcf21fbb ODB-0362, aecfc7ed7 ODB-0370, 657ad3fd4 RSZ-3006); the ORFS
floorplan runs no remove_buffers; logical fanout <= 24 is re-checked on the synthesized netlist by the gate; max non-clock fanout 24; max FF->FF combinational levels 18 (was 17); 0 undriven nets.
Equivalence: tools/qwen_kv_die/attn_pinreg_1019/eq_bench.sh (Verilator 5.050, actual Liberty models): lockstep vs 6326ff81a on all
