# hnx_rp3lp3x — SM P = 3 matrix tile, next-release HBM die (owner 10-19 P3+(a))

The tile is generated by `tools/hbm_next/sm4/hnx_rp3lp3x_kit.py` into `physical/hbm_next/sm4/hnx_rp3lp3x_spec.json`, with pins and stations in tcl. Generate the kit with `python3 tools/ref_tile/ref_tile.py gen physical/hbm_next/sm4/hnx_rp3lp3x_spec.json`. The kit needs the `hnx_xs3` view, so it can only be generated after the xs3 kit `hnx_rp3lp3_xs3` is reviewed and routed. No stand-in path exists: SM4 never gated its lever-(a) tile for the same reason. The kit directory therefore holds only this README until then.
**CRITICAL (hnx_rp3\*):** report only to `lanes/COORD-REVIEW-QUEUE.md` [HBM-NEXT]. Write no REVIEW.json and do not submit.

RTL top: `hnx_rp3lp3x_flat_lp`, generated by lp.py from `hnx_rp3lp3x_flat` (`rtl/hbm_next/sm/hnx_rp3lp3.sv`).
- It is hnx_rp4lp4x with the P-generic leaf `hnx_rp4lp4_lfx` at P = 3. There is no logic fork.
- Each leaf has 1 `hnx_xs3`, 3 block-dot columns and 3 BF16 lane columns (CLOSED d4g views).
- Two landed regions, n and s, with 3 landings: bin_l 2,069 b, the leaf-0 gather 50 b, and the pass gather 100 b.
- Lockstep record: `results/arch/hbm_next_1019/sm4/p3/hnx_rp3lp3x_flat_lp_record.json`.

## Geometry (measured from the floorplan; synthesis area from the gate)
- **Outline 630.72 x 2,203.2 um = 1.3896 mm2.** This is exactly the DIE P3 SM slot (f4c_t9p3 stand-in "lever 630.72 x 2203.2").
- **Children:** 34 hard children (2 x 13 leaf + 8 transport). Hard area is 690,565 um2, a hard fill of 0.497.
- **Std-cell estimate:** about 45-60k um2, from about 20k soft flops in lane fronts, XREL stations, publish rings and gather, plus 13.7k lp landing/pad flops and pin flops. That gives a total fill of about 0.53-0.54. The gate measures the real figure.
- **Layout:** leaf 0 / leaf 1 rows as in the generator docstring. Every child origin is on the 43.2 lattice.
