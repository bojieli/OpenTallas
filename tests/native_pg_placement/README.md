Native placement-hook PG ordering canary
========================================

This test executes the actual clock_spine.tcl or landed_raw_tap.tcl hook with native OpenROAD timing and placement. It requires the immutable original 3_place.odb (SHA256 d57b1ea74ef14cbf8f89d66337c35938edc0847afed4bfeb87b3ab3fb419d3d2) and adjacent 3_place.sdc, copied into an independent writable fixture directory. It keeps sixteen existing native flops and creates one test-only macro with two clock inputs. The macro is a mechanism fixture, not a qualified physical macro. No route is run and no released artifact is modified.

Run cts.tcl in the pinned image openroad/orfs@sha256:16470cea1d346bfa245e402108995a4f04a1e54fe7c7bb7441774d7f6a2ece29 through unpinned ot-run. Mount this directory and the copied placement inputs at OT_PG_CANARY_ROOT; mount the exact common_flow source at OT_PG_CANARY_SOURCE. Set OT_PG_CANARY_DB to the copied DB, SCRIPTS_DIR to the fixture directory, OT_PG_CANARY_MODE to spine or tap, and OT_PG_STRICT to 0 or 1. The native entrypoint is /OpenROAD-flow-scripts/tools/install/OpenROAD/bin/openroad. The two modes use separate processes; the fixture cts.tcl provides the real Tcl source-frame API guard, but is not the complete canonical ORFS stage pipeline.

The estimate wrapper independently checks every native POWER/GROUND MTerm of every inserted spine/tap buffer before invoking the real native estimate. Strict mode fails on any missing connection, then exercises the native final-write guard and all-native-terminal census. Spine mode applies a distinct native clock-wire RC for balancing and restores the platform RC before its final estimate. Tap mode measures propagated raw/ref clock arrival after every insertion. Default-off traces must match the same test with the base hook sources. Old strict hook sources must fail before the first affected measurement. OT_PG_CANARY_PRE_SPEF=1 reads a valid partial SPEF before observer installation and must refuse admission based on actual native annotation state.

Run the two modes independently. The inherited composition spine→tap attempts to disconnect a protected spine net and refuses ODB-0372; this test does not clear protection or qualify that composition. The failed attempt is retained with the passing separate mechanisms.

Evidence is in results/rtl/pg_placement_hooks_1019. It demonstrates ordering, actual timing queries, calibrated RC restoration, final PG checks and bounded default-off identity. It does not qualify production timing, geometry, extracted electrical equivalence or parent adoption.

OT_PG_CANARY_PAD=1 forces a small initial pad estimate so later balancing iterations insert additional native buffers; this checks fresh rule expansion over trial batches. OT_PG_CANARY_DIRTY=1, in strict spine mode, creates an unrelated nonclock buffer and binds its PG through actual add_global_connection calls. The explicit binder must then return zero while global dirty is two. The actual clock-protection hook must refresh placement exactly once despite zero new clock buffers, then leave dirty zero. OT_PG_CANARY_CLK_SOURCE can select the old hook for the causal negative; its zero-refresh result must fail the witness. These test profiles change no production defaults.
