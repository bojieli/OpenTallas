# Qwen RG6 registered north/south face prototypes

These four independent leaf masters are candidates, with no approved die slot, no routed view, and no signoff claim. EN0 adds one ordinary CLK capture edge. EN1 adds one ENGINE capture edge and samples the early engine qualifier `me_e` on the preceding CLK edge, matching `ot_qfd_vm_xrelay_t` with MEREG=1. EN1 retains four enable replicas, each driving 128 data bits. None of the leaves has a reset port, matching the existing delay1 and xrelay modules; the bench exercises upstream reset/flush patterns by clearing data and engine qualification.

`sn` puts `d[511:0]` on S and `q[511:0]` on N. `ns` reverses those faces through a separate physical master and kit. Both control inputs enter W. The proposed outline is 129.6 x 12.96 microns (core 125.28 x 8.64). Signals cap at M5, with N/S ports on M5 and W control ports on M4. These preliminary kit pins must be replaced or re-gated against the die lead's assigned pin file before integration. No rotated reuse of a differently pinned master is assumed.

Run the independent scalar golden with `bash tools/qwen_sn_face/bench.sh /tmp/face-bench 0`. Modes 1, 2, and 3 corrupt data, ignore ENGINE stalls, and consume the early qualifier on the wrong edge respectively; each must return nonzero. The bench compares all 512 bits after every applicable edge across 4200 edges, including random stalls, one-hot walks, all-zero/all-one extremes, and upstream flush sequences. The initial output can be unknown because the leaf has no reset; enabled comparisons begin at the first qualified capture.

Generate and probe each kit using `python3 tools/ref_tile/pre_route_gate.py tools/qwen_sn_face/qfd_vm_face_sn_e0.json --remote auto --cts --mem 6` (substitute the other three names). This runs only synthesis, actual floorplan/PDN/IO placement, and placement/CTS with three-corner insertion measurement through `ot-run`. It does not submit a closure-loop route. Period remains 833.3 ps. A prototype gate result cannot establish die-slot approval, complete routed timing/DRC, insertion signoff, or parent timing closure.

The initial local checks warn that recipe-2 pin hold cells and fixed pin-flop bands may consume the shallow core. Do not infer feasibility from arithmetic pin capacity or a local WARN verdict: inspect actual placement and CTS results. Failed and superseded probe scratch must be deleted after preserving diagnostic evidence.
