# Current selected-parent minimum

`python3 tools/qwen_tokfunc/s6c_parent_minimum.py --authority INPUTS_FROM_CURRENT_GEN.json --out NEW_OUT` is the next bounded parent command. Run it through normal unpinned ot-run with an initial 32 GiB / 4-thread declaration after actual inputs are complete. It compiles one bounded parent cut once, then runs the same binary positively and with the first actual boot word changed. It does not launch the complete die or duplicate the separate r17 attention build.

The input packet uses schema `opentallas.qwen.s6c-parent-inputs.v1`, status `QUALIFIED_SOURCE_GEN_INPUTS`, a full source revision, and exact source/GEN/parameter/age/image digests. Both typed authority files use schema `opentallas.qwen.s6c-parent-authority.v1`, the same status and exact source/GEN/epoch/profile binding. A synthetic or incomplete packet refuses before source generation or compilation.

The selected cut must contain the real boot-dispatch consumer (`qkd_kvs_ctl`), S6C group, authentic SRAM PC/PC_H parents, real recurring descriptor owner (`qkd_kvn_ctx_ovl_rope`) and actual admission calendar (`qkd_d2d_cal_seq_pin_ovl_rope`). At most 16 selected parent instances are allowed. Their master sources are read from the immutable revision; named instance connections are extracted from the exact actual GEN die.v. Original GEN aliases and constant straps are retained. Missing pins, unknown widths, changed source or two actual drivers refuse. No child output is forced, and no historical flop-array parent substitutes for SRAM.

The source-bound clock authority supplies actual clock nets and integer-femtosecond `half_period_fs` / `phase_fs` values, preserving sub-picosecond phase offsets. The driver authority supplies compiler-derived external pin events and independently expected parent outputs at named domain edges. A driver edge is the positive capture edge, numbered from 1; values are set at its preceding negative edge. The first edge's values are initialized before clocks start. Every check observes actual connected DUT output nets, after the positive edge. Source-derived hierarchical monitors must see nonzero boot acceptance, first token data, cold SRAM writes and cold SRAM reads. They do not replace the independent data checks.

Boot images are not preloaded into DUT memories. `image_streams` supplies verified current GEN hex images, actual target IDs, source-bound domain/start edge, and the real selected dispatcher instance. The runner derives its boot-pr/target/ready nets from the original GEN named connections. It emits the existing dispatcher ABI (64-bit word, 10-bit address, valid bit 74) and seals each image through the real ready pin. The actual boot/programme exporter must provide these images and dates; historical images or guessed offsets are not fallback inputs.

`--prepare-only` emits the selected source tree, actual cut and boot-word stimulus without building or simulating. Use a separate new output directory for the eventual run. The template has no current GEN identities or dates and intentionally refuses.
