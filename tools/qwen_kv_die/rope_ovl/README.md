# Coherent RoPE KV source integration

Opt-in `OT_KV_ROPE_OVL=1` requires actual RoPE and MU source and the non-OBSX partition. It selects the independent K TX/RX list player and OVL sfm3 link end. The sole pair compiler owns the generated `ovl_release_rope` image, wrapper constants and both K list ROM payloads. The historical EW595 source and chains remain independent.

The K consumer receives actual recurring Ckind12 O61 from the link record face. Only the actual adm_done recurring phase qualifies these records. Admission may label a filler CONTEXT with calendar user0 and a different owner; it never installs the per-user bank or starts embedding here. A real adm_done fork also qualifies the embedding consumer; this is a phase qualification, without waiting or flow control. User identity is O61[44:43], the low two epoch bits. A four-entry owner bank checks that identity against the independent RX calendar user. It rejects an older seq14, or different token/position under the same epoch, while allowing identical repeats and forward jumps after cancelled allocations. Live wrap is rejected. The explicit program-begin fence clears validity and per-user stage counters; fault remains reset-sticky. RX calendar starts derive stage1..36 per user. The KVN expected identity never comes from received KVN data.

The K embedding source checks the same descriptor user and checks each EMB TX slot user against the retained owner epoch. KVN-bank faults flow into the existing embedding health fault. There is no queue, wait, credit or arbitration.
