ROMQ parent composition capability, not an adopted physical parent

`ot_v41_rom_elem_q_qxpq_w10_gb_shell` wraps the already proved two-half split. `IOREG=0` is transparent and no existing caller changes. New parameters are appended after the split parameter prefix.

The proposed signed-child profile is IOREG=1, OLAT=1, IFN=1, RSTP=1, CGR=0. It captures all 605 inputs together: the 604 data/control/tag bits AND reset. This shifts autonomous child state and reset assertion/release by the same one edge as payload. All 131 output bits, including walking/free/busy/fault, share the second register stage. The profile adds two interface cycles for rising-edge producers/consumers and one child reset edge. OUTPUT_NEG=1 uses the child's falling OLAT edge, giving a full-cycle child-to-parent hop; OUTPUT_NEG=0 is the rising-output alternative. The falling-output form has the same previous-value convention after rising edges as the existing OLAT interface. Other parameter combinations have no latency qualification from this work.

`romq_shell_bench.sh OUT` tests the exact shell with an interface fixture, not a second arithmetic implementation. The fixture models input/output lockups and includes autonomous state to detect reset-age mistakes. At 833 ps, six producer arrival phases and repeated stream resets, the positive checks both output-edge choices and default bypass: 11,934 whole-word comparisons and 2,400 reset-age checks. Tag-stage bypass, output-status bypass, reset-stage bypass and output-bit mutants all fail. The real NB=2 versus two NB=1 arithmetic/status proof remains `qxpq_split_bench.sh olat`; this fixture does not replace physical signoff or the real parent handoff.

No plan, binder, timing constraint, existing RTL module or child layout changes here. Parent adoption still requires both qualified child packs, exact sealed child parameters, coherent reset/cycle metadata and native handoff, actual parent contents/pins/PG budgets, reviewed geometry and normal routed signoff/LEC. A private 545.40x230.04 parent proposal places the unchanged 268.38x221.40 halves at (4.32,4.32) and (272.70,4.32). Its 6,625.152 um² ring offers 2,981.3184 um² at .45 utilization; 736 DFFHQNx1 cells alone measure 214.6176 um². Clock, OR, buffer, reset and routing reserves remain to be measured. This proposal is not active in the plan of record.
