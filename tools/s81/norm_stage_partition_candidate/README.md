# S81 CTFN stage-partition candidate (not adopted)

The current granted v22 pin file gives different physical column ownership to the two ends of the same data bit. A plain four-column cut of the existing two-stage CTFN cannot retain both pin faces. The exact graph includes 5,608 normal/y-shift dependencies, 2,310 crossing column pairs, and a maximum horizontal span of 199.584 um. Unique data nets crossing the three column boundaries are 580 / 192 / 659. The stage partition exposes the existing first-stage registers as actual leaf outputs and gives the existing second-stage registers separate clocks, with a wires-only parent. It adds no data edge.

The candidate is fixed to the actual NG256 / GS8 / NCOL3 / S_RD2 shape (FDW2920). It is a separate experimental module; current CTFN and production parent instantiations are unchanged. Four input-stage leaves own bits by the granted fd_in physical x. Four output-stage leaves own bits by fdm x. Each output leaf receives each unique source bit once; normal and shifted operands index that packed source bus. Control captures and reset chains are real flops, not latency-only substitutes. No credits or ready-driven issue are introduced.

Same-recipe Yosys generic scalar synthesis found 5,865 clock FF in eight actual clock domains versus 5,856 in the original. Root counts are input [67,1219,1444,208], output [516,805,805,801], with no unattributed FF. The actual generic cost is +9 FF: six additional reset-chain flops and three selector captures no longer merged across distinct roots. This is not Liberty cell mapping, area, CTS, or routed timing evidence. The source-level 16 selector declarations are not evidence of 16 surviving FF.

The old module is extracted verbatim from source for lockstep testing. The test compares every normal/reset data and control output over 2,048 cycles, repeated reset epochs and short between-edge reset assertions. Eight independent missing-clock mutants drop one edge at each actual input/output root and must produce an observed mismatch at cycle99. Candidate and original only share external stimuli, not internal compute results. Pending proof logs are not a PASS claim.

## Conditional geometry direction for the next coordinator

`aligned_bus_geometry_proposal.json` records a better coupled producer/consumer proposal: put both CTFS.fd_out and CTFN.fd_in at the actual granted CTFN.fdm bit positions. This preserves the NORM-lane exclusion while changing the real bit order on both ends of the through-bus seam. All normal-mode dependencies remain within their own columns. Total cross-column normal/y-shift pairs fall from 2,310 to 384; unique data nets at each cut fall to 128 / 128 / 128; worst horizontal dependency falls to 125.376 um. A four-column hard-leaf candidate could retain each column's two current stages and export actual first-stage bits needed by the neighboring output stage. This improves the local through-bus cut, but it is not a complete valid transform.

The all-incident check caught a substantial counterexample: CTFS.fd_out also drives next_cth.CTFXS.fd_in[1127:0] (and the corresponding serial CTFX/capture branch), not only CTFN. With the broadcast sink unchanged, the actual pin x values plus the documented NTree 365.04 um vertical offset give **544 of 1,128 broadcast bits above 500 um**, maximum lower bound **666.768 um**, even before any interrow gap. This screen does not apply a current placed die transform and therefore is not final die timing, but it is sufficient to reject an unconditional two-endpoint adoption. The broadcast neighbor must be repinned/repositioned as part of the connected group; first/last chain source and terminal pins also need real evidence.

This direction is only a held geometric proposal: the exact proposed per-bit N/S coordinates are explicitly labelled ungranted, and every incident producer/consumer, clock and reset connection still needs audit. Current CTFS native routing is preserved. No closed tile is rerouted based on this proposal alone. The proof candidate below tests the eight-root stage partition, not the unimplemented four-root aligned-bus design.

## Physical blockers and next work

No physical kit or route is submitted for this candidate. The diagram uses actual pin coordinates, drawn to scale, but is not legal placement evidence. Proposed half-height leaf boxes are 144.18 x 12.96 um; clock-entry sites, cuts, free rows, internal interstage pin tracks, and all incident neighbor pins need actual checks. The cut of 659 data nets may already exhaust the permitted 0.60 routing fraction once control nets and real track exclusions are included. The eight independently compensated phi-R clock deliveries and replicated reset/valid source pins need an explicit die contract. A width-only observation is insufficient. Do not claim the same slot can fit until this is measured.

The CTFL one-stage case cannot use this existing-stage split: its input/output columns differ and there is no spare data stage. It needs actual producer/consumer repinning, a wider leaf spanning its actual pin pairs, or an explicitly priced added stage. Do not copy this CTFN candidate into CTFL and call it equivalent.

All current CTfnK8 / CTfs native routes stand and are preserved. The failing current K4 native audit is the reason for this bounded source study, not permission to retune or reroute an unrelated CLOSED element. NT swap, overall die changes, compiler calendar qualification, real PHY/input pin contracts, and complete token qualification remain open.

## Reproduction

`python3 tools/s81/norm_stage_partition_candidate/build_candidate.py` regenerates the candidate source, original extraction and pin graph from the exact granted JSON. In an isolated directory copy candidate source plus ctfn_original.sv, tb_ctfn_columns.sv and run.sh; use `ot-run --mem 2 --threads 1 --dir DIR -- bash -lc 'mkdir -p tmp; export TMPDIR="$PWD/tmp"; bash run.sh'`. Generic synthesis uses `yosys -p 'read_verilog -sv SOURCE; synth -top TOP -flatten -noabc; write_json mapped.json; stat'`. Heavy work must stay on fleet admission.
