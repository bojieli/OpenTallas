The selected Qwen input embedding is the existing HBM bootstrap path, `qkd_embgw_splitboot` through four `qkd_land_emb_ifw` landing strips and the real HBM controller. These tools preserve its deployed C1 precision: signed INT8 codes and one BF16 scale per 4096-element row, produced by the unchanged `qwen3_deployment_quality.quantize_w8`. The checkpoint lock pins the original BF16 tensor; this exporter introduces no new quantization choice.

`fetch_source.py` fetches and validates only the locked index and embedding-containing shard. `build.py --snapshot SNAP --out IMAGE --vectors EXISTING_TOKEN_VECTORS` validates the source bytes and tensor shape, quantizes all 151936 rows, checks historical token 0/65536/151935 vectors, and exports compact codes, little-endian BF16 scale bits and a manifest with full source/payload SHA values and the complete boot checksum. Run the heavy quantization through `ot-run` with CPU Torch, NumPy and safetensors available.

Every logical sector has 32 payload bytes. Code sector E = token*128+i; scale sectors start at 19447808 and contain sixteen consecutive scales. There are 19457304 sectors, 622633728 payload bytes. `emit_boot.py IMAGE OUT --format boot281` streams the existing bench representation `(payload256<<25)|E25`. Format `hb283` emits the selected HOST bus `(payload256<<27)|(E25<<2)|1` followed by the count/checksum marker. The boot checksum is the sum modulo 2^32 of CRC32 over the little-endian E32 followed by its payload. This is the existing boot contract; HBM protection remains in the RTL controller. Full image output is optional because the compact files are canonical and reconstruct every sector without padding.

`export_vectors.py IMAGE OUT` emits the existing bootstrap/decoder bench files for 25 actual boundary tokens, including scale-group, stack, row-index and final-vocabulary boundaries. FP32 decoded values are independent observations derived from immutable payload bytes, never RTL output substitutions.

Data export alone does not qualify the native embedding engine. The selected gateway, static HBM request schedule, real controller/landing state, arithmetic and destination VM composition require their separate RTL evidence. The alternative resident-ROM provider is outside the selected production path.
