# Persistent real eight-die native59 collector

`ot_qwen_native59_collective8` contains the actual eight native59 collectors and the same LATU14/LATS40/BPC3600 UCIe/SerDes models as the independently checked provider. It has no input-stimulus or expected-result arrays. Public vectors use native TP8 rank `4*DIE+PKG`, while internal placement follows `2*PKG+DIE`.

Create one library handle for the whole token. Keep it through every layer reduction and head gather. `native59_tick` drives the low phase, samples the signals consumed at the upcoming rising edge, then advances the actual RTL. Its returned valid/data/credit/fault signals therefore describe that edge. The producer updates its own credit counter with returned credit minus the input-valid bit it offered on that edge; initial credit is32. The observed `credits` array is a diagnostic pre-edge mirror. Every output-valid beat is posted and must be captured. All eight internal clocks share the defined functional833334fs period. Call the model on related engine edges, including idle edges with valid0; there is no per-operation reset or implicit context recreation.

Reset is explicit through input.rst_n. Start with actual reset edges, then wait for all online bits before offering input. Ordinary stage changes keep rst_n1. A tag with bits above58 set on an active input returns-3 without modifying or advancing the model; it cannot silently truncate into another identity.

The per-rank drain flag observes actual collector queue/head/reservation counts; accepted operand and arithmetic/identity pipelines; engine source credits; local input-credit accounting; peer result credits; and every corresponding link valid/credit pipeline. Global collector drain is all eight bits. It requires no outstanding input, no output or fault, recovered input credits32, engine credits4/32, peer credits32, and actual empty pipelines. It is not a cycle-delay estimate. Online covers actual RTL reset release. These are functional model probes through named state, not qualified physical ports. This component does not certify external HOST/KV/VM/FIFO drains or an allocator acceptance event.

The external regression retains one model/reset cohort across72 reductions and a gather. It checks147536 observed words including the post-reset check, full tags/ranks/last/error, and actual15–36-edge credit drain after the final data. Queued traffic from only one rank keeps drain false even with no outputs. A real warm reset cancels that pending state. A subsequent mismatched-epoch participant faults every die and emits no poisoned output. Offered test identities remain offered metadata, not accepted whole-token allocator receipts. The independent arithmetic fixture is outside the DUT; this is a transport regression, not a whole-token checkpoint arithmetic or price claim.

`build.sh OUTPUT` builds the model and shared C API. `build.sh OUTPUT EXISTING_MODEL_OUTPUT` reuses a compiled model only after checking every RTL/macro source SHA against its original manifest, records the model archive SHA, and links the current bridge. `test.py --lib LIB --fixture FIXTURE --out OUTPUT` runs the persistent component regression. The binary and full generated model remain in the frozen remote build; repository evidence stores hashes, source manifests and receipts.
